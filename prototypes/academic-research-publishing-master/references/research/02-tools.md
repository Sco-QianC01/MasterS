## 1. 文献检索与追踪

> **覆盖范围**：选题与文献综述 / 研究设计与统计 / 论文写作与投稿 / 同行评审应对 / 基金申请与实验室协作；理工与社科通用。

### 1. Web of Science Core Collection
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 用一套经人工筛选的期刊清单做引文检索与被引追踪，同时是国内评价体系里「SCI/SSCI 收录」这句话的事实定义来源。
- **谁在用**: 理工、生医、社科全学科；从研究生到 PI；也是科研管理与职称评审部门的默认口径。
- **相对优劣**: 对 Scopus —— WoS 收录更严（Clarivate 用 24 条质量标准 + 4 条影响标准评审期刊），期刊数量更少但「被收录」这件事本身在中国大陆更有行政含义；Scopus 期刊数量与会议论文覆盖更广，社科与非英语期刊命中更多。对 Google Scholar —— WoS 的检索式可复现、可导出、可写进系统综述的方法学部分，Google Scholar 不行。`evidence: [T02-S008, T02-S009, T02-S004]`
- **价格与获取**: 纯机构订阅，个人无法单买。中国大陆多数 985/211 与科研院所有订阅，需校园 IP 或 VPN；订阅内容按「版本」拆分（SCIE / SSCI / AHCI / ESCI / CPCI / BKCI 各自单卖），**你所在学校可能只买了其中几个**。Master Journal List 的基本查询免费开放，可以在校外查某刊是否仍被收录。`evidence: [T02-S008, T02-S009]`
- **上手成本**: 半天学会字段代码与检索式（TS=、TI=、AU=）；一周学会用「被引文献」和「引证文献」做滚雪球。
- **常见误用 / 坑**: ① 把「学校能打开 Web of Science」当成「学校订了 SCIE 全部年份」——回溯年限（backfiles）是另买的，1900 年以前的检索结果可能整段缺失；② 把 ESCI 收录说成「SCI 收录」；③ 用 WoS 的检索结果直接下结论说「这个题目没人做过」——WoS 不收多数中文期刊、不收大部分预印本、书籍覆盖有限；④ 期刊会被剔除（delisted），今年在 WoS 不等于投稿时还在。`evidence: [T02-S008, T02-S009]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S008, T02-S009]

### 2. Scopus
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 覆盖面比 WoS 更宽的引文数据库，做系统综述时它是「必须再跑一遍的第二个库」。
- **谁在用**: 生医、工程、社科；做系统综述与文献计量的人几乎必用两库对跑。
- **相对优劣**: 厂商自报覆盖「25,000+ 种活跃期刊、83M+ 条记录、10.5M 篇会议论文、750K+ 条来自 arXiv/bioRxiv/medRxiv/ChemRxiv 的预印本」（口径：Elsevier 官方页，2026 年查证，**数字为厂商自报**）。对 WoS 而言胜在广度与会议论文；输在中国大陆的行政认可度（评审文件里写 SCI 的远多于写 Scopus 的）。`evidence: [T02-S004]`
- **价格与获取**: 机构订阅。中国大陆高校订阅率略低于 WoS，工科院校较多。作者本人可免费认领并修正自己的 Scopus Author Profile（不需要机构订阅）。`evidence: [T02-S004]`
- **上手成本**: 与 WoS 类似，半天到一周。
- **常见误用 / 坑**: ① 直接把 WoS 的检索式粘进 Scopus——字段语法不同，检索式必须重写（这正是 Polyglot 一类工具存在的原因）；② 把 CiteScore 当影响因子引用（两者是不同机构、不同分母的指标）；③ 把 Scopus 里已收录的预印本当成已发表论文引用。`evidence: [T02-S004, T02-S011]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S004]

### 3. PubMed / PubMed Central
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 生物医学领域唯一一个人人都能免费用、且带受控主题词（MeSH）的检索入口。
- **谁在用**: 生物医学、公共卫生、护理、药学；临床医生与基础研究者；系统综述作者的第一站。
- **相对优劣**: 官方说明为「超过 4000 万条引文与摘要」，由 MEDLINE、PMC、Bookshelf 三部分组成，本身不存全文，全文靠链接到 PMC 或出版商（口径：NLM 官方 about 页）。对 Embase —— PubMed 免费但药物与欧洲会议摘要覆盖不如 Embase，Cochrane 一类高标准综述通常要求两者都检索；对 Google Scholar —— PubMed 的 MeSH 主题词让你能检出作者没用你那个关键词的文献。`evidence: [T02-S007]`
- **价格与获取**: 完全免费，中国大陆可直接访问（历史上偶有不稳定，但无需机构 IP）。PMC 全文免费，但**能在 PubMed 检到 ≠ 能免费看全文**。`evidence: [T02-S007]`
- **上手成本**: 基础检索十分钟；MeSH 主题词树、副主题词、explode/major topic 要一到两周才用得顺。
- **常见误用 / 坑**: ① 只用自由词不用 MeSH，导致漏检——新论文在建立 MeSH 索引前用 MeSH 检不到，所以规范做法是 MeSH 与自由词并用；② 把 PubMed 当全学科库用（心理学要查 PsycINFO、教育要查 ERIC）；③ 用 PubMed 的相关文章（Similar articles）代替系统检索写进方法学部分。`evidence: [T02-S007]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S007]

### 4. Google Scholar
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 全文级模糊检索 + 找 PDF 的最短路径，也是唯一能一次扫到学位论文、报告、预印本与灰色文献的入口。
- **谁在用**: 所有人，所有学科，尤其在没有机构订阅时。
- **相对优劣**: 对 WoS/Scopus —— Google Scholar 检的是全文而非题录，能捞到藏在正文里的方法名；但收录范围不公开、结果不可复现、无法导出完整结果集、去重差，因此**不能作为系统综述的唯一检索库**。它的引用计数包含未经审核的来源，比 WoS/Scopus 高但脏。`evidence: [T02-S017]`
- **价格与获取**: 免费。**中国大陆无法直接访问 scholar.google.com**，这是本 track 里最硬的可及性断点；常见替代路径是机构镜像、其他学术搜索引擎（如 Semantic Scholar、OpenAlex、Lens）或学校购买的发现系统。`evidence: [T02-S017, T02-S019, T02-S005]`
- **上手成本**: 十分钟。高级用法（引用追踪、Scholar Alerts、个人 Profile）一小时。
- **常见误用 / 坑**: ① 把 Google Scholar 的引用数写进本子或简历，被评审指出与 WoS/Scopus 数字不一致；② 把 h 指数（Google Scholar Profile 自动算的那个）跨学科比较；③ 把「Google Scholar 搜不到」当成「不存在」——它对中文期刊、部分订阅内容与非拉丁语种覆盖不稳定。`evidence: [T02-S017]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S017]

### 5. 学科专用数据库（PsycINFO / ERIC / Embase / Cochrane Library / IEEE Xplore / ACM DL / EconLit / CAS SciFinder / Compendex）
- **档位**: 场景特化
- **环节**: 1 文献检索与追踪
- **一句话**: 你那个学科的受控词表和收录范围只有本学科库有，综合库替不了。
- **谁在用**: 心理与教育（PsycINFO、ERIC）、临床与药学（Embase、Cochrane CENTRAL）、计算机与电子（IEEE Xplore、ACM DL）、经济（EconLit）、化学（SciFinder）、工程（Compendex）。
- **相对优劣**: 相对综合库，胜在词表贴合本学科概念、会议论文与试验注册记录覆盖全；输在跨学科检索要一个个跑、语法各不相同。系统综述的方法学审稿人几乎必问「你检了几个库、分别是哪些」。`evidence: [T02-S011, T02-S012]`
- **价格与获取**: 绝大多数是机构订阅（Cochrane Library 在部分国家有国家级免费许可，中国大陆一般仍需机构订阅）。**这一条的可及性完全由你学校买了什么决定。**
- **上手成本**: 每个库单独学半天到一天；跨库检索式转换是主要成本。
- **常见误用 / 坑**: ① 只检一个综合库就写「已进行系统检索」；② 把某库的自动映射（auto-mapping）当成检索式的一部分却不在附录里写清楚，导致别人无法复现；③ 忘记检索试验注册库与灰色文献，产生发表偏倚。`evidence: [T02-S011]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S011, T02-S012]

### 6. 中文文献库（CNKI 知网 / 万方 / 维普 / CSSCI / CSCD）
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 中文文献、学位论文、会议论文与中文核心期刊目录的事实垄断入口，做中国议题绕不开（**这一条的「必备」限于中国大陆语境**）。
- **谁在用**: 所有在中国大陆写中文论文、写开题报告、查重、查学位论文的人；社科与人文尤其依赖。
- **相对优劣**: 对 WoS/Scopus —— 中文文献覆盖无可替代，学位论文库是独有资产；输在检索语法弱、导出格式对国际文献管理软件支持一般、开放程度低。万方与维普在部分刊源上与知网互补，检索时应至少跑两家。
- **价格与获取**: 机构订阅为主；个人可按篇购买。**监管背景必须知道**：2023 年 9 月国家互联网信息办公室依法对知网作出网络安全审查相关行政处罚，责令停止违法处理个人信息并处罚款五千万元人民币（口径：网信办官方通报原文，2023 年，人民币）。`evidence: [T02-S016, T02-S022]`
- **上手成本**: 半天。
- **常见误用 / 坑**: ① 把「北大中文核心」「CSSCI」「CSCD」三套目录混着说成「中文核心」——它们是三套不同机构、不同周期的目录；② 用知网查重率当论文质量指标（见避坑清单）；③ 只检知网不检万方/维普，漏掉刊源差异；④ 把知网收录的会议论文集当成正式期刊论文写进成果表。`evidence: [T02-S022, T02-S016]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S016, T02-S022]

### 7. 预印本平台（arXiv / bioRxiv / medRxiv / SSRN / OSF Preprints / PsyArXiv / SocArXiv / ChinaXiv）
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 在正式发表前先看到（和先占住）最新工作，同时留下带时间戳的优先权记录。
- **谁在用**: 物理、数学、计算机（arXiv 已是事实上的首发渠道）、生物（bioRxiv）、医学与公卫（medRxiv）、经济与法学（SSRN）、心理与社会学（PsyArXiv / SocArXiv）；中文语境有 ChinaXiv。
- **相对优劣**: 相比等期刊，预印本快数月到一年，并且很多期刊已接受先发预印本；但**平台的筛查不是同行评审**——bioRxiv/medRxiv 官方明确说明只做剽窃、非科学内容、不当类型与公共健康风险的筛查，且每篇都带「未经同行评审认证」的声明，平台不对方法、假设、结论或科学质量作任何背书。`evidence: [T02-S013, T02-S014, T02-S018]`
- **价格与获取**: 免费投稿、免费阅读。中国大陆访问 arXiv 通常可用（速度不稳），bioRxiv/medRxiv 一般可用；ChinaXiv 由中科院体系运行，是中文语境的对应物。
- **上手成本**: 半小时。真正的成本在判断「什么时候可以贴预印本」——要先看目标期刊政策与合作导师意见。
- **常见误用 / 坑**: ① 把预印本当成已发表成果写进简历成果栏而不标注；② 引用预印本却不标注版本号与「preprint」字样，读者无法核对（预印本会改版，v1 和 v4 可能结论不同）；③ 忘记检查目标期刊是否禁止预发（少数期刊、尤其部分医学刊仍有限制）；④ 把预印本平台的筛查当质量把关。`evidence: [T02-S013, T02-S014]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S013, T02-S014, T02-S018]

### 8. 开放学术图谱与替代引文库（OpenAlex / Semantic Scholar / Dimensions / Lens.org）
- **档位**: 场景特化
- **环节**: 1 文献检索与追踪
- **一句话**: 在没有 WoS/Scopus 订阅、或需要把检索接进代码流程时，这几家提供开放或半开放的引文关系数据。
- **谁在用**: 做文献计量与科学学的人；没有商业库订阅的机构；需要批量筛选的系统综述团队；做专利与基金布局分析的工科团队。
- **相对优劣**: **OpenAlex**（OurResearch 运营）数据 CC0 开放、有 API、可全量下载，官方帮助页称收录超过 3.2 亿件 works，非英语与全球南方文献覆盖优于商业库（口径：OpenAlex 官方帮助页，2026 年查证，**项目方自报**）；弱点是作者消歧与机构归属仍有错误、无官方分区。**Semantic Scholar**（Allen Institute for AI）免费、有开放 API、提供 TLDR 一句话摘要与"高影响力引用"标记，中国大陆可直接访问，是 Google Scholar 不可达时的常用替代；弱点是收录规模与全文索引深度不及商业库。**Dimensions**（Digital Science）与 **Lens.org** 把论文、专利、基金项目、临床试验放在同一张关系网里，适合写本子时查"这个方向被谁资助过"；弱点是期刊遴选把关与国内行政认可度不如 WoS。`evidence: [T02-S005, T02-S006, T02-S019, T02-S023, T02-S024]`
- **价格与获取**: OpenAlex 数据 CC0 免费、API 有免费额度与付费档；Semantic Scholar 免费（API 有速率限制）；Dimensions 有功能受限的免费网页版与付费分析版；Lens.org 免费注册可用、机构版付费。四者中国大陆一般可访问。`evidence: [T02-S005, T02-S019, T02-S023, T02-S024]`
- **上手成本**: 网页界面十分钟；API 与批量分析需要会写一点 Python/R，一到两天。
- **常见误用 / 坑**: ① 直接用 OpenAlex 的作者页做人才评价——**同名消歧错误率不可忽视，必须人工核对**；② 把自动生成的 topic/concept 标签或 TLDR 摘要当成权威结论；③ 用它们替代 WoS/Scopus 做需要"可复现检索式"的系统综述而不报告数据快照日期；④ 把免费层跑出的统计数字当成完整数据写进本子（免费层的检索与导出上限不同）；⑤ 把"highly influential citation"当质量背书——那是算法标记，不是同行判断。`evidence: [T02-S005, T02-S006, T02-S019, T02-S023]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S005, T02-S006, T02-S019, T02-S023, T02-S024]

### 9. 引文网络发现工具（Connected Papers / ResearchRabbit / Litmaps / Inciteful）
- **档位**: 场景特化
- **环节**: 1 文献检索与追踪
- **一句话**: 给一篇种子论文，画出它周围的引用邻居，用来快速摸清一个陌生领域的骨架和"我是不是漏了一支重要文献流"。
- **谁在用**: 刚进入新方向的博士生与转方向的博后；写综述引言时找遗漏；社科与理工通用。
- **相对优劣**: Connected Papers 一次生成一张静态图，适合"这个方向长什么样"；ResearchRabbit 与 Litmaps 更偏持续追踪（收藏集合 + 新文提醒），适合"这个方向以后有新东西提醒我"。**三者都不能替代系统检索**：它们的输出取决于种子论文的选择，天然放大你已有的偏好。`evidence: [T02-S015, T02-S020, T02-S021]`
- **价格与获取**: Connected Papers 有免费额度 + 付费档；ResearchRabbit 官方定位为对研究者免费；Litmaps 有免费层与付费层。中国大陆一般可访问（速度不稳）。**具体价格随时会变，用前请自行核对官方定价页。**`evidence: [T02-S015, T02-S020, T02-S021]`
- **上手成本**: 十五分钟。
- **常见误用 / 坑**: ① 把图谱当成检索结果写进系统综述的方法学部分（不可复现、不可穷尽）；② 只用一篇种子论文，得到一张只反映一个学派的图；③ 图里节点大小/颜色的含义各家定义不同，凭直觉解读会读错。`evidence: [T02-S015, T02-S020, T02-S021]`
- **last_updated: 2026-09** ；**(Decay risk: high)**
- evidence: [T02-S015, T02-S020, T02-S021]

### 10. 检索式构建与去重工具（Polyglot Search Translator / Deduplicator / SearchRefinery，Bond University SRA 与 TERA）
- **档位**: 场景特化
- **环节**: 1 文献检索与追踪
- **一句话**: 把一条 PubMed/Ovid 检索式自动翻成 Embase、Cochrane、Web of Science、CINAHL、PsycINFO、Scopus 的语法，并把多库结果去重——系统综述里最枯燥也最容易出错的两步。
- **谁在用**: 做系统综述与范围综述的人；医学图书馆员；循证医学团队。
- **相对优劣**: 对手工翻译检索式 —— 快、错误少，但**翻译结果必须人工复核**（受控词表在库之间不是一一对应的）。对 EndNote 内置去重 —— 专用去重工具在系统综述场景的查准/查全通常更好，但仍需人工过一遍。团队自述定位是"在不牺牲质量的前提下缩短系统综述耗时"。`evidence: [T02-S011, T02-S012]`
- **价格与获取**: 由 Bond University 循证医疗研究所运行，网页工具免费；旧站 SR-Accelerator 已引导用户迁往新平台 TERA。中国大陆可访问。`evidence: [T02-S011, T02-S012]`
- **上手成本**: 一小时。
- **常见误用 / 坑**: ① 把自动翻译的检索式原样写进论文附录而不标注「经人工校核」——审稿人会逐条检查；② 去重时用宽松阈值把不同版本（会议摘要 vs 全文）当重复删掉；③ 忽略这套工具以健康研究为中心，非医学库的支持有限。`evidence: [T02-S011, T02-S012]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S011, T02-S012]

### 11. 订阅式新文追踪（PubMed My NCBI 邮件提醒 / 期刊目录 RSS / Google Scholar Alerts / 数据库检索式提醒）
- **档位**: 必备
- **环节**: 1 文献检索与追踪
- **一句话**: 把「定期去搜一遍」变成「有新文自动送到眼前」，是唯一能长期维持领域敏感度的低成本机制。
- **谁在用**: 所有阶段；对博士生尤其重要（读文献的习惯就是这么建立的）。
- **相对优劣**: 数据库自带的检索式提醒（PubMed My NCBI、WoS/Scopus alert）精度最高、可复现；Google Scholar Alerts 覆盖最广但噪音大且大陆不可直接访问；期刊 RSS 最稳定但只覆盖你订的那几本，会错过跨界工作。三者应该叠加而不是二选一。`evidence: [T02-S007, T02-S017]`
- **价格与获取**: PubMed My NCBI 免费；数据库 alert 随订阅；RSS 阅读器有免费与付费选择。
- **上手成本**: 半小时建好，之后是维护成本——**每季度回头删掉噪音过大的那条检索式**，否则会形成「全都不看」的失效状态。
- **常见误用 / 坑**: ① 建了十条提醒然后全部归档不看，等于没建；② 只订自己的关键词，形成回音室，永远看不到反例；③ 把提醒当成系统检索的替代（提醒只覆盖建立之后的新文）。`evidence: [T02-S007]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S007, T02-S017]

### 12. scite
- **档位**: 新兴
- **环节**: 1 文献检索与追踪
- **一句话**: 不只告诉你一篇论文被引了多少次，还把每条引用分成"支持 / 反驳 / 仅提及"，用来快速判断一个结论是不是还站得住。
- **谁在用**: 生医与心理学的谨慎读者、审稿人、做证据合成的人；也被部分出版商作为 badge 嵌进文章页。
- **相对优劣**: 对普通引文计数 —— 能看到引用语境（引在哪一节、说了什么），对判断「这篇被撤稿/被质疑过吗」很有价值；输在分类由深度学习模型自动完成、**误分类真实存在**，且覆盖依赖能拿到的全文，非开放获取文献的语境提取不全。厂商自报的分类语料规模在十亿量级（**厂商自报，未经独立核实**）。`evidence: [T02-S010]`
- **价格与获取**: 个人订阅制，有机构订阅与试用；部分出版商页面上的 scite badge 免费可见。中国大陆一般可访问。`evidence: [T02-S010]`
- **上手成本**: 二十分钟。
- **常见误用 / 坑**: ① 把「0 条 contrasting」当成「没人反驳过」——大量文献没有被 scite 覆盖全文；② 用支持/反驳的比例当成证据强度指标写进论文；③ 忘了引用分类是模型输出，必须点进去读原句才能确认。`evidence: [T02-S010]`
- **last_updated: 2026-09** ；**(Decay risk: high)**
- evidence: [T02-S010]


## 2. 文献管理与阅读

### 13. Zotero
- **档位**: 必备
- **环节**: 2 文献管理与阅读
- **一句话**: 一键抓取题录 + 自动生成任何期刊要求的参考文献格式，把「手工调参考文献」这件事从论文流程里彻底删掉。
- **谁在用**: 全学科、全阶段；在没有机构 EndNote 授权的团队里几乎是默认选项；社科与人文占比尤其高。
- **相对优劣**: 对 EndNote —— Zotero 开源免费、浏览器抓取更强、群组库对小团队协作友好、内置 PDF 阅读与标注；输在超大库（数万条）的性能与 Word 深度整合的成熟度，以及机构 IT 支持。对 Mendeley —— Zotero 由非营利组织运营且不属于任何出版商，数据主权更清晰。`evidence: [T02-S025, T02-S027, T02-S029]`
- **价格与获取**: 软件本身免费开源；只有云端同步的文件存储收费——免费 300 MB，2 GB 每年 20 美元、6 GB 每年 60 美元、无限量每年 120 美元（口径：Zotero 官方存储页，2026 年查证，美元）。**PDF 可以只存本地不上云，从而完全免费使用。** 中国大陆可直接访问，同步偶尔不稳，可自建 WebDAV 存储替代。`evidence: [T02-S001, T02-S025]`
- **上手成本**: 一小时装好插件（浏览器扩展 + Word/LibreOffice 插件）；一周养成「读到就存」的习惯。写 LaTeX 的人需要额外装 Better BibTeX 插件。`evidence: [T02-S026]`
- **常见误用 / 坑**: ① 抓取的题录字段有错（尤其从 Google Scholar 和出版商页面抓的，作者姓名顺序、期刊缩写、卷期常错）却直接生成参考文献，投稿被退；② 不用群组库，靠邮件互传 .ris 文件，最后谁的库都不一样；③ 300 MB 免费额度爆掉后同步静默失败，人还不知道；④ 装了一堆插件后升级大版本时插件不兼容，写论文当天崩掉——**投稿季不要升级大版本**。`evidence: [T02-S025, T02-S026, T02-S001]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S001, T02-S025, T02-S026]

### 14. EndNote
- **档位**: 必备
- **环节**: 2 文献管理与阅读
- **一句话**: 机构统一采购、期刊官方 output style 最全的文献管理器，也是很多中国高校图书馆培训里唯一教的那一个。
- **谁在用**: 生医与理工为主；有机构站点授权的高校；投稿要求提供 EndNote 样式文件的场合。
- **相对优劣**: 对 Zotero —— EndNote 在超大文献库、复杂手稿、与 Word 的域代码整合上更稳，出版商提供的 output style 覆盖更全；输在价格、开放性与浏览器抓取体验。当前版本为 EndNote 2025，官方宣传包含 AI 研究助手与 Web of Science 整合、云端无限存储（口径：EndNote 官方产品页，**功能描述为厂商自报**）。`evidence: [T02-S027, T02-S028]`
- **价格与获取**: 商业软件，个人版一次性购买（官方页给出的升级价为 125 美元，2026 年查证，美元，**厂商自报**），学生版需验证在读身份，机构站点授权最常见。**中国大陆高校普遍有站点授权——先去图书馆网页查，不要自己买。**`evidence: [T02-S028]`
- **上手成本**: 半天；从 Zotero/Mendeley 迁库要额外半天且字段会丢。
- **常见误用 / 坑**: ① Word 里域代码（field codes）没去掉就投稿，编辑部拿到的稿子在别的机器上乱码——投稿前用「Convert to Plain Text」另存一份；② 不同版本 EndNote 生成的 .enl 库互不兼容，与合作者版本不一致会毁库；③ 直接用某期刊名字的 output style 而不核对当年投稿指南（样式文件更新滞后于期刊要求）。`evidence: [T02-S027]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S027, T02-S028]

### 15. 其他文献管理器（Mendeley / Paperpile / NoteExpress）
- **档位**: 场景特化
- **环节**: 2 文献管理与阅读
- **一句话**: 在特定生态里比 Zotero/EndNote 更顺手的三个选择——Elsevier 生态、Google Docs 生态、中文国标格式生态。
- **谁在用**: **Mendeley**：深度使用 Elsevier 平台（Scopus/ScienceDirect）的人；**Paperpile**：用 Google Docs 多人实时协作写稿的团队（海外为主）；**NoteExpress**：在中国大陆写中文学位论文与中文期刊论文的人。
- **相对优劣**: Mendeley 界面友好、与 Elsevier 平台整合好，但**它归出版商所有**，数据主权与长期可用性是社群里的真实分歧点，且历史上经历过桌面版重写与功能取舍，用户信任度受损。Paperpile 在 Google Docs 里插引用的协作体验最好，但**中国大陆无法直接访问 Google Docs，这基本排除了它在国内团队的可行性**。NoteExpress 对知网/万方/维普题录导入与 GB/T 7714 国标参考文献格式支持最完整、有中文界面与本地支持，输在国际期刊 output style 覆盖、跨平台支持（macOS/Linux 弱）与开放性。`evidence: [T02-S029, T02-S033, T02-S035]`
- **价格与获取**: Mendeley 基础免费 + 存储分层收费；Paperpile 订阅制（依赖 Google 服务，大陆不可用）；NoteExpress 商业软件，**大量中国高校有集团授权，学生凭校园网可免费用——先查图书馆页面，不要自己买**。`evidence: [T02-S029, T02-S033, T02-S035]`
- **上手成本**: 各一小时到半天。
- **常见误用 / 坑**: ① 把任何一个当成长期资产而不定期导出 BibTeX/RIS 备份；② 依赖某个特定桌面版本的功能，版本更迭后消失（Mendeley 有前科）；③ Paperpile 定稿导出 Word 后引用变成静态文本，之后改动无法自动更新，且不用 Paperpile 的合作者看不到可编辑的引用对象；④ NoteExpress 在中英混排时英文条目格式细节出错，换到英文投稿才发现题录字段不全需要重抓；⑤ 三者与 Zotero/EndNote 互导会丢字段。`evidence: [T02-S029, T02-S033, T02-S035]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S029, T02-S033, T02-S035]

### 16. PDF 阅读与标注（Zotero 内置阅读器 / Adobe Acrobat / PDF Expert / 平板手写批注）
- **档位**: 场景特化
- **环节**: 2 文献管理与阅读
- **一句话**: 让读过的痕迹（高亮、批注、疑问）留在能被检索的地方，而不是散在下载文件夹里。
- **谁在用**: 所有需要精读的人；论文修改阶段与审稿阶段尤其。
- **相对优劣**: Zotero 内置阅读器胜在标注直接进入文献库、可导出成笔记、跨设备同步；专用 PDF 软件胜在手写、大文件性能与表单能力。**关键判据是标注能否被搜索到**——存在孤立 PDF 里的高亮，三个月后等于没做。`evidence: [T02-S025]`

### 17. 笔记与知识管理（Obsidian / Logseq / Notion / 纯文本 Markdown）
- **档位**: 场景特化
- **环节**: 2 文献管理与阅读
- **一句话**: 把读过的东西变成自己的句子并互相链接，让写引言时不必从零开始。
- **谁在用**: 人文与社科偏多；写综述、写大论文、跨年度追踪一个主题的人。
- **相对优劣**: Obsidian/Logseq 是本地纯文本（Markdown），可版本管理、可长期保存、可被 grep，代价是要自己搭结构；Notion 是云端结构化数据库，团队协作与表格好用，代价是数据在别人服务器上、导出后结构损失、**中国大陆访问不稳定**。`evidence: [T02-S034]`
- **价格与获取**: Obsidian 个人使用免费（官方同步与发布服务另收费）；Notion 有免费层与教育优惠。`evidence: [T02-S034]`
- **上手成本**: 软件半小时；**方法论是真正的成本**——多数人会花几个月折腾体系然后放弃。建议先用最笨的办法（一篇文献一个文件、写三句话）跑满三个月再谈体系。
- **常见误用 / 坑**: ① 花在搭系统上的时间超过读文献的时间（这是本条最常见的失败模式）；② 把摘要复制粘贴进笔记当成「已读」——复制不产生理解；③ 笔记里存了大段原文，写作时不慎变成未标注引用，构成抄袭风险；④ 云端笔记里放未发表数据与被试信息，违反伦理批件与数据合规要求。`evidence: [T02-S034]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S034]

### 18. 系统综述筛选与去重平台（Rayyan / Covidence）
- **档位**: 场景特化
- **环节**: 2 文献管理与阅读（系统综述筛选）
- **一句话**: 两个人各自盲筛几千条题录、自动比对分歧、自动出 PRISMA 流程图，把系统综述最枯燥的一段变成可审计的流程。
- **谁在用**: 做系统综述、范围综述、meta 分析的团队；医学、护理、公卫、教育、心理；循证医学与 Cochrane 体系。
- **相对优劣**: **Rayyan** 有可用的免费层（官方帮助中心说明免费与 Essential 套餐同时最多 3 个进行中的综述），对个人与小团队门槛低；输在全流程覆盖。**Covidence** 把去重、双人题摘筛选、全文筛选、数据提取表、偏倚风险评估串成一条线并自动生成 PRISMA 流程图、可导出到 RevMan，官方页说明机构订阅为站点级、综述与用户数不限，个人/小团队可在线用信用卡买按次套餐；输在没有真正可用的长期免费层。**对 Excel 手工筛，两者都远胜**——因为盲筛与分歧记录本身就是 PRISMA 要求报告的内容。`evidence: [T02-S031, T02-S032]`
- **价格与获取**: Rayyan 免费层 + 个人订阅 + 机构订阅（Academic / Business / Enterprise）；Covidence 以机构站点订阅为主。**两者的价格与免费额度厂商随时调整，用前必须自己开定价页确认；并且先查你学校图书馆是否已有站点订阅——很多人自掏腰包买了才发现学校有。** 中国大陆均可访问，但国内机构订阅率远低于欧美澳。`evidence: [T02-S031, T02-S032]`
- **上手成本**: 两小时到半天；团队要额外花时间统一纳排标准并做预筛一致性校准。
- **常见误用 / 坑**: ① 不开盲筛（blind mode），两人互相看得见对方的决定，一致性统计失去意义；② 纳排标准没定死就开始筛，筛到一半改标准且不记录；③ 把自动生成的 PRISMA 流程图直接贴进论文而不核对各环节数字（自动统计与手工排除的记录常对不上）；④ 数据提取表设计不当，提取到一半发现缺字段要全部返工；⑤ 免费层的综述数量限制在项目中途触顶，或订阅到期后数据导出不完整。`evidence: [T02-S031, T02-S032]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S031, T02-S032]


## 3. 写作与协作

### 19. LaTeX + Overleaf（含期刊模板与 Pandoc / rticles 格式转换）
- **档位**: 必备
- **环节**: 3 写作与协作
- **一句话**: 公式、交叉引用、参考文献、期刊模板四件事一次搞定，并且能多人同时在浏览器里改同一份稿子。
- **谁在用**: 数学、物理、计算机、统计、部分工程与经济学（在这些学科里不用 LaTeX 才是例外）；生医与多数社科仍以 Word 为主。
- **相对优劣**: 对 Word —— LaTeX 在公式、编号、交叉引用与大文档结构上压倒性占优，且源文件是纯文本可进 Git；输在与不会 LaTeX 的合作者（尤其是导师和临床合作方）协作、以及很多期刊/基金要求 Word 格式提交。Overleaf 官方自述超过 2000 万用户、创建文档超过 1 亿份（口径：Overleaf 官方 about 页，**厂商自报，未经独立核实**），2014 年起属于 Digital Science。`evidence: [T02-S036, T02-S047]`
- **价格与获取**: LaTeX 本身开源免费（本地装 TeX Live / MacTeX）。Overleaf 有免费层与付费层（协作者数量、编译时长、版本历史、Git 同步等按档区分，**具体额度厂商会调，用前查官方 plans 页**）。中国大陆可访问 Overleaf 但常较慢；很多国内用户改用本地 TeX + Git，或使用国内镜像的 CTAN 源。`evidence: [T02-S036, T02-S037, T02-S047]`
- **上手成本**: 两周能写出一篇像样的论文；一年才真正不怕报错。**新手最大的时间黑洞是排版细节，不是内容。** 配套的格式转换工具（Pandoc 通用文档转换器、rticles 的 R Markdown 期刊模板集）各需一小时上手，均开源免费。`evidence: [T02-S041, T02-S049]`
- **常见误用 / 坑**: ① 在正文里手写编号而不用 `\label`/`\ref`，改一处全篇错位；② 用了期刊模板但没读模板附带的 README，投稿被格式退回；③ 免费层编译超时在截稿前爆掉；④ 与导师协作时导师只会 Word，最后靠人肉转换，引入大量错误；⑤ 把 `.bib` 文件里的脏题录（作者名、期刊缩写错）当成"LaTeX 会帮我处理好"；⑥ 以为"用了官方模板就等于符合投稿要求"——模板不管字数、图表数量上限、引用上限、结构化摘要这些实质要求；⑦ 被拒转投时忘了删掉上一本期刊的模板痕迹（页眉、期刊名、投稿编号）；⑧ 用 Pandoc / rticles 做 LaTeX↔Word 转换后不逐页目视检查，公式与表格悄悄走样。`evidence: [T02-S036, T02-S047, T02-S030, T02-S041, T02-S049]`
- **last_updated: 2026-09** ；**(Decay risk: low)**

### 25. 图表绘制与配色可及性（ggplot2 / matplotlib / Inkscape / Illustrator / BioRender + ColorBrewer / viridis / Okabe-Ito）
- **档位**: 必备
- **环节**: 3 写作与协作
- **一句话**: 图是论文里被看得最多的部分；用代码画能保证"数据变了图自动跟着变"，用对配色能保证图在色觉障碍读者眼里和黑白打印时都还读得懂。
- **谁在用**: 全学科。R 用户用 ggplot2，Python 用户用 matplotlib/seaborn，生命科学示意图用 BioRender，最终排版微调用 Inkscape（开源）或 Illustrator。配色部分越来越多期刊在投稿指南里明确要求。
- **相对优劣**: **代码绘图的核心优势是可重复**——审稿人要求换个分组方式，改一行重跑；点选式软件（Excel、Prism、Origin）快但每次修改都是手工劳动且无法追溯。Inkscape 免费开源、导出 SVG/EPS 符合多数期刊要求；Illustrator 功能更全但需订阅；BioRender 解决"画一张像样的机制示意图"，**但导出与发表许可条款按订阅档位不同，用前必须确认**。配色上，ColorBrewer 提供按用途（定性/顺序/发散）分类并可筛选"色盲安全"的方案；viridis 系列色标的官方说明强调其在感知上均匀且对常见色觉缺陷友好——相对 jet/rainbow 彩虹色标，后者在感知上不均匀，会在数据里制造并不存在的边界，这是学界长期批评的点。`evidence: [T02-S043, T02-S039, T02-S040]`
- **价格与获取**: ggplot2、matplotlib、Inkscape、ColorBrewer、viridis 全部开源/免费；BioRender 有免费层与付费层；Illustrator 订阅制，部分高校有授权。中国大陆均可获取。`evidence: [T02-S043, T02-S039, T02-S040]`
- **上手成本**: ggplot2/matplotlib 出一张能看的图一小时，出一张能投顶刊的图要几十小时的积累；Inkscape 半天；配色二十分钟。
- **常见误用 / 坑**: ① 交位图（PNG/JPG）给要求矢量图的期刊，分辨率不足被退；② 图里字号小于正文的一半，缩到单栏宽后完全看不清；③ 条形图 + 误差棒展示小样本连续数据，隐藏真实分布（应画散点/箱线/小提琴）；④ 用双 Y 轴制造相关性错觉；⑤ **只靠颜色区分序列，不同时用形状/线型/直接标注——颜色永远应该是冗余编码而不是唯一编码**；⑥ 用红绿对比表示"好/坏"（最常见的色觉障碍类型正是红绿）；⑦ 用发散色标画本来没有中点的顺序数据；⑧ 定性配色用了超过 8 种颜色，谁也分不清。`evidence: [T02-S043, T02-S039, T02-S040]`

- **一句话**: 免费、点选式、但底层是 R 的统计软件，让不会写代码的人也能做贝叶斯分析和规范的效应量报告。
- **谁在用**: 心理与教育的教学场景；不想学编程但需要贝叶斯因子的研究者；预算受限的实验室。
- **相对优劣**: 对 SPSS —— 免费、界面现代、输出直接是 APA 格式表格、JASP 的贝叶斯模块是它最大的差异化；输在高级建模与自定义能力。对 R —— 上手快得多；输在灵活性与可脚本化程度（两者都有一定的可复现记录能力，但不如脚本）。JASP 由阿姆斯特丹大学团队发起，jamovi 建在 R 之上，两者都开源。`evidence: [T02-S055, T02-S056]`
- **价格与获取**: 均免费开源，跨平台。中国大陆可下载。`evidence: [T02-S055, T02-S056]`
- **上手成本**: 半天。
- **常见误用 / 坑**: ① 拿到贝叶斯因子却按"BF>3 就是有效果"当成新的 p<0.05 二分标准用；② 用默认先验而不在论文里说明先验是什么（**贝叶斯分析必须报告先验**）；③ 以为界面软件就不需要理解模型假设。`evidence: [T02-S055, T02-S056]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S055, T02-S056]

### 30. G*Power 与基于模拟的功效分析
- **档位**: 必备
- **环节**: 4 统计与可复现
- **一句话**: 在收数据之前算出"要多少样本才有合理概率检出我关心的那个效应"，这是伦理审查、预注册与审稿都会问的问题。
- **谁在用**: 心理、教育、临床试验、动物实验；所有要写伦理申请或预注册的人。
- **相对优劣**: G*Power 由杜塞尔多夫大学 Buchner、Erdfelder、Faul、Lang 开发，免费，覆盖 t 检验、F 检验、χ² 检验、z 检验、相关与回归、logistic 与 Poisson 回归等（口径：作者团队官方页）。**它的边界是标准设计**——多层模型、纵向数据、复杂交互作用超出它的能力，这类设计要用基于模拟的功效分析（R 里的 `simr`、`Superpower`、或自己写模拟）。`evidence: [T02-S057, T02-S050]`
- **价格与获取**: G*Power 完全免费（官方声明包括商业环境用户也免费，仅禁止商业分发），Windows 与 macOS 均有版本。中国大陆可下载。`evidence: [T02-S057]`
- **上手成本**: 标准设计半天；模拟法要会写 R 代码，一到两周。
- **常见误用 / 坑**: ① **事后功效（post hoc power）**——用观察到的效应量反算功效，这是无信息量的，方法学审稿人见到会直接批；② 把 Cohen 的"中等效应"当默认输入，而不是用领域内的最小有意义效应；③ 只算主效应的功效，实际关心的是交互作用（交互作用通常需要数倍样本）；④ 算完不记录参数，论文里写不清楚假定的是什么。`evidence: [T02-S057]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S057]

### 31. Stan / brms / PyMC（贝叶斯建模）
- **档位**: 场景特化
- **环节**: 4 统计与可复现
- **一句话**: 把"数据是怎么产生的"写成模型再让数据更新参数，适合层次结构复杂、样本量小、或需要把先验知识写进来的问题。
- **谁在用**: 生态、心理、认知科学、流行病学、天体物理；做多层/混合效应模型且遇到频率派收敛问题的人。
- **相对优劣**: Stan 是概率编程语言与推断引擎（官方站为 mc-stan.org），brms 让你用 R 的公式语法写贝叶斯多层模型再自动生成 Stan 代码，PyMC 是 Python 生态的对应物。对频率派混合模型（lme4）—— 贝叶斯路线在复杂随机效应结构下更稳、能给出完整的不确定性；输在计算时间与"要向不熟悉的审稿人解释"的成本。`evidence: [T02-S059]`
- **价格与获取**: 全部开源免费。
- **上手成本**: brms 有 R 基础的话两周能跑通；真正理解先验、诊断（R-hat、有效样本量、发散转移）需要几个月。**建议配合 McElreath 的 Statistical Rethinking 学。**
- **常见误用 / 坑**: ① 不做收敛诊断就报结果；② 用默认先验且不做先验敏感性分析，被审稿人质疑结论是先验驱动的；③ 把后验概率当成"假设为真的客观概率"讲给不懂贝叶斯的读者；④ 用贝叶斯因子做二分判断（同 JASP 那条坑）。`evidence: [T02-S059, T02-S055]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S059]

### 32. DAGitty（因果图）
- **档位**: 场景特化
- **环节**: 4 统计与可复现
- **一句话**: 把你对因果关系的假设画成图，软件直接告诉你"该控制哪些变量、不该控制哪些"，避免调整了对撞变量反而制造出虚假关联。
- **谁在用**: 流行病学、公共卫生、社会学、经济学、心理学；所有用观察数据谈因果的人。
- **相对优劣**: 官方说明它是浏览器里创建、编辑、分析因果图（有向无环图）的环境，能识别调整集（adjustment sets）与可检验蕴含（testable implications），由 Radboud 大学的 Johannes Textor 维护，GPL 开源，CRAN 上有 dagitty R 包（口径：DAGitty 官方站）。对"把所有能测的协变量都放进模型" —— DAGitty 的价值正是证明这个做法是错的。`evidence: [T02-S058]`
- **价格与获取**: 免费开源，网页版直接用，无需安装。中国大陆可访问。`evidence: [T02-S058]`
- **上手成本**: 会画图两小时；**难的不是工具而是画出诚实的图**——你得先想清楚领域知识里的因果结构，这可能要几周的文献工作与专家讨论。
- **常见误用 / 坑**: ① 事后调整因果图直到得出自己想要的调整集（这是新的研究者自由度）；② 图里漏掉未测量的混杂因子，得到"只要控制这三个就行"的假安心；③ 把 DAG 当成统计模型（DAG 编码假设，不做估计）；④ 论文里不附上 DAG，读者无法判断你的识别策略。`evidence: [T02-S058]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S058]

### 33. 元分析工具（metafor / RevMan / Cochrane 偏倚风险工具）
- **档位**: 场景特化
- **环节**: 4 统计与可复现
- **一句话**: 把多项研究的效应量合并、检查异质性与发表偏倚，并把偏倚风险评估变成可核查的表格。
- **谁在用**: 做系统综述与 meta 分析的人；医学、心理、教育、生态。
- **相对优劣**: metafor 是 R 包，能拟合等效应、固定效应、随机效应与混合效应模型，支持调节变量分析与 meta 回归，GPL-2 开源（口径：项目官方站）；RevMan 是 Cochrane 的官方软件，流程规范、直接对接 Cochrane 综述格式；商业软件 CMA 界面友好但封闭。**metafor 灵活但要写代码，RevMan 规范但模型选择受限。**`evidence: [T02-S060, T02-S061]`
- **价格与获取**: metafor 免费开源；RevMan 由 Cochrane 提供，Cochrane 综述作者可用，非 Cochrane 用途的可用性与收费按其当时政策（**用前查官方页确认**）。`evidence: [T02-S060, T02-S061]`
- **上手成本**: metafor 有 R 基础一周；元分析的方法学（效应量换算、依赖数据结构、异质性解释）要几个月。
- **常见误用 / 坑**: ① 用 I² 的大小机械判断"能不能合并"（I² 依赖于纳入研究的精度，不能单独解释）；② 纳入研究之间存在依赖（同一队列的多篇论文）却当成独立处理；③ 用漏斗图不对称直接下"存在发表偏倚"的结论；④ 合并了偏倚风险高的研究却在结论里不区分；⑤ 未预先注册就在做的过程中调整纳排标准。`evidence: [T02-S060, T02-S061]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S060, T02-S061]

### 34. Quarto / R Markdown / Jupyter（可重复文稿）
- **档位**: 必备
- **环节**: 4 统计与可复现
- **一句话**: 让论文里的每个数字都由代码现场算出来，改了数据重新渲染，正文里的数字自动更新——从此不再有"表 2 和正文对不上"。
- **谁在用**: 计算类学科、定量社科、生物信息；越来越多期刊接受或鼓励提交可执行文稿。
- **相对优劣**: Quarto 官方 FAQ 说明它是建在 Pandoc 之上的开源科学与技术出版系统，可直接渲染 .ipynb，计算引擎支持 knitr 与 Jupyter，主要支持 Python、R、Julia 与 Observable JS，由 Posit 赞助开发（1.4 起为 MIT 许可）。对 R Markdown —— Quarto 是更通用的后继者，同一套语法跨语言；对纯 Jupyter Notebook —— Quarto/R Markdown 更适合产出成品文档，Notebook 更适合探索。`evidence: [T02-S046, T02-S068]`
- **价格与获取**: 全部开源免费。
- **上手成本**: 会用两天；把一篇已有论文改造成可重复文稿，第一次通常要一周。
- **常见误用 / 坑**: ① notebook 乱序执行造成的假可重复（见 Python 那条）——发布前一定要"清空内核 + 从头跑一遍"；② 在文档里缓存中间结果却不说明，别人重跑得到不同数字；③ 把可重复文稿理解成"排版工具"而不改分析习惯；④ 渲染依赖本地环境（字体、LaTeX 发行版、包版本），换机器就失败——要配合 renv/容器。`evidence: [T02-S046, T02-S068, T02-S063]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S046, T02-S068]

### 35. Git + GitHub / GitLab / Gitee
- **档位**: 必备
- **环节**: 4 统计与可复现
- **一句话**: 记录代码与手稿的每一次改动、谁改的、为什么改，并让"回到三个月前那个能跑的版本"成为一条命令。
- **谁在用**: 所有写代码的研究者；写 LaTeX 的人；越来越多的纯文本笔记与手稿管理。
- **相对优劣**: 对网盘同步（Dropbox/坚果云）—— Git 能追溯与分支、能合并多人改动；输在学习曲线与二进制文件（Word、大数据文件）处理。GitHub 生态最大且能一键关联 Zenodo 存档拿 DOI；GitLab 可自建；**Gitee 在中国大陆访问最快，很多国内团队用它做主仓库、GitHub 做镜像。**`evidence: [T02-S062]`
- **价格与获取**: Git 开源免费；GitHub 个人与教育账户免费（私有仓库亦可），机构版付费。中国大陆访问 GitHub 速度不稳但通常可用。
- **上手成本**: 三条命令能用（add/commit/push）；分支、合并冲突、rebase 要几个月。**对多数研究者，只用最简单的线性提交流程就够了。**
- **常见误用 / 坑**: ① 把数据（尤其含被试隐私的数据）提交进公开仓库——**一旦推送过，删掉文件也仍在历史里**；② 把 API 密钥、数据库口令写进代码提交上去；③ 提交信息全写 "update"，历史等于没有；④ 论文发表时给一个 GitHub 链接但不打 tag、不存档，仓库后续被改动或删除，链接失效（应配合 Zenodo 归档拿 DOI）。`evidence: [T02-S062]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S062]

### 36. 可重复流水线：依赖锁定、容器与工作流引擎（renv / conda / uv / Docker / Apptainer / Snakemake / Nextflow / targets）
- **档位**: 场景特化
- **环节**: 4 统计与可复现
- **一句话**: 把"我这台机器上装的是哪些版本""这几十个步骤按什么顺序跑"变成可交付的清单、镜像与流水线，别人才可能真的跑出同样的结果。
- **谁在用**: 计算量大的项目；要在集群上跑的人；生物信息（测序分析几乎必用工作流引擎）、气候与地学、大规模仿真；论文接受后需要提供可运行代码的人。
- **相对优劣**: **层次是递进的**——renv 为 R 项目锁定包版本（Posit 官方文档），conda/uv 管 Python 环境，Docker 打包整个操作系统层的依赖，Apptainer 是面向高性能计算集群的无 root 容器方案（很多超算不允许跑 Docker）。再往上，Snakemake 用 Python 语法定义规则、Nextflow 用 DSL 且在生信社群有大量现成流水线（nf-core）、targets 是 R 生态的对应物，它们提供增量重算、并行调度、失败恢复与日志。**多数论文做到"锁定版本"这一层就已经好过绝大多数同行**；对只有几个步骤的项目，工作流引擎属于过度工程。`evidence: [T02-S063, T02-S064, T02-S065, T02-S066, T02-S067]`
- **价格与获取**: renv、conda、uv、Apptainer、Snakemake、Nextflow、targets 均开源免费（Nextflow 背后的 Seqera 提供商业版）；Docker Desktop 对大企业收费、对个人与小机构有免费条款（**具体按其当时的许可条款，用前确认**）。中国大陆有镜像源加速。`evidence: [T02-S063, T02-S064, T02-S065, T02-S066, T02-S067]`
- **上手成本**: renv 一小时；Docker 一到两周（写 Dockerfile 是另一门手艺）；工作流引擎一到两周。
- **常见误用 / 坑**: ① 只写 `install.packages()` 清单不锁版本号，一年后包更新导致结果变化；② Docker 镜像里用 `latest` 标签，等于没锁；③ 镜像里塞进原始数据，体积巨大且可能违反数据共享协议；④ 建了容器/流水线但没写"怎么用它重跑分析"的说明，等于没交付；⑤ 流水线里硬编码路径与集群参数，换环境全废；⑥ 流水线依赖的外部工具版本不锁定——**流水线本身可复现但结果不可复现**；⑦ 论文里只给流水线代码不给参数配置文件。`evidence: [T02-S063, T02-S064, T02-S065, T02-S066, T02-S067]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S063, T02-S064, T02-S065, T02-S066, T02-S067]

### 39. OSF（Open Science Framework）
- **档位**: 必备
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 一个地方放下项目文件、预注册、材料、数据与预印本，并且预注册一旦提交就是带时间戳的只读记录。
- **谁在用**: 心理学、教育、社会学、神经科学、医学；做预注册与开放科学实践的人；越来越多的期刊要求提供 OSF 链接。
- **相对优劣**: 官方帮助文档说明预注册是把带时间戳的只读研究计划放到公共仓库，并提供多种模板（标准 OSF 模板、开放式模板、EEG/ERP、眼动、系统综述、社会心理学、定性研究、AsPredicted 八问模板、复制与二手数据模板），支持最长四年的禁运期（embargo），禁运期内可给审稿人匿名的只读链接。对 AsPredicted —— OSF 更完整、能挂材料与数据；输在填写成本高。`evidence: [T02-S073, T02-S075]`
- **价格与获取**: 由非营利的 Center for Open Science 运营，核心功能免费；存储有配额与机构版。中国大陆通常可访问（速度不稳）。`evidence: [T02-S073, T02-S074]`
- **上手成本**: 建项目十分钟；**写一份真正有约束力的预注册要一到两周**（因为它逼你把分析计划想清楚，这才是它的价值）。
- **常见误用 / 坑**: ① 预注册写得模糊到什么结果都能套（"我们将检验组间差异"），等于没注册；② 数据收完了才注册，且不说明；③ 把预注册当成不能偏离的合同——**偏离是允许的，但必须在论文里明确列出偏离项与理由**；④ 忘了在论文里给出预注册链接，审稿人无从核对；⑤ 禁运期结束后忘了检查，敏感内容自动转公开。`evidence: [T02-S073, T02-S074]`
- **last_updated: 2026-09** ；**(Decay risk: low)**

### 40. AsPredicted
- **档位**: 场景特化
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 八个问题、一页纸的轻量预注册，为"嫌 OSF 太重所以干脆不注册"的人降低门槛。

### 41. PROSPERO 与临床试验注册（ClinicalTrials.gov / ChiCTR / WHO ICTRP）
- **档位**: 场景特化
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 系统综述与临床试验各有自己的强制注册平台，不注册在很多期刊直接不收。
- **谁在用**: 做健康领域系统综述的人（PROSPERO）；做临床试验的人（ClinicalTrials.gov、中国临床试验注册中心 ChiCTR）。
- **相对优劣**: PROSPERO 由约克大学 CRD 运行，是健康研究系统综述的前瞻注册平台，注册前先查重能避免"三个组同时做同一个题"；ClinicalTrials.gov 由美国 NLM 运行，是 ICMJE 要求的注册平台之一，**试验必须在首例受试者入组前注册，否则多数医学期刊不收**。非健康领域的综述 PROSPERO 通常不收，可用 OSF Registries 或 INPLASY 一类替代。`evidence: [T02-S085, T02-S086, T02-S075]`
- **价格与获取**: 均免费。中国大陆可访问。ChiCTR 是 WHO ICTRP 认可的一级注册机构之一，中文项目常用。`evidence: [T02-S085, T02-S086]`
- **上手成本**: 半天填表；PROSPERO 审核有排队时间，**要提前规划**。
- **常见误用 / 坑**: ① 数据提取都做完了才补注册（回顾性注册），期刊会要求说明；② 注册版本与最终论文的纳排标准、结局指标不一致却不报告差异——**这是审稿人和读者最容易查到的硬伤**；③ 主要结局指标在注册后被悄悄换掉（outcome switching）；④ 以为注册号写进论文就完事，不更新注册记录的状态。`evidence: [T02-S085, T02-S086]`
- **last_updated: 2026-09** ；**(Decay risk: low)**

### 42. 注册报告（Registered Reports）
- **档位**: 场景特化
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 在收数据之前把方案投给期刊评审，通过后拿到"原则性接收"，之后无论结果显著与否都发表。
- **谁在用**: 心理学、神经科学、生医、部分社科；做复制研究与高风险验证性研究的人；已有两百家以上期刊提供这一格式。
- **相对优劣**: COS 官方说明注册报告是"预注册的方案先接受同行评审"的一种出版格式，通过后给出原则性接收（in principle acceptance），只要按方案执行就保证发表——**这是唯一从制度上消除发表偏倚的机制**，而普通预注册做不到。代价是周期长（第一阶段评审本身要几个月），且不是所有期刊都提供。`evidence: [T02-S074]`
- **价格与获取**: 随期刊，无额外费用；可在 COS 与相关社群维护的期刊清单里找哪些刊接受。`evidence: [T02-S074]`
- **上手成本**: 方案写作的质量要求高于普通投稿，第一次通常要一到两个月。
- **常见误用 / 坑**: ① 把"预注册"说成"注册报告"（**这是最典型的外行破绽之一**）；② 拿到原则性接收后偏离方案却不报告，接收承诺失效；③ 选了一本提供该格式但审稿周期极长的期刊，卡住整个项目时间线；④ 以为原则性接收等于第二阶段不会被要求修改。`evidence: [T02-S074]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S074]

### 43. Zenodo
- **档位**: 必备
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 给任何研究产出（数据、代码、幻灯片、预印本）一个 DOI 并长期保存，一键把 GitHub 仓库的某个版本存档成可引用对象。
- **谁在用**: 所有需要在论文里写"数据与代码见 DOI:..."的人；没有学科对口仓储时的兜底选择。
- **相对优劣**: 官方简介说明 Zenodo 2013 年上线，由 CERN 与 OpenAIRE 联合运营、获欧盟委员会资助，是覆盖全学科的通用仓储，引用信息传递给 DataCite。对 GitHub 链接 —— **Zenodo 给的是不可变的版本快照 + DOI，GitHub 链接随时会变或消失**；对学科仓储 —— Zenodo 通用但缺少学科元数据标准与领域内的可发现性。`evidence: [T02-S077]`
- **价格与获取**: 免费（有单次上传体积上限，超大数据集需另行申请）。中国大陆可访问。`evidence: [T02-S077]`
- **上手成本**: 二十分钟；GitHub 集成配置十分钟。
- **常见误用 / 坑**: ① 上传了但不写 README 与变量说明，数据等于不可用；② 上传含个人信息的原始数据而没做去标识化与合规审查（**这是不可逆的**）；③ 只存最终代码不存运行环境说明；④ 选了错误的许可证（或不选），别人法律上不敢用；⑤ 有对口学科仓储时仍扔进 Zenodo，导致领域内没人找得到。`evidence: [T02-S077, T02-S079]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S077]

### 44. 数据仓储的选择（Dryad / figshare / Harvard Dataverse / 学科仓储 / re3data）
- **档位**: 场景特化
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 先找有没有你这个学科的对口仓储（基因表达进 GEO、测序进 SRA、蛋白结构进 PDB、社科调查进 ICPSR/Dataverse），没有再用通用仓储兜底。
- **谁在用**: 所有被期刊或资助方要求共享数据的人。
- **相对优劣**: Dryad 是非营利数据出版平台，官方自述截至 2026 年托管超过 6.5 万份数据出版物、连接约 30 万名研究者与 2000 家期刊（口径：Dryad 官方 about 页，**平台自报**），采用会员/合作方资助的收费模式；figshare 属 Digital Science，很多机构有机构版；Harvard Dataverse 在社科强势。**re3data 是查"我这个学科该存哪"的目录**。学科仓储的优势是元数据标准与领域内可发现性，通用仓储的优势是什么都能收。`evidence: [T02-S078, T02-S087, T02-S079]`
- **价格与获取**: Dryad 对部分机构成员免费（费用由机构或期刊承担），非成员按其当时的数据发表费收取（**具体金额随时会变，投稿前查官方页**）；figshare 基础层免费；学科仓储多为公共资助免费。`evidence: [T02-S078, T02-S087]`
- **上手成本**: 通用仓储半天；学科仓储（如 GEO/SRA）的元数据提交要一到两周，**必须留出时间**。
- **常见误用 / 坑**: ① 论文接受后才开始准备数据提交，发现学科仓储的审核要几周，卡住发表；② 数据共享声明写"数据可向通讯作者索取"——这在很多期刊已不再被接受，且实证研究显示索取常无回应；③ 敏感数据直接公开而不是走受控访问（**FAIR 不等于 Open**，受控访问的数据一样可以是 FAIR 的）；④ 数据与论文里的变量名对不上，别人无法复现。`evidence: [T02-S078, T02-S079, T02-S087]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**

### 47. 持久标识符（DOI / ORCID / ROR / RRID）
- **档位**: 必备
- **环节**: 5 预注册、数据与代码共享
- **一句话**: 让"这篇文章""这个人""这个机构""这只抗体"在机器眼里唯一可辨，避免同名、改名与链接失效带来的归属丢失。
- **谁在用**: 所有投稿的人（ORCID 在很多期刊与资助方已是必填）；生医研究者（RRID 用于标识抗体、细胞系、模式生物、软件工具）。
- **相对优劣**: ORCID 是研究者的持久标识符（官方站 orcid.org），解决重名与改名；ROR 是机构标识符，解决"同一所大学有二十种英文写法"；DOI 解决对象定位；RRID 解决材料可追溯（**生医不可重复的根源常在材料而非统计，RRID 正是对这一点的回应**）。对"写清楚全名" —— 标识符是机器可读的，检索与统计才准。`evidence: [T02-S082, T02-S083]`
- **价格与获取**: ORCID、ROR 对个人免费；DOI 由仓储/出版商代为注册。中国大陆可访问。`evidence: [T02-S082, T02-S083]`
- **上手成本**: 注册 ORCID 十分钟；**维护成本被严重低估**——不定期更新的 ORCID 记录会缺一半成果。
- **常见误用 / 坑**: ① 注册了 ORCID 但从不授权期刊自动写入，档案长期空白；② 一个人有两个 ORCID（换邮箱重注册），成果被拆成两份；③ 投稿时机构名称与 ROR 记录不一致，影响机构统计；④ 生医论文不写细胞系/抗体的 RRID，导致材料无法追溯。`evidence: [T02-S082, T02-S083]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S082, T02-S083]

### 48. 期刊匹配与范围核对（JANE / Elsevier Journal Finder / Springer Nature Journal Suggester / WoS Manuscript Matcher）
- **档位**: 场景特化
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 把摘要粘进去，返回一批"发过类似文章"的期刊，用来缩小候选范围——但它给的是相似度，不是"这本刊会要你"。

- **相对优劣**: **JANE**（Erasmus MC 的 BioSemantics 组维护）免费、基于 PubMed，还能顺带找潜在审稿人；**出版商自己的 finder** 只推荐自家期刊，是明显的利益相关，但会给出开放获取费用与审稿周期的自报数据；**WoS Manuscript Matcher** 随 WoS 订阅。**共同短板**：它们只看主题相似度，不看你论文的强度、创新性与该刊当前的收稿偏好。`evidence: [T02-S098, T02-S099, T02-S100]`
- **价格与获取**: JANE 免费；出版商工具免费（但只覆盖自家）；Manuscript Matcher 需 WoS 订阅。中国大陆一般可访问。`evidence: [T02-S098, T02-S099, T02-S100]`
- **上手成本**: 十分钟。
- **常见误用 / 坑**: ① 完全依赖工具而不读目标期刊的 Aims & Scope 与最近三期目录——**范围不符是 desk reject 的头号原因**；② 用出版商工具时被推荐到该社旗下的"广撒网型"大刊而没意识到那是商业推荐；③ 忽略工具推荐里混进来的可疑期刊，没有再跑一遍可信度自查；④ 不看审稿周期与版面费就投，接受后才发现付不起。`evidence: [T02-S098, T02-S099, T02-S100, T02-S094]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**

### 49. CRediT 贡献者角色分类
- **档位**: 必备
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 用 14 个标准化角色写清"每位作者具体做了什么"，把署名争议从投稿前移到项目开始时解决。
- **谁在用**: 越来越多期刊在投稿系统里强制填写；多作者、跨机构、跨学科项目尤其需要。
- **相对优劣**: 官方站说明 CRediT 是"社群共有的 14 个贡献者角色分类法"，2022 年被批准为 ANSI/NISO Z39.104-2022 标准，其定位是**补充而非取代传统署名**（口径：NISO CRediT 官方站）。**关键区分**：ICMJE 的四条标准回答"谁能当作者"，CRediT 只回答"谁做了什么"——**把 CRediT 当署名标准用是典型的外行破绽**。`evidence: [T02-S084, T02-S002]`
- **价格与获取**: 免费的公开标准。`evidence: [T02-S084]`
- **上手成本**: 十五分钟读完 14 个角色的定义。
- **常见误用 / 坑**: ① 用 CRediT 给不符合作者资格的人挂名（"他做了 Resources 所以算作者"）——**资格由 ICMJE 或期刊政策决定**；② 到投稿当天才第一次讨论贡献分工，此时冲突已无法调和；③ 所有作者都勾选全部 14 项，等于没填；④ 忽略 CRediT 不覆盖"通讯作者""共同一作"这类中国语境下极其重要的位次概念——**那是期刊政策和单位规定的事，CRediT 不管**。`evidence: [T02-S084, T02-S002]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S084, T02-S002]

### 50. 查重（Crossref Similarity Check / iThenticate / Turnitin / 知网学术不端文献检测系统）
- **档位**: 必备
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 在编辑部替你查之前先自己查一遍文字重复，尤其是方法部分和自我重复。
- **谁在用**: 所有投稿的人（虽然多数是被动接受编辑部的检查）；中国大陆的学位论文必须过知网检测；期刊编辑与学位办。
- **相对优劣**: Crossref 官方说明 Similarity Check 由 Turnitin 的 iThenticate 驱动，**只对正在出版 DOI 内容的 Crossref 会员开放**，比对库含超过 7800 万条全文学术内容加互联网内容，产出的是"相似度分数 + 高亮匹配"，编辑必须自行判断是否构成抄袭（口径：Crossref 官方服务页）。**这句话是本条最重要的一句：工具给的是文本相似度，不是抄袭判定。** 知网的学术不端文献检测系统在中文学位论文场景是事实标准，比对库以中文文献与学位论文为主。`evidence: [T02-S088, T02-S089, T02-S090]`
- **价格与获取**: 作者个人通常**买不到也不需要买** iThenticate 的会员通道；很多中国高校为学位论文提供每人若干次的免费知网检测名额，先查研究生院通知。**慎用来路不明的"低价查重"服务——你的未发表稿件可能被收进对方的比对库。**`evidence: [T02-S088, T02-S090]`
- **上手成本**: 半小时读懂报告；**读懂"哪些匹配是正常的"比拿到分数重要得多**（参考文献、方法学标准表述、机构名称、量表条目都会被标红）。
- **常见误用 / 坑**: ① **把重复率当论文质量指标**——低重复率的论文可以毫无价值，高重复率的方法部分可能完全正当；② 为降重把通顺的句子改成不通顺的同义词堆砌（这正是 tortured phrases 的来源，反而会被可疑论文筛查工具抓到）；③ 忽略自我重复（一稿多投与切香肠式发表是独立的伦理问题，不是查重能解决的）；④ 把未发表稿件上传到第三方查重网站，稿件泄露；⑤ 以为图表和数据不查重就可以复用——图像完整性检查是另一套工具。`evidence: [T02-S088, T02-S090, T02-S093]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S088, T02-S089, T02-S090]

### 51. 图像完整性检查（Proofig / ImageTwin）
- **档位**: 新兴
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 自动扫描论文里的显微图、western blot 与照片，找出重复、拼接、旋转翻转复用以及与已发表图库的雷同。
- **谁在用**: 出版商与编辑部（两家官方页都列出多家大型出版社为客户）；机构诚信办公室；投稿前自查的通讯作者。
- **相对优劣**: 两家官方页自述的能力高度相似——检测单图内的克隆/编辑/删除/拼接、跨图重复（支持缩放旋转翻转与部分重叠）、与大规模已发表图库比对（Proofig 自报比对超过 1.55 亿张 PubMed 开放图像，ImageTwin 自报超过 1.6 亿张已发表图，**均为厂商自报，未经独立核实**）、以及 AI 生成图像检测。**共同的硬约束：工具输出的是"疑似"，判定必须由人做**——正当的图像复用（同一对照组、同一代表性视野）会被标红。`evidence: [T02-S091, T02-S092]`
- **价格与获取**: 商业订阅，主要卖给出版商与机构；个人作者可注册试用（**具体额度与价格按其当时页面**）。中国大陆可访问。`evidence: [T02-S091, T02-S092]`
- **上手成本**: 上传扫描十分钟；读懂报告并判断每一处标红要几小时。
- **常见误用 / 坑**: ① 把"零标红"当成清白证明（工具覆盖的图像类型有限，且比对库不含未发表与非开放内容）；② 把标红直接当成造假指控发到公开平台——**误报率不低，正当复用很常见**；③ 通讯作者不做投稿前自查，等编辑部查出来再解释，此时已进入学术诚信流程；④ 忽视"原始图像必须留存"这一根本要求——工具救不了拿不出原图的实验室。`evidence: [T02-S091, T02-S092, T02-S107]`
- **last_updated: 2026-09** ；**(Decay risk: high)**
- evidence: [T02-S091, T02-S092]

### 52. 报告规范核对清单（EQUATOR Network：PRISMA / CONSORT / STROBE / ARRIVE / COREQ 等）
- **档位**: 必备
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 按你这类研究对应的清单逐条核对，把"审稿人会问什么"提前变成写作提纲。
- **谁在用**: 所有做实证研究的人；医学与公卫是硬要求（很多期刊在投稿系统里要求上传填好的清单），社科与理工在快速普及。
- **相对优劣**: EQUATOR Network 是报告规范的总库，按研究类型索引（随机对照试验用 CONSORT、系统综述用 PRISMA、观察性研究用 STROBE、动物实验用 ARRIVE、定性研究用 COREQ/SRQR）。**相对"写完再对照清单查漏"，正确用法是写之前就拿清单当提纲**。`evidence: [T02-S101]`
- **价格与获取**: 全部免费公开；部分清单有中文译本。中国大陆可访问。`evidence: [T02-S101]`
- **上手成本**: 找到对的清单十分钟；第一次逐条填写半天。
- **常见误用 / 坑**: ① **引用已被取代的旧版本**（CONSORT 2025、SPIRIT 2025、PRISMA 2020、TRIPOD+AI 2024 都有新版，引旧版是最省力的外行识别器）；② 填了清单但正文里对应位置根本没写那件事，页码栏写"NA"；③ 把清单当成投稿时的形式材料，而不是设计阶段的工具；④ 用错清单（把队列研究套 CONSORT）。`evidence: [T02-S101]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S101]

### 53. 可疑论文与撤稿筛查（Problematic Paper Screener / Retraction Watch Database / PubPeer）
- **档位**: 场景特化
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 定稿前把参考文献跑一遍，确认你没有引用已撤稿、已被公开质疑或明显是论文工厂产物的文献。
- **谁在用**: 所有写综述与引言的人；审稿人；编辑；做证据合成的团队。
- **相对优劣**: **Problematic Paper Screener**（Guillaume Cabanac 等在 IRIT 维护，免费）用一组检测器扫描文献：tortured phrases（把标准术语改写成怪异同义词的痕迹）、计算机生成论文、引用了撤稿文献的论文（Feet of Clay）等，数据来自 Crossref、Dimensions、PubMed、PubPeer；**Retraction Watch Database** 回答"这个 DOI 是否被撤稿或更正"；**PubPeer** 回答"有没有人公开质疑过它、质疑落在哪张图"。**三者的定位都是给线索而不是下判定**：PubPeer 上的图像类指控质量通常较高，但方法与解释类的讨论常成为立场之争，被质疑者往往不回应，形成单方记录。`evidence: [T02-S093, T02-S105, T02-S106]`
- **价格与获取**: 三者均免费。中国大陆一般可访问。`evidence: [T02-S093, T02-S105, T02-S106]`
- **上手成本**: 单篇查询五分钟；批量核对参考文献要写一点脚本（Crossref API 已包含撤稿数据）。
- **常见误用 / 坑**: ① 把"数据库里没记录"当成"这篇没问题"——**没记录只说明没被记录**；② 把 PubPeer 上的质疑当成已成立的造假结论并公开转述，可能构成诽谤；③ 引用了撤稿论文却在正文里当正常证据用（**引用撤稿文献必须标注并说明为什么仍要引**）；④ 只查自己领域的高引论文，不查综述里那些"顺手引一下"的边角文献。`evidence: [T02-S093, T02-S105, T02-S106]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S093, T02-S105, T02-S106]

### 54. 期刊可信度自查（Think. Check. Submit. / DOAJ / COPE 成员查询 / 中科院预警名单 / 中国科协目录）
- **档位**: 必备
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 在投出去之前，用一张正向核查清单确认这本刊的编辑部、评审流程、收费与索引都说得清楚——而不是去找一份"黑名单"。
- **谁在用**: 所有投稿的人，尤其是收到主动约稿邮件、或被"快速发表"吸引的作者；导师审核学生的投稿目标。
- **相对优劣**: **Think. Check. Submit.** 是由 ALPSP、COPE、DOAJ、ISSN、LIBER、OAPEN、OASPA、STM、UKSG 等联合发起的跨行业倡议，给的是一张自查清单（是否认识这本刊、能否轻易找到并联系出版方、评审流程是否透明、文章是否被可检索的数据库索引、费用是否说清、许可与版权政策是否公开、出版方是否是 COPE/DOAJ/OASPA 一类组织的成员），**它明确不给"是否掠夺性"的判定**。**DOAJ** 回答"这本 OA 刊是否通过了编辑透明度审核"，但不覆盖订阅制刊、也不判质量。**中国侧**：中科院文献情报中心的国际期刊预警名单仍在运行；但同一中心的期刊分区表已发布公告——"自2026年起，中国科学院文献情报中心将不再更新与发布期刊分区表"（口径：分区表官网公告原文）。`evidence: [T02-S094, T02-S095, T02-S096, T02-S097]`
- **价格与获取**: Think.Check.Submit. 与 DOAJ 免费；预警名单免费公开；商业的 Cabells Predatory Reports 收费且其判据本身受到学术批评。中国大陆可访问。`evidence: [T02-S094, T02-S095, T02-S096, T02-S097]`
- **上手成本**: 一小时走完清单。
- **常见误用 / 坑**: ① **把"不在黑名单上"当成安全**——正向核查清单才是方法，黑名单永远滞后；② 把商业分区（JCR 分区 / 中科院分区）当成期刊质量的定义，而不是一个有特定口径的排序；③ 说"1 区"却不说是哪一套、哪一年、大类还是小类；④ **继续引用或依赖已停更的分区表数据**，或误信第三方冒名发布的"最新分区"；⑤ 被"3 天录用、7 天见刊"的邮件说服（这类中介与包发表服务在中国属于明文禁止的科研失信行为，只应作为识别与避开的对象，不要访问其页面）；⑥ 只看影响因子不看这本刊是否还在 WoS 收录（期刊会被剔除）。`evidence: [T02-S094, T02-S095, T02-S096, T02-S097, T02-S009]`
- **last_updated: 2026-09** ；**(Decay risk: medium)**
- evidence: [T02-S094, T02-S095, T02-S096, T02-S097]

### 55. 投稿与评审系统（Editorial Manager / ScholarOne Manuscripts / OJS / 各社自建系统）
- **档位**: 必备
- **环节**: 6 投稿、评审与合规检查
- **一句话**: 你和编辑部之间唯一的正式通道，也是最容易在最后一天因为格式与附件问题卡住的地方。
- **谁在用**: 所有投稿的人与所有审稿人。Editorial Manager（Aries Systems，属 Elsevier）与 ScholarOne（Clarivate）覆盖大量期刊；OJS 是 Public Knowledge Project 的开源系统，被大量中小型与非营利期刊使用（在中国也有不少期刊在用）。
- **相对优劣**: 三者的差别对作者而言主要是界面与必填项，不是能力。**真正的差别在于：这些系统会记录你的所有行为**——投稿时间、修改次数、是否回应过、推荐与回避的审稿人。OJS 的价值在于让没有商业系统预算的期刊也能规范运行。`evidence: [T02-S102, T02-S103, T02-S104]`
- **价格与获取**: 对作者与审稿人免费；系统由期刊购买或自建。中国大陆可访问（部分系统上传大文件较慢）。`evidence: [T02-S102, T02-S103, T02-S104]`
- **上手成本**: 第一次投稿要留出**整整一天**（分文件上传、图表单独文件、Highlights、Cover letter、推荐审稿人、伦理声明、数据可用性声明、CRediT、利益冲突、ORCID 全都要填）。
- **常见误用 / 坑**: ① 以为提交后就完成了——多数系统需要通讯作者再点一次"Approve Submission"，不点就一直躺着；② Cover letter 写成摘要复述，而不是回答"为什么是这本刊、为什么现在、有什么新东西"；③ 推荐审稿人填了直接合作者或同单位的人，被系统或编辑判定利益冲突；④ 双盲期刊里忘了清理文件元数据与正文里的自我指认（"我们此前的工作[12]"加上机构名）；⑤ 返修时把带修订标记的稿子和干净稿传反；⑥ 审稿邀请一直不回应，影响自己的编辑部记录。`evidence: [T02-S102, T02-S103, T02-S104, T02-S107]`
- **last_updated: 2026-09** ；**(Decay risk: low)**
- evidence: [T02-S102, T02-S103, T02-S104]


## 7. 生成式 AI 相关工具

> 这一节的排列方式与前六节不同：**先看政策边界，再看工具**。因为在这一行，能不能用某个 AI 工具、用了要不要说，是由期刊、出版商、资助方与所在国监管共同决定的，而不是由工具好不好用决定的。

### 7.0 当前政策边界（各主要出版方与监管方，2026-09 查证）

| 主体 | AI 能否当作者 | 作者侧披露要求 | 审稿人侧 | 图像 |
|------|--------------|---------------|---------|------|
| **ICMJE**（2026-01 版） | 不能 | 有独立的第五节「Use of Artificial Intelligence in Publishing」，分为作者、审稿人、编辑三小节 | 单列条款 | 见原文 |
| **Springer Nature** | 不能——「LLMs such as ChatGPT cannot take accountability and do not meet authorship criteria」，使用须写进 Methods 或致谢 | 须透明声明；**仅用于语法与可读性的润色不需声明** | **审稿人不得把稿件上传进生成式 AI 工具**；若 AI 参与了评审，须在评审报告中声明 | 生成式 AI 图像原则上禁止，除非符合特定例外并明确标注为「AI-generated」 |
| **Elsevier** | 不能——「Authorship implies responsibilities and tasks that can only be attributed to and performed by humans」 | 须写声明段落，注明工具名、用途并确认已复核输出；**基础拼写语法检查不需披露** | 「Reviewers should not upload a submitted manuscript or any part of it into an AI tool」；实质性使用须披露 | 解释性示意图可用并须在图注披露；数据可视化仅当可由底层数据复现；**显微、扫描等一手研究图像不允许** |
| **Wiley** | 不能——AI「cannot fulfil the role of an author and must not be listed as one on an article」 | 投稿时须披露实质性编辑、开发或翻译用途；纯拼写语法不需披露 | 「editors and peer reviewers are not permitted to upload manuscripts (or any parts of manuscripts including figures and tables) into AI Technology」；编辑与审稿人可用 AI 改善表达但须告知处理编辑 | 见原文 |
| **中国科技部**《负责任研究行为规范指引（2023）》 | 不能——「生成式人工智能不得列为成果共同完成人。应在研究方法或附录等相关位置披露使用生成式人工智能的主要方式和细节」 | 「使用生成式人工智能生成的内容，特别是涉及事实和观点等关键内容的，应明确标注并说明其生成过程」；期刊「应要求作者披露是否使用生成式人工智能，说明具体的软件名称、版本和使用时间」 | 「在评议活动中使用生成式人工智能的，应事先征得评议活动组织者同意，操作中应防止泄漏评议内容」 | 「依规合理使用生成式人工智能处理文字、数据或学术图像，防范伪造、篡改数据等风险」 |

**两条中国侧的硬红线，值得单独抄一遍**：
- 「不得抄袭、买卖、代写申报材料，**不得使用生成式人工智能直接生成申报材料**」——写基金本子的人尤其注意。
- 「**不得直接使用未经核实的由生成式人工智能生成的参考文献**」；且「对其他作者已标注为人工智能生成内容的，一般不应作为原始文献引用」。

`evidence: [T02-S002, T02-S003, T02-S109, T02-S110, T02-S111, T02-S112, T02-S113]`

**四条政策的共同结构**（可以当成默认假设，但**投稿前仍必须读目标期刊当年的作者须知**）：
1. AI 不能当作者，责任不可转移；
2. 实质性使用要披露，纯语法拼写润色一般不用；
3. **审稿人不得把稿件传进 AI 工具**——这一条在四家里最一致，也是最容易被违反的；
4. 一手研究图像不能由 AI 生成。
`evidence: [T02-S002, T02-S109, T02-S110, T02-S111, T02-S113]`

### 56. AI 文献检索与综述辅助（Elicit / Consensus / Undermind / SciSpace / NotebookLM）
- **档位**: 新兴
- **环节**: 7 生成式 AI 相关工具
- **一句话**: 用自然语言提问，返回带引用的答案并把多篇论文的关键字段抽成表格，用来快速摸清陌生领域或做系统综述的初筛。
- **谁在用**: 做初步文献调研的研究生；做系统综述初筛的团队；跨学科读者。
- **相对优劣**: **Elicit** 官方自述可对超过 1.25 亿篇论文做检索、摘要、表格化数据提取与系统综述式的筛选，并自报 95% 检索查全、97% 摘要筛选、99% 全文筛选、96% 抽取的指标（口径：Elicit 官方站，**厂商自报、未经独立核实，且未说明测评集与口径**）。**Consensus** 官方博客说明其聚合 Semantic Scholar、OpenAlex 与自有学术爬虫，覆盖两亿篇量级，并**主动承认局限**：AI 模型可能误读来源、即使引用正确也可能把真实论文总结错。**Undermind** 走的是慢速深度检索代理路线。**NotebookLM** 的差异在于它只在你自己上传的资料范围内作答，从而大幅降低编造，但也因此不承担检索发现的职责。**共同短板：全都不能作为系统综述的可复现检索式来源。**`evidence: [T02-S114, T02-S115, T02-S116, T02-S120, T02-S121]`
- **价格与获取**: 均为免费层 + 订阅制，价格与额度变动频繁（**用前自行核对官方定价页**）。中国大陆：NotebookLM 依赖 Google 服务不可直接访问；其余几家一般可访问但需注意稿件与未发表内容的上传风险。`evidence: [T02-S114, T02-S115, T02-S116, T02-S120, T02-S121]`
- **上手成本**: 十五分钟。**难的是养成"每一条都点进原文核对"的习惯。**
- **常见误用 / 坑**: ① **把生成的参考文献直接抄进论文**——中国科技部指引明文禁止「直接使用未经核实的由生成式人工智能生成的参考文献」，而国际期刊一旦查出虚构引用通常按学术不端处理；② 把 AI 的摘要当成论文结论（Consensus 自己承认会"summarize real papers incorrectly"）；③ 用它替代系统检索却在方法学部分写成"检索了 XX 数据库"，属于虚假陈述；④ 把二手综述当一手证据引用；⑤ 把未发表稿件或含被试信息的材料上传，违反保密与数据合规。`evidence: [T02-S113, T02-S114, T02-S115]`

### 57. AI 写作与润色（Paperpal / Writefull / 通用大模型）
- **档位**: 新兴
- **环节**: 7 生成式 AI 相关工具
- **一句话**: 用学术语料训练的写作助手改句子、查语言、给结构建议，专门针对非英语母语作者的投稿场景。
- **谁在用**: 中文母语作者写英文稿；返修阶段压缩篇幅、改写审稿人指出的段落。
- **相对优劣**: **Paperpal**（Cactus Communications）与 **Writefull**（Digital Science）都定位为学术写作专用，相对通用大模型的优势是不会把学术表达改成通俗表达、并提供投稿前的语言与格式检查；**通用大模型**（ChatGPT / Claude / Gemini 等）灵活得多，但改写幅度不可控，更容易越过"润色"与"代写"的界线。**判断边界的实用标准不是工具名字，而是：改完之后，这些句子表达的是不是仍然只是你自己想出来的意思。** 三家出版商政策一致地把"纯拼写语法"划为不需披露、把实质性改写划为需披露。`evidence: [T02-S117, T02-S118, T02-S109, T02-S110, T02-S111]`
- **价格与获取**: 免费层 + 订阅制；Paperpal 有面向中国大陆的独立站点。通用大模型的可及性因产品而异，**大陆用户使用境外模型时须自行确认合规与数据跨境问题**。`evidence: [T02-S117, T02-S118]`
- **上手成本**: 十分钟。
- **常见误用 / 坑**: ① 让 AI 直接写讨论部分，产出通顺但空洞、且把不确定说成确定的段落（**这是最容易被有经验的审稿人识别出来的失效模式**）；② 让 AI 改写别人的段落以规避查重——这是隐性抄袭，且改写产生的怪异同义词正是 tortured phrases 检测器的目标；③ 该披露不披露，事后被追溯；④ 用 AI 生成基金申报材料，**在中国属于指引明文禁止的行为**；⑤ 把整篇未发表稿件贴进公开聊天界面，违反与合作方、期刊的保密约定。`evidence: [T02-S113, T02-S109, T02-S093]`
- **last_updated: 2026-09** ；**(Decay risk: high)**

### 58. AI 代码与统计辅助（GitHub Copilot / Claude / 各类编程助手）
- **档位**: 新兴
- **环节**: 7 生成式 AI 相关工具
- **一句话**: 把"我想做什么"翻译成 R/Python 代码，帮不会编程的研究者跨过语法门槛，也帮会编程的人少写样板代码。
- **谁在用**: 写分析脚本的所有人；数据清洗、绘图、批处理这类重复劳动最受益。
- **相对优劣**: 相对搜索加复制粘贴 —— 快得多、能针对你的变量名生成代码；输在**它不知道你的模型假设是否成立**。相对请教统计顾问 —— 便宜、随时可用；输在它会用同样自信的语气给出正确与错误的建议。**代码辅助是本节中风险最低、收益最直接的一类**，因为代码可以运行、可以对拍、可以用模拟数据验证——这是文献综述辅助和写作辅助都不具备的自纠错通道。`evidence: [T02-S119]`
- **价格与获取**: Copilot 对经认证的学生与教育工作者有免费通道（**具体资格与额度按其当时页面**），其余为订阅制。中国大陆可及性因产品而异。`evidence: [T02-S119]`
- **上手成本**: 十分钟；**但用它写统计分析的前提是你自己看得懂它写了什么**。
- **常见误用 / 坑**: ① 让它选统计方法——它会给出一个常见方法而不是适合你数据结构的方法；② 生成的代码能跑但静默做了错误的事（默认删除缺失值、把因子当数值、错误的分组）；③ 把含真实被试数据的片段贴进去；④ 生成的代码引用了不存在的函数或参数（在小众包里尤其常见）；⑤ **论文里不说明代码是 AI 辅助生成的**——各出版方对代码的披露要求尚不统一，稳妥做法是在数据与代码可用性声明里写一句。`evidence: [T02-S119, T02-S109, T02-S113]`
- **last_updated: 2026-09** ；**(Decay risk: high)**

### 59. AI 审稿辅助（以及为什么这一类基本不能用）
- **档位**: 新兴
- **环节**: 7 生成式 AI 相关工具
- **一句话**: 市面上有把稿件喂进模型自动生成评审意见的工具，但**四家主要出版方的现行政策在这一点上高度一致：审稿人不得把稿件上传进生成式 AI 工具**。
- **谁在用**: 不该用的人在用。审稿任务过载是真实问题，但目前没有一条合规的捷径。
- **相对优劣**: Elsevier：「Reviewers should not upload a submitted manuscript or any part of it into an AI tool」；Wiley：「editors and peer reviewers are not permitted to upload manuscripts (or any parts of manuscripts including figures and tables) into AI Technology」，理由是 AI 工具「may store or reuse input data for training or other purposes」，会破坏评审保密性、作者与审稿人隐私以及版权；Springer Nature：审稿人不得上传稿件，若 AI 参与评估须在评审报告中透明声明。中国科技部指引：「在评议活动中使用生成式人工智能的，应事先征得评议活动组织者同意，操作中应防止泄漏评议内容，如发生信息泄漏应及时采取必要补救措施」——**注意这是"须事先获同意"而不是"一律禁止"，与三家出版商的措辞不同**。`evidence: [T02-S109, T02-S110, T02-S111, T02-S113]`
- **价格与获取**: 不适用。**合规的替代做法**：用 AI 润色你自己已经写完的评审意见的英文表达（Wiley 明确允许编辑与审稿人用 AI 改善表达但须告知处理编辑），而不是让 AI 读稿件。`evidence: [T02-S111, T02-S110]`
- **上手成本**: 不适用。
- **常见误用 / 坑**: ① 把稿件贴进聊天界面"让它帮我列几条意见"——**这一步本身就已经违规**，无论后面怎么改写；② 以为"我用的是本地模型所以不算"——多数政策的措辞是"上传进 AI 工具"，本地部署的边界尚不清晰，稳妥做法是先问处理编辑；③ 交出一份泛泛而谈、抓不住具体段落的评审意见（这是 AI 生成评审最典型的痕迹，编辑看得出来）；④ 忽视自己单位与资助方另有更严格的规定。`evidence: [T02-S109, T02-S110, T02-S111, T02-S113]`
- **last_updated: 2026-09** ；**(Decay risk: high)**
- evidence: [T02-S109, T02-S110, T02-S111, T02-S113]

### 7.9 这一类工具的四种已知失效模式（务必逐条对照）

1. **编造引用（hallucinated citations）**：生成看起来完全正常的作者、年份、期刊与 DOI，但文献不存在，或 DOI 指向另一篇文章。**这是目前后果最严重的一种**——中国科技部指引明文要求「不得直接使用未经核实的由生成式人工智能生成的参考文献」，国际期刊查出后通常进入学术不端流程。**唯一可靠的对策是逐条点开 DOI 核对**，不是"多问一次模型"。`evidence: [T02-S113]`
2. **把二手当一手**：模型把综述、评论、教科书甚至另一个模型的输出当成原始研究来引述，导致你论文里的"原始证据"其实是三手转述。中国科技部指引另有一条针对性规定：「对其他作者已标注为人工智能生成内容的，一般不应作为原始文献引用，确需引用的应加以说明」。`evidence: [T02-S113]`
3. **隐性抄袭**：为规避查重让模型改写他人段落，或模型直接复现训练语料里的句式与论证结构。改写产生的怪异同义词（tortured phrases）本身已经成为可疑论文筛查工具的检测目标——**降重和反检测是同一个动作的两面**。`evidence: [T02-S093, T02-S090]`
4. **把不确定说成确定**：模型倾向于生成语气笃定、结构完整的段落，抹掉原研究里的限定条件、样本局限与相反证据。Consensus 官方博客承认 AI「可能误读来源」、即使引用正确也可能把真实论文总结错。**这类错误最难被发现，因为读起来完全像一段好的学术写作。**`evidence: [T02-S115]`

> **关于 AI 生成内容检测工具**（Turnitin 的 AI 写作检测、GPTZero 之类）：这类工具的假阳性问题在学界有持续争议，**对非英语母语作者的误判风险是被反复提出的具体担忧**。本清单不推荐把任何检测分数当作判定依据；出版方的政策路径是要求作者主动披露，而不是靠检测。`evidence: [T02-S002, T02-S109, T02-S110]`

## 选型决策树

### 第 0 个问题（必须先问）：**你所在机构订阅了什么？**

这一行的工具可及性由机构订阅决定，个人偏好排第二。在做任何选择之前，先花一小时去图书馆网页（或问学科馆员）查清楚这五件事：

1. **引文数据库**：有没有 Web of Science？买了哪几个版本（SCIE / SSCI / AHCI / ESCI / CPCI / BKCI）？回溯年限到哪一年？有没有 Scopus？`evidence: [T02-S008, T02-S004]`
2. **学科库**：Embase / PsycINFO / ERIC / IEEE Xplore / Cochrane Library 有哪些？——**这直接决定你的系统综述能不能达到方法学标准。**`evidence: [T02-S011]`
3. **软件授权**：EndNote、NoteExpress、SPSS、Stata、MATLAB、Microsoft 365、Grammarly 的校园授权。**很多人自掏腰包买了才发现学校有。**`evidence: [T02-S028, T02-S035, T02-S053]`
4. **系统综述平台**：Covidence / Rayyan 的机构订阅。`evidence: [T02-S032, T02-S031]`
5. **查重与图像检查**：学位论文的知网检测名额；期刊侧的 iThenticate 你个人是买不到的。`evidence: [T02-S090, T02-S088]`

只有当上述某一项**没有**订阅时，开源与免费替代才成为第一选择——不是因为它们更差，而是因为在有订阅的环境里，与合作者和审稿人的沟通成本比工具本身重要。

### 分叉 A：**做系统综述 / meta 分析**

- **必用**：至少两个综合库（WoS + Scopus）+ 至少一个学科库（医学加 Embase 与 Cochrane CENTRAL）→ 检索式转换与去重（Polyglot / Deduplicator）→ 双人盲筛平台（Rayyan 或 Covidence）→ 前瞻注册（PROSPERO，非健康领域用 OSF Registries）→ 报告清单（PRISMA 2020）→ 合并分析（metafor 或 RevMan）。`evidence: [T02-S011, T02-S031, T02-S032, T02-S085, T02-S101, T02-S060]`
- **为什么**：这条链上的每一环都会被方法学审稿人逐条查——检了哪些库、检索式原文、去重方式、筛选一致性、注册号与偏差说明、清单页码。
- **什么条件下换**：**没有 Covidence 机构订阅 → 用 Rayyan 免费层**（注意同时最多 3 个进行中的综述的限制）；**做的是范围综述（scoping review）→ 换 PRISMA-ScR 清单**；**非健康领域 → PROSPERO 通常不收，改用 OSF Registries**。`evidence: [T02-S031, T02-S085, T02-S075]`
- **不要做**：不要用 Connected Papers 一类的图谱工具代替系统检索（不可复现、不可穷尽）；不要用 AI 文献工具生成的检索结果冒充数据库检索。`evidence: [T02-S015, T02-S114]`

### 分叉 B：**做实验研究（自己收数据）**

- **必用**：功效分析与样本量论证（G*Power，复杂设计用模拟）→ 预注册（OSF；嫌重就 AsPredicted）→ 方案发布（protocols.io，湿实验加 ELN）→ 分析环境（R 或 Python）→ 可重复文稿（Quarto）→ 版本管理（Git）→ 数据与代码存档（学科仓储优先，兜底 Zenodo）→ 报告清单（CONSORT 2025 / ARRIVE 2.0 / STROBE 按类型选）。`evidence: [T02-S057, T02-S073, T02-S080, T02-S050, T02-S046, T02-S062, T02-S077, T02-S101]`
- **为什么**：实验研究的可信度几乎全部取决于「数据看到之前做了什么决定」，而这一串工具就是把那些决定固定下来的手段。
- **什么条件下换**：**高风险、可能出零结果、且领域重视复制 → 直接走注册报告（Registered Reports），拿原则性接收**；`evidence: [T02-S074]` **实验室全员不会编程 → JASP / jamovi + SPSS 语法窗口**，但必须保存 syntax 文件；`evidence: [T02-S055, T02-S053]` **多层结构或小样本 → 从 lme4 换到 brms/Stan**。`evidence: [T02-S059]`

### 分叉 C：**做二手数据分析 / 观察性研究**

- **必用**：因果图（DAGitty）确定调整集 → 数据来源与版本记录 → 分析环境（R / Stata / Python）→ 依赖锁定（renv / conda）→ 敏感性分析与规格曲线 → 报告清单（STROBE）→ 代码存档。`evidence: [T02-S058, T02-S054, T02-S063, T02-S101, T02-S062]`
- **为什么**：二手数据分析的研究者自由度最高（谁都能反复跑不同规格直到显著），所以**"我预先声明了要控制哪些变量、为什么"** 是它唯一的护身符。
- **什么条件下换**：**做面板数据与政策评估 → Stata 的 do 文件是学科通用语言，别为了开源硬转 R**；`evidence: [T02-S054]` **数据不能公开（隐私或协议限制）→ 走受控访问仓储而不是不共享；FAIR 不等于 Open**；`evidence: [T02-S079]` **数据量到需要集群 → 加工作流引擎与容器**。`evidence: [T02-S066, T02-S065]`

### 分叉 D：**写基金标书**

- **必用**：资助方官方指南原文（NSFC《项目指南》与申请须知 / NIH Grants Policy Statement）→ 文献检索（查这个方向被谁资助过：Dimensions / Lens）→ 参考文献管理（Zotero / EndNote）→ 数据管理计划（DMPTool，如果资助方要）→ 图表（示意图与技术路线图）→ ORCID 与机构 ROR。`evidence: [T02-S023, T02-S024, T02-S001, T02-S081, T02-S082, T02-S083]`
- **为什么**：本子的形式审查往往比学术评审更容易致命（格式、字数、附件、签章、时间节点）。
- **硬红线**：**中国科技部《负责任研究行为规范指引（2023）》明文写着「不得抄袭、买卖、代写申报材料，不得使用生成式人工智能直接生成申报材料」**——这一条在标书场景优先于任何工具便利性。`evidence: [T02-S113]`
- **什么条件下换**：**申请欧美资助 → 数据管理计划与数据共享条款是实质性评分项，用 DMPTool 的官方模板**；`evidence: [T02-S081]` **本子里要引用自己的成果 → 先跑一遍撤稿数据库，别让一条撤稿引用毁掉可信度**。`evidence: [T02-S105]`

### 分叉 E：**应对返修（major / minor revision）**

- **必用**：逐条回复表（审稿意见 → 我们的回应 → 修改位置的页码行号）→ 版本比对生成标记稿（latexdiff 或 Word 比较文档）→ 干净稿 + 标记稿两份 → 补充分析（保留代码）→ 重新跑一遍报告清单 → 投稿系统上传。`evidence: [T02-S042, T02-S048, T02-S101, T02-S102]`
- **为什么**：返修阶段审稿人的时间极其有限，**你让他找不到你改在哪里，他就会再提一轮**。
- **什么条件下换**：**审稿人要求补做统计（如功效分析、敏感性分析）→ 补做并把代码放进公开仓库，比在回复里辩解有效得多**；`evidence: [T02-S062]` **不同意某条意见 → 必须写明理由，不能沉默**；**"拒稿但鼓励重投" → 形式上已经是拒稿，按新投稿准备，不要按返修准备**。
- **不要做**：不要让 AI 生成回复表的实质内容——它会把不确定说成确定，而审稿人正是最有能力发现这一点的读者。`evidence: [T02-S115]`

## 避坑清单

1. **把某个数据库的收录范围当成全部文献。** Web of Science 不收多数中文期刊、大部分预印本，书籍覆盖有限；PubMed 不覆盖心理学与教育学；Google Scholar 收录范围根本不公开。**"我搜了没有" 不等于 "没人做过"。**`evidence: [T02-S008, T02-S007, T02-S017]`
2. **把「学校能打开 Web of Science」当成「订了全部内容」。** 版本（SCIE/SSCI/AHCI/ESCI/CPCI/BKCI）与回溯年限是分开卖的，你可能整段年份检不到却毫无察觉。`evidence: [T02-S008]`
3. **用错引文样式导致格式退回。** CSL 样式库与 EndNote output style 都滞后于期刊的最新投稿指南——**最终必须对照目标期刊当年的 Guide for Authors 逐条核**，模板不管字数、图表上限、结构化摘要这些实质要求。`evidence: [T02-S030, T02-S027]`
4. **把 AI 生成的参考文献直接投出去。** 中国科技部指引明文禁止「直接使用未经核实的由生成式人工智能生成的参考文献」；国际期刊查出虚构引用通常按学术不端处理。**对策只有一个：逐条点开 DOI 核对。**`evidence: [T02-S113]`
5. **把查重率当质量指标。** Crossref 官方说明白：工具产出的是相似度分数与高亮匹配，编辑必须自行判断是否构成抄袭。低重复率的论文可以毫无价值；方法部分的高重复可能完全正当。**为降重把通顺句子改成同义词堆砌，反而会被 tortured phrases 检测器抓到。**`evidence: [T02-S088, T02-S093]`
6. **把商业分区当成期刊质量的定义。** JCR 分区与中科院分区表是两套不同体系；说「1 区」不说哪一套、哪一年、大类还是小类，是典型的外行破绽。更要紧的是：**中科院文献情报中心已公告「自2026年起……将不再更新与发布期刊分区表」**——继续引用停更数据、或误信第三方冒名发布的"最新分区"，是当下最新鲜的一个坑。`evidence: [T02-S096]`
7. **靠黑名单判断期刊，而不是靠正向核查清单。** Think. Check. Submit. 明确只给自查清单不给"是否掠夺性"的判定；DOAJ 只审开放获取刊的编辑透明度、不判质量、不覆盖订阅刊。**黑名单永远滞后，清单才是方法。**（承诺"保证发表 / 保证过审"的中介与"包发表"服务，在中国属于明文禁止的科研失信行为，只应作为识别与避开的对象。）`evidence: [T02-S094, T02-S095]`
8. **审稿时把稿件贴进 AI 工具。** Elsevier、Wiley、Springer Nature 三家现行政策在这一点上高度一致地禁止；理由是 AI 工具可能存储或复用输入数据，破坏评审保密性、作者隐私与版权。**这一步本身就已经违规，无论后面怎么改写输出。**`evidence: [T02-S109, T02-S110, T02-S111]`
9. **把 CRediT 当署名标准用。** CRediT（ANSI/NISO Z39.104-2022）只描述谁做了什么；**谁能当作者由 ICMJE 四条标准或期刊政策决定**。用「他做了 Resources 所以算作者」来挂名，是把两件事混为一谈。`evidence: [T02-S084, T02-S002]`
10. **在 notebook 里乱序执行单元格，然后以为分析可重复。** 这是可重复性最常见的单一失效来源。**发布前必须"清空内核 + 从头跑一遍"**；再配合 renv/conda 锁定版本，否则一年后包更新就得到不同数字。`evidence: [T02-S068, T02-S063]`
11. **用事后功效（post hoc power）回答"我的样本量够不够"。** 用观察到的效应量反算功效是无信息量的，方法学审稿人见到会直接批。功效分析必须在收数据之前做，且用领域内的最小有意义效应而不是 Cohen 的"中等效应"。`evidence: [T02-S057]`
12. **把预印本平台的筛查当质量把关，或引用预印本时不标版本。** bioRxiv/medRxiv 官方声明只做剽窃、非科学内容、不当类型与公共健康风险的筛查，每篇都带「未经同行评审认证」的声明，平台不对方法、假设、结论作任何背书。预印本会改版，**v1 和 v4 可能结论不同**。`evidence: [T02-S013, T02-S014]`

## Phase 2 提炼提示

### (a) 工具选择背后暗含的心智模型

1. **"可审计" 才是这一行工具的真正卖点，而不是 "高效"。** 从预注册、双人盲筛、修订标记、依赖锁定到 CRediT，绝大多数被行业接受的工具都在做同一件事：**把一个原本发生在脑子里、事后无法核查的决定，变成一条带时间戳、别人能查的记录**。选工具时问「它替我留下了什么可核查的痕迹」，比问「它替我省了多少时间」更接近这一行的判断标准。
2. **透明度是可审计性的前提，不是质量的替代品。** 预注册的研究可以是烂研究，开放数据的论文可以是错论文。工具能证明你没有事后编故事，但证明不了你的问题值得问。**这两件事被系统性地混淆**——尤其在把开放科学当成评价指标的场合。
3. **可及性由机构订阅决定，个人偏好排第二。** 这一行与其他行业最大的结构性差别：你能用什么，很大程度上不是你选的。这也解释了为什么开源工具（Zotero、R、OSF、Quarto）在这一行的采纳率远高于一般行业——它们抹平了机构之间的资源差距。
4. **工具给线索，人下判定。** 查重、图像完整性、可疑论文筛查、引用分类，四类工具的官方文档都在说同一句话的不同版本：输出是"疑似"不是"判定"。**把工具输出当结论，是这一行最常见的越界。**
5. **默认值是研究者自由度的藏身处。** SPSS 的缺失值处理、Zotero 抓来的题录字段、Docker 的 `latest` 标签、贝叶斯软件的默认先验——**每一个你没有主动设定的参数，都是一个别人无法复现你结果的理由。**

### (b) 近 12-24 个月真正改变了工作方式的变化（不是「又出了一个新工具」）

1. **生成式 AI 的政策边界从「模糊」收敛成「四条几乎一致的规则」。** ICMJE 2026 年 1 月版把 AI 单列为第五节（作者 / 审稿人 / 编辑三小节）；Elsevier、Wiley、Springer Nature 的措辞已趋同：AI 不能当作者、实质性使用要披露、纯语法润色不用披露、**审稿人不得上传稿件**。**这改变的不是"能不能用"，而是"用了必须写在哪里"**——投稿流程里多了一个必答项。`evidence: [T02-S002, T02-S109, T02-S110, T02-S111]`
2. **中国把 AI 使用写进了成文规范，且比出版商更细。** 科技部《负责任研究行为规范指引（2023）》要求披露「具体的软件名称、版本和使用时间」，禁止用生成式 AI「直接生成申报材料」，禁止「直接使用未经核实的由生成式人工智能生成的参考文献」，并规定「生成式人工智能不得列为成果共同完成人」。**对中国大陆研究者，这不是行业惯例而是监管要求。**`evidence: [T02-S113]`
3. **中科院分区表停更。** 官网公告「自2026年起，中国科学院文献情报中心将不再更新与发布期刊分区表」。**这直接改变了中国大陆最广泛使用的一个期刊评价工具的可用性**，也让"第三方冒名分区"的识别变成一项新的必备技能。`evidence: [T02-S096]`
4. **图像完整性检查从"个别编辑手工看"变成"出版侧的自动化流水线"。** Proofig 与 ImageTwin 的官方页都列出多家大型出版社为客户，且都已加入 AI 生成图像检测。**这意味着"投稿前自己先扫一遍"正在从可选变成必要**，同时也带来了新的问题：正当的图像复用被标红后作者要如何自证。`evidence: [T02-S091, T02-S092]`
5. **撤稿数据进入了基础设施层。** Retraction Watch 数据由 Crossref 承载并进入 REST API 后，"批量核对参考文献里有没有撤稿论文"从人工劳动变成了可脚本化的一步。`evidence: [T02-S105]`
6. **AI 文献工具开始自我披露局限。** Consensus 官方博客主动承认模型会误读来源、即使引用正确也可能总结错——**厂商话术从"更快更准"转向"更快但要你核对"，这本身是一个可观察的行业信号。** 与此同时 Elicit 仍在官网给出 95%–99% 的自报指标而未说明测评口径；**同一类产品内部对"要不要给数字"的分歧是真实的。**`evidence: [T02-S115, T02-S114]`

### (c) 中国大陆用户特有的可及性与替代方案

| 障碍 | 影响 | 现实替代 |
|------|------|---------|
| **Google Scholar 无法直接访问** | 失去全文级模糊检索与灰色文献入口 | Semantic Scholar、OpenAlex、Lens.org（均可直接访问）；学校购买的发现系统；PubMed（生医） `evidence: [T02-S019, T02-S005, T02-S024]` |
| **Google Docs 不可用** | Paperpile、NotebookLM 基本出局 | Word + Zotero；腾讯文档/飞书类国内协作工具（但要注意未发表数据的合规） `evidence: [T02-S033, T02-S116]` |
| **GitHub 速度不稳** | 代码协作与 CI 受影响 | Gitee 做主仓库 + GitHub 做镜像；论文存档仍走 Zenodo 拿 DOI `evidence: [T02-S062, T02-S077]` |
| **Overleaf 较慢** | 截稿前编译排队风险 | 本地 TeX Live + Git；CTAN 国内镜像 `evidence: [T02-S036, T02-S047]` |
| **CRAN / PyPI / conda 慢** | 装包失败 | 清华、中科大等国内镜像源 `evidence: [T02-S050, T02-S052]` |
| **中文文献与国标格式** | 国际工具支持弱 | NoteExpress（多数高校有集团授权）；知网/万方/维普三家都要跑 `evidence: [T02-S035, T02-S022]` |
| **数据出境合规** | 云端 ELN、在线翻译、AI 工具都涉及 | 自建 eLabFTW；本地化部署；对未发表数据一律不上传公开服务 `evidence: [T02-S069, T02-S003]` |
| **知网的监管背景** | 2023 年 9 月网信办对其作出行政处罚（责令停止违法处理个人信息、罚款五千万元人民币） | 不影响日常使用，但机构采购与个人信息授权应知情 `evidence: [T02-S016]` |
| **商业软件盗版普遍** | 国际投稿与合规审查时是风险点 | 优先用校园授权；无授权时用 R / JASP / jamovi 等开源替代 `evidence: [T02-S053, T02-S055]` |

**一条容易被忽略的正向差异**：中国大陆高校对 EndNote、NoteExpress、SPSS、Microsoft 365 的集团授权覆盖率相当高，而对 Covidence、Rayyan、Cabells 这类国际学术流程工具的订阅率则明显低于欧美澳。**这决定了中国团队在"写作与统计"环节工具充足，在"系统综述流程与期刊可信度核查"环节工具稀缺**——后者是本 track 里最值得补的缺口。

### (d) 信号薄弱的维度（明确标注，不要在 Phase 2 里当成已知）

1. **人文学科几乎没有对应工具。** 本清单里的检索、统计、可复现、预注册、报告规范全部围绕实证研究构建。历史、文学、哲学的研究者在这张地图上基本找不到自己的位置——**这是真实缺口而非检索失败**，与 Wave 1 在信息源维度得到的结论一致。
2. **价格数据整体不可靠。** 除少数几家（Zotero 存储、EndNote 升级价）有官方定价页可查，多数工具的价格随时调整、分层复杂、且有大量不公开的机构议价。**本文件中所有价格都标注了口径与"厂商自报"，Phase 2 不应把任何具体金额当稳定事实使用。**
3. **AI 工具的准确率指标全部是厂商自报，且没有公开的独立基准测评。** Elicit 给出的 95%–99% 一组数字没有说明测评集、任务定义与对照。**在有独立第三方基准之前，这一整类的性能声明都应视为未经核实。**
4. **中国侧的工具生态缺少公开的一手资料。** 知网、万方、维普的收录量、更新频率、去重规则很难从官方渠道拿到可引用的数字；国内期刊评价体系（北大中文核心、CSSCI、CSCD、科协目录）的具体遴选流程公开程度不一。**这一块的信号强度明显低于英语学界对应部分。**
5. **"新兴"档的七个条目里有六个 Decay risk 为 high。** 这不是保守估计——生成式 AI 相关的四条在 12 个月后大概率需要整条重写（产品、定价、政策都在动）。**Phase 2 若要长期复用本文件，应把第 7 节视为快照而非稳定知识。**
6. **本 track 未覆盖的相邻领域**：实验室物资与经费管理、教学与课程工具、专利与技术转移流程、会议投稿与 poster 制作、以及各学科自己的领域专用软件（如结构生物学、地理信息系统、语料库语言学）。这些在真实工作里占的时间不小，但超出本 track 的界定范围。
