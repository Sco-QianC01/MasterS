## 工作流

### 1. 选题与可行性判断 (Decay risk: low)

- **触发场景**: 刚进组、开题前、上一个项目收尾要接下一个、导师给了个模糊方向让你「自己找个点」、换赛道或博后转型时。
- **入门 SOP（最少步骤）**:
  1. **把兴趣写成一句「谁在什么条件下会怎样」的陈述句**。交付物：一页纸，写清研究对象、变量或现象、你猜的方向。做完的标准：这句话可以被证伪——如果结果反过来，你能说出「那我就错了」。
  2. **做一次「已经有人做过吗」的窄检索**。交付物：20–40 条题录 + 5–8 篇细读的核心文献 + 一段「现有工作停在哪」。做完的标准：你能说出最近三年最接近的那篇是谁做的、它没回答什么。
  3. **把问题降级成一个可测的具体问题**。交付物：一句可操作化的问题（谁 / 什么测量 / 什么比较 / 什么结局）。做完的标准：能写出主结果那张图的横纵轴。
  4. **做「三种结果」演练**。交付物：一段文字，分别写「显著正向 / 无效应 / 反向」三种结果各自意味着什么。做完的标准：三种结果都有话可说——只有一种结果能写成论文的题目不要做。
  5. **可行性核对表**：数据 / 样本 / 设备 / 经费 / 伦理 / 时间 / 技能 / 合作者，逐项写「已有 / 需申请 / 无解」。交付物：一张表。做完的标准：没有「无解」项，或每个「无解」项都有 plan B。
  6. **和导师或一位圈内人做一次 15 分钟口头汇报**。交付物：对方能复述你的问题。做完的标准：对方提出的第一个反对意见你答得上来。
- **资深路径**: **跳过**第 1 步的自由发散（资深者的题目多数来自上一篇论文的局限性一节、审稿意见里反复出现的质疑、或基金指南的空白），也**跳过**第 6 步的正式汇报（改为在组会或会议茶歇里当场试讲）。**优化**第 2 步——用引文网络反向追（谁引了这篇、引的时候是支持还是反驳）而不是关键词穷举；**优化**第 4 步，直接把「无效应」那一支写成注册报告的候选题目。**额外**做三件事：先算一遍粗略功效看这个效应量在现实样本量下能不能被检出（检出不了就换题）；先查这个题目在基金指南与本单位考核口径下值不值得投入；以及先把「三年后这条线还能不能长出第二篇、第三篇」想清楚，选能长成一串的题而不是一次性的题。
- **硬约束**:
  - 如果最终产出可能是系统综述，题目在开工前就要去 PROSPERO 查重并注册（健康相关领域），否则可能撞题 `evidence: [T03-S033]`。
  - 如果研究涉及人、人体材料、个人信息数据、实验动物，或涉及人工智能与算法设计，中国境内自 2023-12-01 起适用《科技伦理审查办法（试行）》，选题阶段就要判断它落不落在需要审查甚至专家复核的清单里——这会直接改变时间表 `evidence: [T03-S016]`。
  - 选题不得以「够发几篇」为切分依据：把一份可以完整报告的工作拆成多篇最小可发表单元（salami slicing）在主要出版商与出版伦理机构的政策里属于不当出版行为 `evidence: [T03-S013, T03-S039]`。
- **常见失败模式**:
  1. **症状**：题目一句话说不清，每次讲给别人听版本都不一样 → **根因**：还停在「主题」而不是「问题」，缺少可证伪的陈述 → **补救**：强制写成「谁在什么条件下会怎样」，再加一句「如果……我就错了」。
  2. **症状**：文献看了三个月还在看，越看越觉得都被做完了 → **根因**：把「穷尽文献」当成开工前置条件，实际是回避决策 → **补救**：给检索设硬截止（例如两周），把剩余文献放进「边做边补」清单。
  3. **症状**：结果出来才发现只有一个方向能写 → **根因**：跳过了三种结果演练，题目本质是「验证我想要的那个答案」 → **补救**：回到第 4 步；无效应也有意义的题才做。
  4. **症状**：数据拿不到 / 伦理批不下来 / 设备排不上，项目卡死在第二年 → **根因**：可行性核对表没做，或做了但把「需申请」当成「已有」 → **补救**：任何「需申请」项在正式开工前先跑一遍最小可行申请。
  5. **症状**：做出来了但没人关心 → **根因**：只回答了「还没人做过」，没回答「为什么值得做」 → **补救**：把「谁会因为这个结论改变做法」写进一页纸，写不出来就换题。
- **时间尺度**: 口径为**社科与实验心理学方向的博士生第一个独立课题**：一页纸问题陈述 1–2 周，窄检索与细读 2–4 周，可行性核对 1 周，合计约 1–2 个月。**生医湿实验方向**因为要预估试剂、动物与伦理批件周期，可行性核对本身常再加 2–4 周。**计算与工程方向**若数据集与基线代码公开可得，整个阶段可以压到 2–3 周，但要额外花时间确认数据集许可与使用条款。这些是常见区间不是保证值，跨学科不可直接套用。
- **中国侧差异**:
  - 英文攻略默认「你自己选题」；国内硕博的题目相当比例来自导师在研项目的子课题，可协商空间在「怎么切」而不是「做不做」。开题报告与培养方案里的时间节点是硬的，不能按英文攻略那种「想清楚再开工」的节奏走。
  - 破除「唯论文」的 2020 年两份文件把评价导向从数论文转向代表作，但落到具体单位的博士毕业与考核细则上执行程度差异很大——选题前应当去查**本单位现行**的学位与考核文件，而不是套用国家层面的原则 `evidence: [T03-S022]`。
  - 涉及人工智能、算法与个人数据处理的研究在中国明确纳入科技伦理审查范围，而按美国联邦通则的豁免类别读英文攻略会误以为纯数据研究不需审查——这是选题阶段最常见的时间表误判 `evidence: [T03-S016, T03-S035]`。
- **近期变化**: `last_updated: 2026-09`。近 24 个月最大的变化有两条：一是生成式模型让「快速摸清一个陌生领域」的成本骤降，但也让「看起来有据可查、实则引文不存在」的选题依据变多，所以第 2 步的每一条关键文献都必须回到原文确认；二是主要出版商与医学期刊编辑规范陆续把 AI 使用的披露写进正式条款（ICMJE 2026 年 1 月版把 AI 单独成节），选题阶段就该决定这条线上要不要用、怎么记录 `evidence: [T03-S010, T03-S039]`。
- evidence: [T03-S016, T03-S033, T03-S013, T03-S022, T03-S010]

### 2. 文献综述与系统综述 (Decay risk: medium)

> 这里有**两条不同的流程**：给论文写引言用的叙述性综述，和作为独立研究产出的系统综述。两者的严谨度要求差一个数量级，最常见的错误是用前者的做法冒充后者的名义。

- **触发场景**: 写引言与讨论、开题报告、基金本子的立项依据、要独立发表一篇系统综述或元分析、给一个有争议的问题做证据盘点。
- **入门 SOP（最少步骤）**:
  1. **先判定你要做哪一种**。交付物：一句话说明——「这是给论文写引言的叙述性综述」还是「这是要独立发表、需要注册与报告规范的系统综述」。做完的标准：如果是后者，你已经知道要遵 PRISMA 2020 并准备注册 `evidence: [T03-S002]`。
  2. **写检索式，而不是「搜关键词」**。交付物：一份可复制的检索式（数据库名 + 完整检索串 + 字段限定 + 时间范围 + 语言限定 + 执行日期）。做完的标准：把这段交给另一个人，他跑出来的条数和你差不多。
  3. **多库检索并保留原始导出文件**。交付物：每个数据库一个导出文件（原始、不修改）+ 一份合并去重后的库。做完的标准：能说出各库各命中多少条、去重后剩多少条。
  4. **两级筛选：题摘筛 → 全文筛**。交付物：预先写好的纳入排除标准 + 每一条被排除文献的排除理由（尤其全文阶段）。做完的标准：能画出流程图的四个数字（识别 / 筛选 / 纳入资格 / 最终纳入）。
  5. **提取数据到结构化表**。交付物：一张提取表（每行一篇，列是你后面要用的字段）。做完的标准：不回原文就能做后续分析。
  6. **偏倚风险评估**（系统综述必做）。交付物：逐研究的偏倚评估结果表。做完的标准：结论里能区分「高质量研究说什么」和「所有研究平均说什么」。
  7. **写成有主线的综述而不是流水账**。交付物：按论点组织的段落，而不是按文献一篇一段。做完的标准：每一段的主题句是你的判断，引文是证据。
- **资深路径**: **跳过**逐库穷举（改为先用一次高召回检索建种子集，再用引文网络前向后向滚雪球补全，最后只回一两个核心库做查全验证）；**跳过**从零读起（先读该领域近三年的高质量综述与规范文件，把它们的参考文献当骨架）。**优化**第 4 步——两人独立筛选并计算一致性、只对分歧条目讨论，比一人筛两遍快也更可信；**优化**提取表——开工前就按最终要画的那张森林图或证据表倒推需要哪些列。**额外**做的：做检索式时找图书馆的学科馆员或信息专家共同拟定并署名（Cochrane 传统里这是标准做法）；额外跑一次「灰色文献与预印本」检索和一次「已注册但未发表」核查，因为发表偏倚正是从这里进来的；额外记录一份可追溯的决策日志，把每一次纳入排除标准的调整写清时间与理由。
- **硬约束**:
  - 系统综述与元分析按 **PRISMA 2020**（2021 年发表，通用于各学科，健康领域最强制）报告，包含 27 条清单与四阶段流程图；摘要有 PRISMA for Abstracts、范围综述有 PRISMA-ScR 等扩展版，用前去 EQUATOR 确认当前版本 `evidence: [T03-S002, T03-S001]`。
  - 健康相关的系统综述应在开工前于 PROSPERO 前瞻注册；非健康领域 PROSPERO 通常不收，可用 OSF 注册替代 `evidence: [T03-S033, T03-S029]`。
  - 提交给期刊时多数出版商要求随稿提交完整检索式与 PRISMA 清单对照表，作为可复现性材料 `evidence: [T03-S039]`。
  - 元分析的合成方法、异质性评估与敏感性分析按方法学手册执行，异质性来源比合并值本身更重要 `evidence: [T03-S083]`。
  - 引用纪律：不得为了抬高被引而互引、不得应要求加入与内容无关的引用；引用操纵在出版伦理机构的核心原则与中国的相关行业标准里都属于明确禁止的行为，只作为要识别与拒绝的信号呈现 `evidence: [T03-S013, T03-S021]`。
- **常见失败模式**:
  1. **症状**：把叙述性综述叫「系统综述」投出去，被审稿人要求补流程图和注册号，补不出来 → **根因**：混淆两种流程 → **补救**：改名为叙述性综述 / 范围综述并按对应规范补齐，或退回去重做检索并说明为回溯性。
  2. **症状**：检索式复现不出来，几个月后自己也跑不出当初那批文献 → **根因**：在数据库界面上点选而没保存完整检索串与执行日期 → **补救**：每次检索后立刻导出检索历史并写进方法学附录。
  3. **症状**：流程图的数字对不上（排除数加起来不等于识别数） → **根因**：筛选在多个工具间来回搬，没有单一事实来源 → **补救**：固定一个筛选工具或一张主表，所有状态变更只在这一处记录。
  4. **症状**：综述读起来像文献罗列，审稿人说「看不出作者的观点」 → **根因**：按文献组织而非按论点组织 → **补救**：先写出 5–8 条判断作为小标题，再把文献塞进去。
  5. **症状**：纳入的研究质量参差，合并出一个漂亮的效应值 → **根因**：跳过偏倚风险评估，垃圾进垃圾出 → **补救**：补做偏倚评估并做敏感性分析（只留低偏倚研究再合并一次），两个结果并排报告。
- **时间尺度**: 口径为**健康与生医领域、有方法学支持的正式系统综述**：方案撰写与注册 2–6 周，检索与去重 1–3 周，双人题摘筛选（数千条量级）4–10 周，全文筛选与提取 4–12 周，偏倚评估与合成 3–8 周，写作 4–8 周——这类综述常见的总跨度以**月到一年以上**计，是一项独立研究而不是论文的准备工作。**社科的叙述性综述或论文引言的文献工作**通常 2–6 周。**计算与工程领域的系统文献综述**（software engineering 传统的 SLR）介于两者之间。不要把任何一条当成跨学科通用值。
- **中国侧差异**:
  - 中文文献是很多社科与临床题目绕不过去的一块，但主要中文库的检索语法与导出格式和国际库不同，去重时作者姓名与机构字段常对不齐——检索式要中英文各写一套并分别记录。
  - 国内的开题报告与基金本子的「国内外研究现状」有固定写法预期（先国外后国内、分段总结、末尾点出空白），这与英文期刊引言的漏斗结构不是一回事，两者不要互相套用。
  - 主要出版商与 EQUATOR 都有报告规范的中文译本索引，可以用中文清单自查、用英文原文引用 `evidence: [T03-S001, T03-S052]`。
- **近期变化**: `last_updated: 2026-09`。两条：一是 AI 辅助筛选与数据提取已经从「能不能用」进入「怎么报告」阶段——PRISMA 2020 已要求说明自动化工具的使用，现在期刊进一步要求写清哪一步用了什么模型、人工复核比例多少 `evidence: [T03-S002, T03-S039]`；二是论文工厂产出的低质量文献大量进入检索结果，纳入前多了一道新工序：查该文献是否已被撤稿或已有公开质疑，撤稿文献若被纳入合并，结论会被直接推翻。
- evidence: [T03-S002, T03-S001, T03-S033, T03-S039, T03-S013]

### 3. 研究设计与预注册 (Decay risk: medium)

- **触发场景**: 选题定了要开始收数据之前；申请伦理审查之前（多数委员会要看方案）；想做注册报告；导师说「先写个方案」；做复制研究。
- **入门 SOP（最少步骤）**:
  1. **把假设写成可以被数据驳倒的形式**。交付物：编号的假设列表，每条注明是验证性还是探索性。做完的标准：每条假设都对应一个具体的统计检验或估计量。
  2. **选设计并说明为什么是它**。交付物：设计描述（随机对照 / 准实验 / 队列 / 横断 / 定性 / 混合等）+ 因果图或变量关系图。做完的标准：能说出这个设计控制了什么威胁、控制不了什么。
  3. **操作化：把概念变成测量**。交付物：每个变量的测量方式、量表来源、编码规则、缺失值定义。做完的标准：另一个团队用你的描述能测出同一个东西。
  4. **样本量论证**。交付物：目标样本量 + 依据（最小有实际意义的效应量、显著性水平、目标功效、或精度目标 / 贝叶斯停止规则 / 定性研究的饱和判据）。做完的标准：写清「我准备检出多小的效应」而不是「N=100 差不多」。
  5. **写分析计划**。交付物：主要结局与主要分析各一个、协变量清单、缺失数据处理、异常值规则、多重比较处理方式、稳健性检验清单。做完的标准：拿到数据后不需要再做任何未记录的选择。
  6. **决定注册路径并注册**。交付物：时间戳注册记录（OSF / AsPredicted / PROSPERO / 临床试验注册平台），或注册报告的 Stage 1 稿。做完的标准：注册在**收数据之前**完成，且有不可篡改的时间戳 `evidence: [T03-S029, T03-S027]`。
  7. **做一次小规模预实验或试点**。交付物：试点数据 + 修订记录。做完的标准：流程跑通、测量工具没崩、明确记录了哪些参数因试点而修改。
- **资深路径**: **跳过**通用模板里不适用的字段（模板是为最坏情况写的，资深者按研究类型选轻量模板——例如 AsPredicted 的八问式适合简单实验，定性研究另有专门模板）`evidence: [T03-S030]`；**跳过**从零推导功效（用同类文献的效应量分布或最小有意义差值直接反推）。**优化**第 5 步——分析计划直接写成能跑的代码，用模拟数据先跑通全流程，这样注册的不只是文字还是可执行的规格；**优化**第 6 步——如果这个问题的价值不依赖结果方向，直接走注册报告而不是普通预注册，因为只有前者能拿到期刊的原则性接收、从制度上消除发表偏倚 `evidence: [T03-S027]`。**额外**做的：预先写好「偏离预案」（如果招募不足 / 设备故障 / 疫情式中断，怎么办，写进注册文件）；额外做一次盲态数据检查或预注册的多重宇宙分析清单；额外把方案按对应的方案报告规范（临床试验用 SPIRIT 2025）成文，因为方案规范和结果报告规范是配套的 `evidence: [T03-S004]`。
- **硬约束**:
  - **随机对照试验**：方案按 SPIRIT 2025 写，结果按 CONSORT 2025 报告；医学期刊编辑规范要求前瞻注册（在首例受试者入组前）作为发表的先决条件 `evidence: [T03-S004, T03-S003, T03-S009]`。
  - **观察性研究**用 STROBE 22 条；**动物实验**用 ARRIVE 2.0 的 Essential 10（含样本量、随机化、盲法、纳入排除标准）；**定性研究**用 COREQ（访谈与焦点小组，32 条）或 SRQR（21 条、更允许不同范式）`evidence: [T03-S005, T03-S006, T03-S007, T03-S008]`。
  - 预注册≠注册报告：前者只是带时间戳的存档，不改变期刊的发表决策；后者在收数据前评审并给出原则性接收。把前者说成后者是常见的说法错误 `evidence: [T03-S027]`。
  - 期刊的透明度要求可以按 TOP 分级框架预判（预注册、数据、代码、材料各有 0–3 级要求），投稿前对照目标刊的等级设计流程 `evidence: [T03-S028]`。
- **常见失败模式**:
  1. **症状**：注册文件写得很含糊，「我们将进行适当的统计分析」 → **根因**：把预注册当成合规打卡而不是自我约束 → **补救**：用「如果……则……」写死每个分支；含糊的注册等于没注册。
  2. **症状**：拿到数据后发现主结局测量有问题，只好换一个结局报告 → **根因**：跳过了试点，测量没验证过 → **补救**：必须报告偏离并说明理由；下次把试点当必做步骤。
  3. **症状**：样本量按「同类文献都是这个数」定，结果功效严重不足 → **根因**：同类文献本身是低功效且被发表偏倚筛选过的 → **补救**：按最小有实际意义的效应量而非文献报告的效应量算；文献里的效应量因为发表偏倚系统性偏大。
  4. **症状**：预注册了，但论文里探索性结果和验证性结果混在一起讲 → **根因**：写作时忘了这条界线 → **补救**：在结果部分用小标题物理隔开两类分析，讨论里不要把探索性结果当结论。
  5. **症状**：有偏离但没报告，被审稿人对照注册文件抓出来 → **根因**：以为偏离是污点 → **补救**：偏离本身不是问题，隐瞒才是；标准做法是列一张「注册 vs 实际」的对照表放进附录。
- **时间尺度**: 口径为**社科与实验心理学的单个实验研究**：假设与设计成文 1–2 周，操作化与量表选定 1–2 周，样本量论证 2–5 天，分析计划 1 周，注册提交当天完成，试点 2–4 周，合计约 1.5–2.5 个月。**临床试验的方案（SPIRIT 口径）**因为要过伦理与注册平台，通常以**数月**计。**注册报告**要额外算上 Stage 1 的同行评审周期，这一段本身可能与一次普通投稿的审稿周期同量级，且各刊差异极大——各期刊自报的处理时长口径不同，不可合并成一个数字。
- **中国侧差异**:
  - 国内基金本子里的「研究方案」与英文语境的 protocol 不完全对应：前者更偏向说服评审人这条路可行，后者更偏向约束自己不许中途改。两份都要写时不要指望一稿两用。
  - 预注册在国内的制度激励弱：多数单位的考核不认注册记录，也不因为你预注册就宽限时间。做预注册目前主要是为了投国际期刊时的可信度与自我约束，不要期待本单位的流程配合。
  - 涉及人的研究在国内需要先拿伦理批件才能收数据，这与预注册的时间点常常冲突——务实的顺序是：方案定稿 → 伦理送审（同时）→ 预注册 → 拿到批件后开始收数据，注册文件里注明伦理审查状态。
  - 临床试验在中国有本国的注册平台，同时国际期刊通常认可世界卫生组织认证的一级注册平台；投国际刊前确认目标刊接受哪些平台 `evidence: [T03-S009]`。
- **近期变化**: `last_updated: 2026-09`。三条：CONSORT 与 SPIRIT 双双在 2025 年出新版，引旧版（CONSORT 2010 / SPIRIT 2013）是最省力的外行识别器 `evidence: [T03-S003, T03-S004]`；注册报告的接受刊数持续增加，且已从心理学扩散到生医、软件工程等领域 `evidence: [T03-S027]`；预注册模板本身在分化，按研究类型（定量实验 / 定性 / 二次数据 / 复制）选模板已经成为标准建议，用错模板会导致大量字段填「不适用」`evidence: [T03-S030]`。
- evidence: [T03-S027, T03-S029, T03-S030, T03-S003, T03-S004, T03-S005, T03-S006]

### 4. 伦理审批与数据合规 (Decay risk: high)

> 这是中国侧与英文攻略差异**最大**的一条工作流，也是最容易因为「照着英文教程做」而出事的一条。

- **触发场景**: 研究涉及人（含问卷、访谈、可穿戴设备、二次使用的健康数据）、人体材料、个人信息、实验动物；涉及人工智能与算法设计；有境外合作方要共享数据或样本；投稿时期刊要求提供伦理批件号。
- **入门 SOP（最少步骤）**:
  1. **判定适用哪几套规则**。交付物：一张勾选表——涉及人？涉及人体材料或人类遗传资源？涉及个人信息（是否敏感个人信息、是否未成年人）？涉及实验动物？涉及 AI 与算法？有境外合作方？有欧盟数据主体？做完的标准：每一项都有明确的是 / 否，且「是」项对应到具体条文。
  2. **确认审查主体与路径**。交付物：本单位科技伦理（审查）委员会的申请入口、受理时间表、所需材料清单。做完的标准：知道下一次受理截止日、知道要不要走专家复核。
  3. **准备材料包**。交付物：研究方案、知情同意书（含单独同意条款）、招募材料、数据管理与安全方案、研究者资质与培训证明、利益冲突声明。做完的标准：材料清单逐项打勾，无「稍后补」。
  4. **知情同意书按受试者读得懂的方式写**。交付物：一份同意书，开头是「关键信息」段——一个人为什么会愿意或不愿意参加。做完的标准：找一个非本专业的人读一遍能复述风险与退出方式 `evidence: [T03-S035]`。
  5. **个人信息的合法性基础单独过一遍**。交付物：一段说明——处理哪些个人信息、是否属敏感个人信息、同意是怎么取得的、如何最小化与去标识。做完的标准：即使伦理批件已到手，这段仍然独立成立 `evidence: [T03-S019]`。
  6. **提交、答复修改意见、拿批件**。交付物：批准文号 + 批准的方案版本号 + 有效期。做完的标准：文号、版本号、有效期三者一致，且论文方法学部分可以直接引用。
  7. **建立变更与续期机制**。交付物：一份记录，写明什么改动需要重新报批（方案实质性变更、增加人群、延长期限）。做完的标准：不会出现「实际做的和批的不是一回事」。
- **资深路径**: **跳过**从零写材料（本组已有获批的同类方案就复用其结构与语言，只改差异部分——伦理委员会看的是同一批要点）；**跳过**在不确定时先问同事（直接看本单位委员会公布的常见退回原因清单与模板，那才是判据来源）。**优化**送审时机——把伦理送审与预注册、基金申报的时间线并排画，让伦理审查的等待期与其他准备工作重叠；**优化**知情同意书——按不同人群准备分层版本（成人 / 未成年人及监护人 / 低识字率人群），一次过审的概率更高。**额外**做的：涉及境外合作方或数据出境的，**提前数月**启动人类遗传资源的审批或备案，这一条常常是整个项目的关键路径 `evidence: [T03-S018]`；额外准备一份数据安全与销毁方案（很多退回意见落在这里）；额外为多中心研究理清各中心的审查关系（谁牵头审、其他中心是认可还是各自审）。
- **硬约束**:
  - **《科技伦理审查办法（试行）》**：科技部等十部门 2023-10-08 印发，**自 2023-12-01 起施行**。适用于在中国境内开展的、涉及人（含人类生物样本与个人信息数据）、实验动物，以及可能带来伦理风险的科技活动——**明确包含人工智能、算法与模型设计、个人数据处理**。单位须设科技伦理（审查）委员会；清单内的高风险活动需经专家复核 `evidence: [T03-S016]`。
  - **《涉及人的生命科学和医学研究伦理审查办法》**（国卫科教发〔2023〕4号，2023-02-18 起施行）：研究开始前必须取得伦理审查批件与知情同意；规定了免除审查 / 免除同意的具体情形（如利用可公开获取或匿名化的信息数据），**但必须逐条对照原文，不能自行放宽** `evidence: [T03-S017]`。
  - **《人类遗传资源管理条例实施细则》**（科技部令第21号，**2023-07-01 起施行**）：外方单位参与的国际科研合作需行政许可或备案；对外提供或开放使用人类遗传资源信息须事先报告并提交信息备份。跨国合作论文最常见的合规事故在此 `evidence: [T03-S018]`。
  - **《个人信息保护法》**（2021-11-01 起施行）：医疗健康、生物识别、特定身份、行踪轨迹以及不满十四周岁未成年人的信息属敏感个人信息，处理需**单独同意**；处理不满十四周岁未成年人信息还须监护人同意。**伦理批件不能替代个人信息保护法上的同意基础** `evidence: [T03-S019]`。
  - **《实验动物管理条例》**（现行有效版本为 2017 年第三次修订）：应使用有生产许可证单位提供的合格动物，在有使用许可证的设施内实验，经本单位动物伦理委员会审查。投国际刊时方法学部分要同时写清批准文号与所遵循的规范（通常引 ARRIVE 2.0）`evidence: [T03-S020, T03-S006]`。
  - 与欧盟合作或涉及欧盟数据主体：GDPR 第 89 条的科研减损**有前提条件**（须落实数据最小化、可含假名化，且须有成员国法律依据），不是「做研究就不受管」`evidence: [T03-S036]`。
  - 美国联邦通则（45 CFR 46，2018 修订版）：知情同意书必须以简明的「关键信息」段开头；「exempt」不等于「不需要审查」，仍须由机构按流程作豁免认定 `evidence: [T03-S035]`。
- **常见失败模式**:
  1. **症状**：数据都收完了才发现要伦理审查，期刊索要批件号 → **根因**：以为问卷 / 访谈 / 公开数据不算「涉及人」 → **补救**：多数委员会不做追溯性批准；可申请「豁免认定」或由委员会出具情况说明，但能不能发表由期刊定，这一步没有万全解，只能不再犯。
  2. **症状**：有伦理批件，但被指出未取得敏感个人信息的单独同意 → **根因**：把伦理审查与个人信息合规当成一件事 → **补救**：两条线分别过；同意书里为敏感信息设独立勾选项而不是打包同意 `evidence: [T03-S019]`。
  3. **症状**：国际合作方要样本或数据，走到一半发现要审批，项目停摆数月 → **根因**：人类遗传资源的审批 / 备案没有列进关键路径 → **补救**：合作意向确定的当天就启动，不要等到有数据了才办 `evidence: [T03-S018]`。
  4. **症状**：材料被退回两三轮，每次都是新问题 → **根因**：一次只改被点名的那条，没有系统对照本单位的材料清单 → **补救**：拿本单位公布的退回原因清单逐条自查后再提交。
  5. **症状**：实际执行的方案与获批版本不一致（多加了一个人群 / 多问了几个问题） → **根因**：不知道什么算实质性变更 → **补救**：任何改动先问委员会秘书；宁可多报一次备案。
- **时间尺度**: 口径为**中国高校 / 医院的本单位伦理委员会、涉及人的社科或临床研究**：材料准备 2–4 周；委员会通常按固定周期开会（常见为每月一次量级，各单位不同），从提交到出批件常见跨度为**数周到数月**，中间往往有一到两轮补充材料。**涉及人类遗传资源的国际合作审批 / 备案**是另一个量级，须按**数月**预留并列入关键路径 `evidence: [T03-S018]`。**动物实验的机构审查**在有成熟平台的单位通常比人体研究快。这些都是各单位自报的经验区间，跨单位差异极大，不要当成承诺值——正确做法是直接问本单位委员会秘书要历史平均处理时长。
- **中国侧差异**（这一节本身就是差异）:
  - **审查触发范围更宽**：AI、算法与模型设计、个人数据处理被明确纳入，纯计算与社科二次数据研究在中国可能需要审查，而按美国联邦通则的豁免类别读英文攻略会误判 `evidence: [T03-S016, T03-S035]`。
  - **人类遗传资源是中国独有的强监管环节**，英文攻略里没有对应制度 `evidence: [T03-S018]`。
  - **同意的法律基础是两条线并行**：伦理审查 + 个人信息保护法的单独同意，只做前者不够 `evidence: [T03-S019, T03-S017]`。
  - 「IRB」这个词在中文语境里常被拿来泛指所有伦理委员会，但国内的科技伦理委员会与医学伦理委员会依据不同办法设立、职责范围不同，写论文时应写本单位委员会的正式名称与文号，不要直译成 IRB。
- **近期变化**: `last_updated: 2026-09`。主要变化集中在 2023 年那一波立法（科技伦理审查办法 2023-12-01 施行、人类遗传资源实施细则 2023-07-01 施行、涉及人的生命科学和医学研究伦理审查办法 2023-02-18 施行），此后各高校与医院在近 24 个月里陆续把这些要求落成本单位的实施细则与在线送审系统——**这意味着本单位流程比国家文件更新得更频繁，每次送审前都要重新看一遍本单位的现行版本**。同期国际侧的变化是数据共享要求收紧（资助机构把数据管理计划与共享作为拨款条件），伦理材料里的数据管理与安全方案权重上升 `evidence: [T03-S025, T03-S026]`。
- evidence: [T03-S016, T03-S017, T03-S018, T03-S019, T03-S020, T03-S035, T03-S036]

### 5. 数据采集与数据管理 (Decay risk: medium)

- **触发场景**: 伦理批件到手要开始收数据；接手别人留下的数据；资助机构要求提交数据管理计划；项目要归档或人员交接；论文投稿时期刊要数据可用性声明。
- **入门 SOP（最少步骤）**:
  1. **写一份数据管理计划**（哪怕只有两页）。交付物：写清会产生什么数据、格式与体量、怎么命名与组织、存在哪里、谁能访问、保存多久、最终共享到哪个仓储、共享的限制与理由。做完的标准：一个新来的人照着它能找到任何一份数据 `evidence: [T03-S025, T03-S026]`。
  2. **定目录结构与命名规则，写进一份 README**。交付物：固定目录树（原始 / 中间 / 结果 / 代码 / 文档）+ 命名规范（含日期格式、版本号、无空格无中文路径）。做完的标准：文件名本身能告诉你是什么、什么时候、第几版。
  3. **原始数据只读**。交付物：一份不可修改的原始数据副本（另存一处、设只读、留校验值）。做完的标准：任何清洗与修正都发生在脚本里，原始文件从头到尾没被改过。
  4. **清洗与转换全部脚本化**。交付物：从原始数据到分析数据集的可重跑脚本。做完的标准：删掉所有中间文件后跑一条命令能全部重建。
  5. **版本控制与备份分开做**。交付物：代码与文本进版本控制系统；数据按 3-2-1 之类的规则备份（多份、不同介质、异地一份）。做完的标准：误删一个目录不会毁掉项目。
  6. **留痕**。交付物：一份决策日志（时间、改了什么、为什么），以及采集端的原始记录（纸质或电子实验记录本、问卷后台导出、设备日志）。做完的标准：三年后被问「这个被排除的样本为什么排除」能答。
  7. **归档与共享**。交付物：数据集存入有持久标识符的仓储、拿到 DOI、写好元数据与许可；论文里写数据可用性声明。做完的标准：别人拿着 DOI 能找到并知道能怎么用 `evidence: [T03-S034, T03-S044]`。
- **资深路径**: **跳过**为小项目搭重型系统（不是每个项目都要数据库和流水线工具；一个规范的目录 + 版本控制 + 一份 README 已经解决八成问题）；**跳过**事后补元数据（在采集模板里就把元数据字段设成必填）。**优化**第 4 步——把清洗脚本写成幂等的（重复跑结果一样，术语上叫 idempotent），并加入数据校验断言（行数、取值范围、唯一键），异常早暴露；**优化**备份——用自动同步而不是靠记性。**额外**做的：给每个数据集建一份数据字典（每个变量的含义、单位、取值范围、缺失编码）；额外做一次「新人测试」——让组里另一个人只拿仓库跑一遍，跑不通就说明留痕不够；额外在项目开始时就决定哪些数据将来能公开、哪些因个人信息或人类遗传资源限制只能受控访问，并把这个判断写进数据管理计划，而不是发表前才发现不能共享 `evidence: [T03-S018, T03-S019]`。
- **硬约束**:
  - **NIH 数据管理与共享政策**：自 2023-01-25 起，产生科研数据的申请须随申请提交 DMS Plan，作为拨款条件；2026 年通过 NOT-OD-26-046 更新了 Plan 的要素并要求使用对应的**强制格式页**（此前大量计划篇幅超标、堆砌无关细节）。适用范围为 NIH 资助或开展的研究，不是全球通行 `evidence: [T03-S025, T03-S026]`。
  - **FAIR 原则**（2016 年发表）要求数据可发现、可获取、可互操作、可复用；**FAIR ≠ Open**——受控访问、需申请审批的数据完全可以是 FAIR 的 `evidence: [T03-S034, T03-S043]`。
  - 期刊侧：主要出版商要求提交数据可用性声明；期刊的透明度等级可按 TOP 框架预判（数据与代码各有分级要求）`evidence: [T03-S039, T03-S028]`。
  - 中国侧：涉及人类遗传资源信息的对外提供或开放使用须**事先报告并提交信息备份**（2023-07-01 起施行的实施细则），这条直接限制了「把数据挂到国际仓储上」这个默认动作 `evidence: [T03-S018]`。敏感个人信息的处理须单独同意，去标识化的程度要与共享方式匹配 `evidence: [T03-S019]`。
- **常见失败模式**:
  1. **症状**：`final_v3_真最终_修改版2.xlsx` 这类文件名，几个月后不知道哪份是对的 → **根因**：用文件名当版本控制，且手动改数据 → **补救**：原始数据只读 + 清洗脚本化 + 版本控制；改数据的动作必须留在代码里。
  2. **症状**：论文数字复现不出来，因为分析用的是某次手动改过的中间文件 → **根因**：手工操作插在流水线中间 → **补救**：把那一步补写成脚本，重跑一遍全流程验证。
  3. **症状**：人员离职后数据无人能读 → **根因**：没有 README、没有数据字典、密码与账号在个人手里 → **补救**：交接清单固定为「仓库 + README + 数据字典 + 访问凭据移交」，并在离职前做一次新人测试。
  4. **症状**：投稿时才发现受试者同意书里没写数据会被共享，共享不了 → **根因**：同意书与数据管理计划各写各的 → **补救**：写同意书时就把共享条款写进去（并按敏感信息设单独同意项）；已收数据的只能如实说明限制原因。
  5. **症状**：备份了但从没验证过，需要恢复时发现备份是空的或损坏 → **根因**：备份 = 复制粘贴一次，没有恢复演练 → **补救**：每隔一段时间实际从备份恢复一次小样本。
- **时间尺度**: 口径为**单人或小组规模、社科问卷或计算类项目**：写一份两页的数据管理计划 2–5 天；搭目录结构与命名规范 1 天；把清洗脚本化通常与分析并行、占分析总时长的 30%–50%（这是常见经验分布不是测量值）；归档与元数据整理在投稿前后 1–2 周。**生医湿实验项目**的采集端留痕（实验记录本、仪器原始文件）是持续性工作，不能压缩成一个阶段；**多中心临床研究**的数据管理是独立岗位的工作量，不适合用上面任何数字类比。
- **中国侧差异**:
  - 数据出境是国内独有的强约束：国际仓储（含通用型代码与数据仓储）对涉及人类遗传资源信息的数据不是默认可用选项，须先走事先报告与信息备份 `evidence: [T03-S018]`。务实做法是在数据管理计划里就分层——哪一层可公开、哪一层只能受控访问、哪一层只能在境内。
  - 国内资助机构对数据管理计划的强制程度普遍弱于 NIH 之类的口径，很多项目不会主动要求；但投国际期刊时期刊会要，所以这份计划要为投稿而写而不是为结题而写。
  - 高校普遍缺少机构级数据仓储，实践中依赖课题组自建与商业网盘，这带来两个具体风险：网盘的版本冲突，以及个人账号离职即失效。把「机构可长期维护的存储位置」写进计划，而不是写某个人的网盘。
- **近期变化**: `last_updated: 2026-09`。两条：资助机构侧在收紧——NIH 在 2026 年通过 NOT-OD-26-046 更新 DMS Plan 要素并强制格式页，方向是「更短、更结构化、更可审」`evidence: [T03-S026]`；期刊侧在把数据与代码可用性从「声明」推向「可核验」，越来越多刊要求提供可访问的仓储链接而不是「合理要求下可向作者索取」这种表述 `evidence: [T03-S039, T03-S028]`。
- evidence: [T03-S025, T03-S026, T03-S034, T03-S018, T03-S019, T03-S039]

### 6. 分析与稳健性检验 (Decay risk: low)

- **触发场景**: 数据收完了要出结果；审稿人要求补分析；自己的结果太漂亮不敢信；结果和预期相反；要判断一个结论稳不稳。
- **入门 SOP（最少步骤）**:
  1. **先看数据再看结论**。交付物：描述性统计、分布图、缺失模式、异常值清单。做完的标准：知道每个变量长什么样，不是直接跑模型。
  2. **按预先写好的分析计划跑主分析**。交付物：主结果（效应量 + 不确定性区间，而不只是 p 值）。做完的标准：这一步没有任何未记录的选择。
  3. **把探索性分析物理隔开**。交付物：两个分开的脚本或两个分开的结果小节。做完的标准：读者能一眼分清哪些是预先说好的、哪些是看了数据之后做的 `evidence: [T03-S027]`。
  4. **做稳健性检验**。交付物：一张表或一张图，展示结论在不同合理选择下怎么变（不同协变量集、不同异常值规则、不同模型设定、不同缺失处理）。做完的标准：能说出「在哪些设定下结论会翻」。
  5. **处理多重比较**。交付物：说明做了多少个检验、用什么方式控制（预先指定主结局、族错误率控制、错误发现率控制、或明确声明为探索性不做校正）。做完的标准：不出现「我只跑了一个检验所以没有多重比较问题」这种说法——分析选择是看了数据之后定的，一类错误率照样被抬高。
  6. **写解释纪律**。交付物：结果段落只描述观察到什么，不加因果词；讨论段落才谈解释并注明其依据。做完的标准：不显著不写成「有变好的趋势」，显著不写成「证明了」。
  7. **可重复性自检**。交付物：从原始数据一条命令跑到论文里每个数字的脚本 + 环境记录（软件版本、随机种子）。做完的标准：换一台机器能跑出一样的数。
- **资深路径**: **跳过**把所有模型都跑一遍再挑（这正是分叉路径问题的来源）——资深者先用因果图确定该放哪些变量，模型设定由问题决定而不是由拟合优度决定；**跳过**对探索性发现的过度解释（直接标记为「待独立验证」，不写成结论）。**优化**第 4 步——把稳健性检验从「补几个模型」升级为系统化的多重宇宙 / 规格曲线分析，把所有合理设定跑一遍看结论分布，这类方法近年已有跨学科的方法学指南与专门的可视化研究 `evidence: [T03-S046, T03-S047]`；**优化**第 7 步——用容器或环境锁文件固定依赖，而不是在方法学里写「使用 R 4.x」。**额外**做的：盲态分析（分析时先不解盲分组标签）或让一位不知道假设的合作者独立跑一遍主分析；额外做正对照与负对照检验（已知应该有效应和已知应该无效应的情形，看流程能不能分辨）；额外把「哪些结果我会因为它改变自己的看法」提前写下来。
- **硬约束**:
  - p 值的解读边界有学会级立场文件（美国统计学会 2016 年声明的六条原则）：p 值不度量假设为真的概率，也不度量效应大小；「p<0.05 所以有 95% 把握」是被这份声明直接否定的读法 `evidence: [T03-S050]`。
  - 各报告规范都要求交代统计方法的细节：CONSORT 2025 要求随机对照试验分别报告随机序列产生、分配隐藏与盲法；STROBE 要求交代混杂如何处理、连续变量如何分组；ARRIVE 2.0 把样本量、随机化、盲法、纳入排除标准列入 Essential 10 `evidence: [T03-S003, T03-S005, T03-S006]`。
  - 事后功效（拿观察到的效应量反算功效）没有信息量，不应被用来解释不显著的结果——这是各方法学教材与规范一致的立场。
  - 期刊的代码与数据透明度要求按 TOP 分级预判，投稿前对照目标刊的等级准备材料 `evidence: [T03-S028]`。
- **常见失败模式**:
  1. **症状**：结果不显著，于是换协变量、换子样本、换模型，直到显著 → **根因**：把分析当成寻找显著性的搜索过程 → **补救**：所有跑过的设定都要报告（多重宇宙式呈现）；这类行为在没有披露时就是研究者自由度的滥用，不是技术问题而是报告问题。
  2. **症状**：论文里的假设和当初想的不一样，但读起来天衣无缝 → **根因**：看了结果之后回头改假设 → **补救**：把这部分明确写成探索性发现；预注册的作用正是从制度上区分假设生成与假设检验 `evidence: [T03-S027]`。
  3. **症状**：结果异常漂亮，效应量比同领域大很多 → **根因**：常见于低功效 + 只有大效应能过显著门槛，或有数据处理错误 → **补救**：先查数据错误（单位、编码、重复记录），再对照同领域效应量分布；漂亮结果的第一反应应该是找错。
  4. **症状**：审稿人问「换个模型还成立吗」答不上来 → **根因**：只跑了一个设定 → **补救**：补做稳健性检验并放进附录，同时在正文一句话概括结论的脆弱程度。
  5. **症状**：几个月后自己重跑，数字对不上 → **根因**：随机种子、软件版本、手动步骤没记录 → **补救**：固定种子、锁环境、去掉手动步骤，把复现脚本纳入投稿材料。
- **时间尺度**: 口径为**社科 / 心理学的单个实验或调查数据集**：描述性检查 2–5 天，主分析 1–2 周，稳健性检验 1–3 周，可复现脚本整理 3–7 天。**生物信息与计算方向**的分析时间主要花在流水线搭建与算力等待上，与上面不同量级。**临床试验的统计分析**由统计师按预先锁定的分析计划执行，锁库到出主结果的节奏由方案规定，不适用上述任何数字。
- **中国侧差异**:
  - 国内课程体系里统计训练在很多院系偏薄，实践中大量依赖统计咨询与外包分析。外包本身不违规，但**必须**保证作者中有人能对分析负责并解释每一步——找不出这个人时，署名与责任就出了问题 `evidence: [T03-S011]`。
  - 「统计显著」在国内的评价与答辩语境里仍有很强的话语权，导致不显著结果被弃置的压力比英文攻略描述的更大。务实做法是在开题时就把不显著结果的去处想好（注册报告、预印本、或作为方法学贡献发表）。
  - 中文期刊与国际期刊对统计报告的严格程度差异明显，按国际规范做的分析在投国内刊时可能被要求「简化」，这时不要删掉不确定性区间与稳健性检验，可移入附录。
- **近期变化**: `last_updated: 2026-09`。两条：多重宇宙 / 规格曲线一类的稳健性分析在近 24 个月从社科扩散到计算社会科学与更广的实证领域，并出现了跨学科的方法指南与专门讨论其可视化的研究，说明它正在从「加分项」变成「被审稿人问到就得有」`evidence: [T03-S046, T03-S047]`；同时生成式模型进入分析环节，带来一个新的报告要求——哪一步用了模型、模型版本是什么、人工核对了什么，主要出版商的编辑政策已把 AI 使用的披露写进条款 `evidence: [T03-S039, T03-S010]`。
- evidence: [T03-S050, T03-S027, T03-S046, T03-S047, T03-S028, T03-S003]

### 7. 图表与结果呈现 (Decay risk: low)

- **触发场景**: 结果出来要做图；投稿前按目标刊的格式要求改图；做汇报或海报；审稿人说图看不懂；论文被质疑图像有问题。
- **入门 SOP（最少步骤）**:
  1. **先写图注再画图**。交付物：每张图一句话——这张图要让读者相信什么。做完的标准：一张图只讲一件事，讲两件事就拆成两张。
  2. **选对图形**。交付物：图形类型的选择理由（比较用什么、分布用什么、关系用什么、随时间变化用什么）。做完的标准：不用条形图去表达分布——尽量展示原始数据点或分布形状，而不只是均值加误差棒。
  3. **把不确定性画出来**。交付物：区间、分布或数据点。做完的标准：读者能看出结论有多确定，而不只是看出哪根柱子高。
  4. **可及性检查**。交付物：色觉障碍模拟检查通过 + 不依赖颜色单独编码信息（同时用形状、线型、直接标注）。做完的标准：图印成灰度仍然读得懂 `evidence: [T03-S042, T03-S049]`。
  5. **按目标刊的规格出图**。交付物：符合尺寸、分辨率、字号、字体、文件格式要求的图文件。做完的标准：不用编辑部返工。
  6. **图像完整性自查**（尤其涉及显微、电泳、影像类图像）。交付物：原始未处理图像存档 + 一份处理记录（做了什么调整、是否全图统一）。做完的标准：任何调整都作用于整幅图、不改变原始数据的含义，且原图随时可提供 `evidence: [T03-S041]`。
  7. **给别人看一次**。交付物：一位非本方向的同行看图 30 秒后的复述。做完的标准：他复述的就是你写的那句图注。
- **资深路径**: **跳过**在软件界面里逐个调整（资深者用脚本出图，改一个参数全部重绘，投不同刊时切换主题即可）；**跳过**装饰性元素（3D 效果、渐变、无信息量的网格与边框一律不加）。**优化**第 1 步——先在纸上画出论文的全部主图并排序，让图序本身就是论文的故事线，写作时按图写；**优化**配色——项目开始时就定一套色板并全程复用，让同一个变量在所有图里是同一个颜色。**额外**做的：为每张图保留生成脚本与输入数据，随论文一起归档；额外准备同一张图的三个版本（论文版、幻灯版、海报版）字号与信息密度不同；额外做一次「误读测试」——找人只看图不看文，看他会得出什么结论，如果他得出的结论比你的数据支持得更强，说明图在暗示过强的东西。
- **硬约束**:
  - **图像完整性**：主要出版商的政策允许一定程度的图像处理（有些技术不可避免），但**最终图像必须正确代表原始数据**；调整须作用于整幅图像；编辑可使用软件筛查图像操作，并可在评审期间要求提供未处理的原始文件，提供不了可能导致评审中止。数据美化（data beautification）不被接受 `evidence: [T03-S041]`。
  - **可及性**：期刊侧已明确建议避免红绿对照、使用色觉障碍安全的色板，并且不要只用颜色编码信息 `evidence: [T03-S042, T03-S049]`。
  - 报告规范里的图是硬要求而不是可选项：随机对照试验必须有受试者流程图（CONSORT 2025）；系统综述必须有四阶段筛选流程图（PRISMA 2020）`evidence: [T03-S003, T03-S002]`。
  - 复用他人已发表的图需要授权与出处说明，具体按目标刊与原刊的许可条款办 `evidence: [T03-S039]`。
- **常见失败模式**:
  1. **症状**：图里只有均值和误差棒，审稿人要求「显示原始数据」 → **根因**：条形图掩盖了分布与样本量 → **补救**：改成点图 / 箱线叠加数据点 / 分布图，n 小的时候尤其必要。
  2. **症状**：图在打印稿或投影上完全分不清哪条是哪条 → **根因**：只用颜色区分、红绿对照、线太细 → **补救**：加线型与直接标注，跑一次色觉障碍模拟。
  3. **症状**：编辑部反复要求重交图文件 → **根因**：出图时没按目标刊规格，事后放大导致模糊 → **补救**：脚本出图并按刊设尺寸与分辨率参数，矢量优先。
  4. **症状**：被指出同一张图在不同论文里重复出现，或图内有拼接痕迹 → **根因**：拼图未标注、复用对照组图像、过度调整对比度 → **补救**：保留每一张原始图像与处理记录；任何拼接必须有明显分隔并在图注说明。这是当前被主动筛查最多的一类问题 `evidence: [T03-S041]`。
  5. **症状**：坐标轴截断或双轴让效应看起来比实际大 → **根因**：为了「效果好看」调整轴 → **补救**：轴从零开始或明确标注截断；双轴图能不用就不用。
- **时间尺度**: 口径为**一篇实证论文（社科或计算方向）的 4–6 张主图**：从有结果到出第一版图 3–7 天；打磨到投稿质量再 3–5 天；按审稿意见改图每轮 1–3 天。**生医论文中含显微 / 电泳 / 影像类图版（figure panel）的**，因为要回原始文件核对与排版，通常比上面多一倍时间。这些是常见经验区间不是标准。
- **中国侧差异**:
  - 国内有成熟的图表代做与「润色美化」服务市场，其中大量服务处在从排版协助到实质性代做的连续谱上。边界很清楚：排版与美工协助可以，但**不得改变数据所表达的内容**；由他人代为编造或修饰实验图像属于明确的科研失信行为 `evidence: [T03-S021, T03-S041]`。
  - 中文期刊对图的格式要求与国际刊差异较大（字体、单位写法、图注位置），一稿两投两种格式是常态，用脚本出图能显著降低这部分成本。
  - 汇报与答辩场景对「图要好看」的要求在国内更强，但答辩用图与论文用图的标准不同——答辩图可以简化，论文图不能。
- **近期变化**: `last_updated: 2026-09`。两条：图像筛查已从「有人举报才查」变成常规化——主要出版商对随机抽取的论文做图像抽查，投稿前自查图像完整性已经是标准动作 `evidence: [T03-S041]`；生成式模型能生成看起来像实验图的图像，出版商相应收紧了对原始文件的索取与 AI 生成内容的披露要求，涉及科研数据的图像一般不允许由生成式模型产生 `evidence: [T03-S039, T03-S010]`。
- evidence: [T03-S041, T03-S042, T03-S049, T03-S003, T03-S002, T03-S021]

### 8. 论文写作 (Decay risk: low)

- **触发场景**: 结果稳定了要成文；导师说「先把初稿写出来」；预印本要挂；学位论文要拆成期刊论文。
- **入门 SOP（最少步骤）**:
  1. **先定一句话结论与一个目标刊**。交付物：一句话（本文发现了什么）+ 一个目标刊 + 该刊的作者指南与字数限制。做完的标准：这句话就是将来的标题内容，且符合目标刊的体裁。
  2. **搭骨架：图先于文**。交付物：主图顺序 + 每张图一句话 + 每个小节的主题句列表。做完的标准：只读主题句就能读懂全文逻辑 `evidence: [T03-S051]`。
  3. **先写方法**（最容易写、也最不受心情影响）。交付物：详细到能被重做的方法学部分。做完的标准：对照目标研究类型的报告规范清单逐条打勾——随机对照试验对 CONSORT 2025，观察性研究对 STROBE，动物实验对 ARRIVE 2.0，定性研究对 COREQ 或 SRQR，系统综述对 PRISMA 2020 `evidence: [T03-S003, T03-S005, T03-S006, T03-S007, T03-S008, T03-S002]`。
  4. **写结果**：只描述，不解释。交付物：按图顺序组织的结果段落，每段一个发现，报告效应量与不确定性。做完的标准：没有「证明」「说明了」这类解释词。
  5. **写引言的漏斗**：从这个领域为什么重要 → 已知什么 → 缺什么 → 本文做什么。交付物：通常 3–5 段。做完的标准：最后一段与你的一句话结论对得上，且中间没有跳步。
  6. **写讨论**：主要发现 → 与已有工作的关系 → 机制或解释 → **局限** → 意义与下一步。交付物：讨论部分。做完的标准：局限一节写的是真正会削弱结论的东西，不是「样本量还可以更大」这种套话。
  7. **最后写标题与摘要**。交付物：标题、摘要、关键词。做完的标准：摘要能独立成立，且摘要里的每个数字都能在正文找到出处。
  8. **自查与外审**。交付物：报告规范清单对照表、参考文献核对、共同作者的书面确认。做完的标准：每一条参考文献都被真正读过、每个作者都看过并同意这一版。
- **资深路径**: **跳过**从引言写起（几乎所有有经验的作者都不从第一段开始写）；**跳过**边写边查文献（先写完把待补引用标出来，最后统一补，否则每次查文献都会打断写作）。**优化**第 2 步——把骨架直接写成会议报告的幻灯，讲一遍给同事听，讲不通的地方就是文章的结构问题；**优化**修改——先改结构（段落顺序、每段主题句），再改句子，最后改词，顺序反了会浪费大量时间。**额外**做的：写一份「审稿人会怎么打这篇」的自评，把最狠的三条质疑提前写进讨论的局限；额外准备一版给非本方向读者的通俗摘要（很多刊要求，也能帮你发现自己没讲清的地方）；额外在定稿前跑一遍报告规范清单并把对照表作为投稿附件（很多刊强制要求）`evidence: [T03-S001]`。
- **硬约束**:
  - 署名按 **ICMJE 四条标准**（对实质性贡献、起草或批判性修改、最终批准、对全部工作负责——**四条必须同时满足**），不符合的列致谢；CRediT 只描述「谁做了什么」，不决定「谁能当作者」，两者不能互换使用 `evidence: [T03-S011, T03-S012]`。
  - ICMJE 建议的现行版本为 **2026 年 1 月版**，其中 AI 相关内容已独立成节，另有数据访问条款 `evidence: [T03-S010, T03-S009]`。
  - 报告规范是写作而不是投稿前才用的清单，且必须用现行版本——引 CONSORT 2010 / SPIRIT 2013 这类已被取代的版本是最省力的外行识别器 `evidence: [T03-S001, T03-S003, T03-S004]`。
  - 红线（只作为识别信号呈现，不提供做法）：代写代投、买卖署名、编造与篡改数据、把一份工作拆成多篇最小可发表单元、引用操纵、赠予署名——这些在中国的《科研失信行为调查处理规则》与出版伦理机构的核心原则里都属于明确禁止并从重处理的行为 `evidence: [T03-S021, T03-S013]`。
- **常见失败模式**:
  1. **症状**：写了三个月还在引言 → **根因**：从最难的部分开始，且边写边查文献 → **补救**：先写方法，引用留占位符。
  2. **症状**：审稿人说「看不出新在哪」 → **根因**：引言的漏斗缺了「缺什么」那一层，或缺口与本文做的事对不上 → **补救**：把引言最后一段和摘要最后一句并排读，不一致就重写引言。
  3. **症状**：方法写得别人重做不出来 → **根因**：按「我做过所以我知道」写，省略了参数、版本、来源 → **补救**：对照报告规范清单逐条补；把方法给组里新人读，问他会卡在哪。
  4. **症状**：讨论写成了结果的重复 → **根因**：没有区分「观察到什么」和「这意味着什么」 → **补救**：讨论第一段只写主要发现一句话，其余全部用来谈关系、机制、局限与意义。
  5. **症状**：投稿后合作者说「这版我没看过」 → **根因**：作者最终批准这一步被跳过 → **补救**：投稿前留一轮固定的书面确认（这是署名四条标准里的一条，不是礼节）`evidence: [T03-S011]`。
- **时间尺度**: 口径为**社科 / 计算方向、数据已就绪的一篇实证论文**：骨架 3–5 天，方法 1 周，结果 1–2 周，引言 1 周，讨论 1–2 周，标题摘要与自查 3–5 天，合作者回稿等待另计——**首篇论文的作者通常是这个区间的两到三倍**。**生医实验论文**常因补实验而反复中断，不适合按连续工时估。**学位论文改写成期刊论文**主要工作量在删（学位论文的文献综述与方法细节需要压缩到期刊体量），通常 2–6 周。这些都是经验区间，不是任何机构的口径。
- **中国侧差异**:
  - 英语写作本身是额外成本。**语言润色是允许的、也是被广泛接受的**（很多出版商自己提供），但边界很清楚：润色不得改变学术内容，且不得由他人代写实质内容——代写在中国是明文列举的科研失信行为 `evidence: [T03-S021]`。
  - 学位论文与期刊论文在国内是两套评价体系：学位论文有抽检制度、有格式与查重的硬性要求，期刊论文按目标刊的作者指南。两者的写法差异比英文攻略里描述的更大，不要指望一稿两用。
  - 「一稿多投」在中国语境里包含中英文双语重复发表这一常见情形，它在期刊政策与国内规则里都属于禁止行为；如果确有翻译发表的需要，必须两边编辑都事先知情并同意、并注明出处 `evidence: [T03-S021, T03-S013]`。
  - 国内不少课题组用中文写初稿再翻译，这条路的风险在于中英文的论证结构不同（中文习惯先铺垫后结论，英文期刊要求先给结论），翻译出来的文章常被审稿人评为「结构松散」。务实做法是骨架直接用英文的主题句写。
- **近期变化**: `last_updated: 2026-09`。两条：AI 写作辅助从灰色地带变成有明确规则的领域——ICMJE 2026 年 1 月版把 AI 单独成节，主要出版商的编辑政策统一要求披露使用方式且**不得把 AI 列为作者**（AI 无法承担作者责任）`evidence: [T03-S010, T03-S039]`；报告规范在 2025 年集中换版（CONSORT 2025、SPIRIT 2025），写作前必须去规范总登记处确认当前版本号 `evidence: [T03-S001, T03-S003, T03-S004]`。
- evidence: [T03-S011, T03-S012, T03-S010, T03-S009, T03-S001, T03-S003, T03-S021, T03-S013]

### 9. 期刊选择与投稿 (Decay risk: high)

- **触发场景**: 稿子成型要投；被拒了要转投；导师说「投个好一点的」；有人推荐一本你没听过的刊；被期刊约稿或收到「快速发表」邀请。
- **入门 SOP（最少步骤）**:
  1. **列 3–5 本候选刊并核对范围**。交付物：候选表，每本写清体裁（原创研究 / 短报告 / 综述）、字数限制、读者是谁、近两年有没有发过同类工作。做完的标准：能指出每本刊上最近一篇与你最像的论文。
  2. **做可信度自查**。交付物：对每本候选刊逐项打勾——出版商与编委会信息是否可查、同行评审流程是否写明、是否被你认可的索引或目录收录、费用是否在投稿前明示、联系方式是否真实。用投稿前核查清单与开放获取期刊目录的收录判据作为工具 `evidence: [T03-S053, T03-S031, T03-S032, T03-S054]`。做完的标准：任何一项存疑就不投。
  3. **决定预印本要不要先挂**。交付物：一个决定 + 目标刊对预印本的政策截图或链接。做完的标准：确认目标刊接受已发预印本的稿件（多数接受，但少数刊与少数学科不接受），并知道挂出后怎么更新版本 `evidence: [T03-S085]`。
  4. **确定署名顺序与贡献声明**。交付物：作者名单与顺序（全体书面确认）+ 贡献声明（用贡献者角色分类法逐人逐项）+ 通讯作者 + 利益冲突声明。做完的标准：每位作者都满足署名四条标准，不满足的移入致谢 `evidence: [T03-S011, T03-S012]`。
  5. **按目标刊格式改稿**。交付物：符合该刊作者指南的正文、图、参考文献格式 + 必需的清单与声明（报告规范清单、数据可用性声明、伦理批件号、注册号、AI 使用披露）。做完的标准：投稿系统的必填项都有对应材料 `evidence: [T03-S039, T03-S010]`。
  6. **写投稿信**。交付物：一页——本文做了什么、为什么适合这本刊、有什么新意、声明未一稿多投与未重复发表、（可选）推荐或回避的审稿人及理由。做完的标准：编辑只读这一页就能判断要不要送审。
  7. **提交并记录**。交付物：投稿日期、稿号、系统里的状态。做完的标准：有一份自己的投稿台账，能回答「这篇现在在哪、投了多久」。
- **资深路径**: **跳过**「先投最高的试试」这种阶梯式投法中最不现实的那一两级（资深者按范围匹配度而不是按声望排序，因为编辑的桌拒往往在几天内就来、不匹配的投稿只是浪费时间）；**跳过**从零改格式（先投一版符合大多数刊通用要求的稿，只在被送审后按要求精改）。**优化**第 1 步——直接找目标刊近两年的相关论文，看它们的编辑是谁、审稿人可能是谁；**优化**投稿信——把「为什么适合这本刊」写成对该刊近期发表工作的具体呼应，而不是套话。**额外**做的：投稿前先请一位组外同行读一遍（一次内部预审能省掉一整轮外审）；额外准备好被拒后的转投计划（下一本刊、要改什么），拒稿当天就能启动；额外查一遍目标刊的开放获取政策与费用（含所在机构有没有转换协议或减免），以及资助机构的公共获取要求，避免接受后才发现付不起或不合规 `evidence: [T03-S059, T03-S060]`。
- **硬约束**:
  - **署名**按 ICMJE 四条标准判定，CRediT 只描述贡献不决定作者资格 `evidence: [T03-S011, T03-S012]`。
  - **临床试验**须在首例受试者入组前于世界卫生组织认证的一级注册平台或同等平台注册，否则多数医学期刊不予考虑 `evidence: [T03-S061, T03-S009]`。
  - 一稿多投、重复发表（含中英文双语重复发表）在期刊政策与中国的规则里都属于禁止行为 `evidence: [T03-S013, T03-S021]`。
  - 期刊的透明度要求可按 TOP 分级框架预判并提前准备 `evidence: [T03-S028]`。
  - **红线，只作为识别信号呈现**：任何承诺「包发表 / 包过审 / 加快见刊」的中介、任何提供代投或买卖署名位次的服务、任何以「合作」名义要求把不参与工作的人加进作者名单的要求——买卖、代写、代投论文在中国是明文列举并从重处理的科研失信行为，不存在灰色地带 `evidence: [T03-S021]`。
  - 掠夺性期刊没有权威黑名单可依，判定要靠**正向核查清单**：德尔菲共识给出的定义强调「以自身利益为先、以误导性信息、偏离最佳编辑与出版实践、缺乏透明度、使用侵扰性招揽手段为特征」`evidence: [T03-S055]`。
- **常见失败模式**:
  1. **症状**：投出去几天就被桌拒（desk reject） → **根因**：范围不匹配，或投稿信没说清为什么适合 → **补救**：回到第 1 步用「该刊近两年有没有发过同类工作」这条硬判据筛，不看声望看匹配。
  2. **症状**：接受后收到一笔没预期的费用 → **根因**：没在投稿前确认开放获取政策与费用，或投了以收费为主要目的的刊 → **补救**：投稿前把费用写进候选表；费用信息不在投稿前明示的刊直接排除 `evidence: [T03-S053]`。
  3. **症状**：合作者在接受阶段提出署名顺序有异议 → **根因**：署名在写作末期才谈 → **补救**：按工作流 12，开工前谈并留书面记录；期刊与出版商都不裁定署名争议，只会把它退回作者所在机构 `evidence: [T03-S014]`。
  4. **症状**：收到某本刊主动约稿的邮件，投了之后一周就接受 → **根因**：这是掠夺性期刊最典型的招揽与「评审」模式 → **补救**：用正向核查清单逐项过；异常短的评审周期本身就是危险信号 `evidence: [T03-S055, T03-S053]`。
  5. **症状**：投稿系统要伦理批件号、注册号、数据可用性声明，临时补不出来 → **根因**：这些是在工作流 3、4、5 就该产出的交付物 → **补救**：把投稿必填项清单反向纳入项目启动清单。
- **时间尺度**: 口径为**期刊自报或作者社群经验，且各刊差异极大，不可合并成单一数字**。可以确定的结构性事实是：桌拒通常最快（以天计），送审后到第一次决定的时长由各刊自报的中位数决定、**同一学科内不同刊可以相差数倍**，从投稿到最终接受再到见刊还要加上修回轮次与排版。**正确做法**是去目标刊官网查它自报的处理时长指标（很多刊会公布中位审稿天数），并注意这是该刊自报的口径，不等于你的稿件的实际经历，也不能跨刊跨学科套用。任何「某学科平均审稿 X 个月」的说法都要问清是哪一年、哪个数据源、哪些刊、是中位数还是均值。
- **中国侧差异**:
  - **分区表这件事变了**：中国科学院文献情报中心已发布官方声明停止更新与发布《期刊分区表》（2026-03-27 声明）。这意味着「几区」这个在国内考核与奖励里被大量使用的口径失去了持续更新的来源，各单位在改用其他判据的过渡期里口径会更不一致——写材料时必须写清用的是哪一套、哪一年 `evidence: [T03-S056]`。
  - 影响因子是**期刊**的属性不是单篇论文的属性；用期刊指标替代单篇质量与人事决定，正是研究评价宣言反对的做法，中国官方版的对应文件是 2020 年破除「唯论文」的两份文件（代表作评价、禁止与奖金直接挂钩）`evidence: [T03-S057, T03-S058, T03-S022]`。
  - 国内有专门的《国际期刊预警名单》发布平台，用途是提示风险而不是给出「是否掠夺性」的判定；不要把「不在预警名单上」当作安全证明 `evidence: [T03-S040]`。
  - 「投中文刊还是英文刊」在国内是一个真实的策略问题而不是能力问题：中文刊在部分学科的评价体系里权重正在上升，但两者的审稿文化、格式要求、周期都不同，不要用同一套预期。
- **近期变化**: `last_updated: 2026-09`。三条：一是中科院分区表停更（2026-03 官方声明），期刊分级的国内口径进入过渡期 `evidence: [T03-S056]`；二是开放获取政策收紧——资助机构侧的公共获取要求在推进（如取消延迟期一类的变化），投稿前要同时看目标刊政策与自己资助机构的要求 `evidence: [T03-S060]`；三是 AI 披露从建议变成投稿系统的必填项，ICMJE 2026 年 1 月版把 AI 独立成节 `evidence: [T03-S010, T03-S062]`。
- evidence: [T03-S053, T03-S031, T03-S032, T03-S055, T03-S056, T03-S057, T03-S058, T03-S011, T03-S012, T03-S061]

### 10. 同行评审应对 (Decay risk: medium)

- **触发场景**: 收到决定信；大修或小修回稿；被拒后决定申诉还是转投；审稿人意见互相矛盾；审稿人明显误读了你的稿子；自己作为审稿人要写评审意见。
- **入门 SOP（最少步骤）**:
  1. **读懂决定信，先分类再动手**。交付物：一句话判断——小修 / 大修 / 拒稿但欢迎重投 / 拒稿 / 转投推荐。做完的标准：你知道「大修」意味着**还没决定**，「拒稿但鼓励重投」形式上**已经是拒稿**（重投通常按新稿处理），这两点是最常被误读的 `evidence: [T03-S038]`。
  2. **冷静期**。交付物：无。做完的标准：收到信的当天不回信、不改稿。
  3. **把所有意见拆成编号条目**。交付物：一张表——编号、原文（照抄）、类型（事实错误 / 方法质疑 / 解释分歧 / 表达问题 / 要求补实验）、你的处置（接受 / 部分接受 / 不接受）。做完的标准：一条不漏，包括编辑自己的意见。
  4. **先做能做的，再谈不能做的**。交付物：改好的稿件 + 变更标记版。做完的标准：所有表达与澄清类意见全部照做（这类占多数，且几乎没有争的价值）。
  5. **写逐条回复信**。交付物：结构固定——先一段总述（感谢 + 主要改动概览），然后逐条：审稿意见原文 → 我们的回应 → 具体改动位置（页码行号）。做完的标准：审稿人不用翻稿子就能看懂你改了什么。
  6. **不同意时的写法**。交付物：证据而不是态度——先复述对方的关切以证明你读懂了，再给出理由（数据、文献、方法学依据），最后说明你在稿中做了什么让读者也能看到这个权衡（例如在局限里加一段）。做完的标准：即使不接受意见，稿件也因此变好了一点。
  7. **提交前自查**。交付物：回复信与改稿一一对应、所有承诺的改动都真的做了、共同作者都看过。做完的标准：不存在「回复里说改了但稿子里没改」。
- **资深路径**: **跳过**逐条辩论（资深者把意见按重要性排序，把力气集中在决定成败的两三条上，其余照做）；**跳过**为「补一个实验」的要求自动买单（先判断这个实验是否真的改变结论，不改变的就说明理由并提供替代证据，例如敏感性分析或已有文献）。**优化**第 5 步——回复信的每一条都以「我们同意 / 我们理解但……」开头分类，让编辑一眼看出争议点有几个；**优化**时间管理——收到大修当天就排出时间表倒推，把需要合作者配合和需要补数据的部分最先启动。**额外**做的：给编辑单独写一段（编辑不是审稿人，他关心的是争议是否已解决、稿件是否还适合本刊）；额外准备一份「变更汇总表」放在回复信最前面；额外在拒稿后做一次**转投前重写**而不是原样换一本刊投——审稿意见即使来自你不认可的审稿人，也是关于「读者会怎么误读」的免费数据。
- **硬约束**:
  - 编辑与出版商**不裁定署名争议**，只能把争议退回作者所在机构调查；在调查期间编辑可能发关注声明或暂停处理 `evidence: [T03-S014, T03-S013]`。
  - 评审过程中的稿件是保密材料：审稿人不得据此获利、不得未经许可分享给第三方（含把稿件贴进外部生成式模型服务），主要出版商与出版伦理机构的行为准则对此有明确条款 `evidence: [T03-S063, T03-S039]`。
  - 建议或回避审稿人须真实：伪造审稿人身份与邮箱（假评审）在中国的《发表学术论文「五不准」》与《科研失信行为调查处理规则》里都是明文红线，只作为识别信号呈现 `evidence: [T03-S021]`。
  - 部分期刊实行透明同行评审（评审意见与作者回复随论文一并公开），投稿时就要知道自己的回复信将来会不会被公开 `evidence: [T03-S084]`。
- **常见失败模式**:
  1. **症状**：把「大修」当成「快接受了」，改得敷衍 → **根因**：误读决定信的语义 → **补救**：把大修当成一次新的说服机会，按第 3–6 步全套走一遍 `evidence: [T03-S038]`。
  2. **症状**：回复信写成情绪对抗，编辑直接拒稿 → **根因**：把审稿意见当成人身评价 → **补救**：冷静期 + 固定模板（复述关切 → 给证据 → 说明稿中的处理）；态度不能替代证据，但坏态度可以单独毁掉一篇能过的稿。
  3. **症状**：两位审稿人意见相反，两边都想满足，改成四不像 → **根因**：没有请编辑仲裁 → **补救**：明确写出冲突、给出你的选择与理由，请编辑判断；这是编辑的职责范围内的事。
  4. **症状**：修回拖了几个月，期刊按撤稿处理或要求重新投稿 → **根因**：没有注意修回截止日、也没申请延期 → **补救**：收到决定信当天就确认截止日；需要更多时间时提前写信申请，这在多数刊是常规操作。
  5. **症状**：回复信里承诺的改动没真的落到稿子里 → **根因**：回复信与改稿分开写、最后没对照 → **补救**：提交前逐条对照页码行号。
- **时间尺度**: 口径为**各期刊自行规定的修回期限，差异极大且必须按目标刊的决定信为准**——常见的结构是小修给较短的期限、大修给较长的期限，很多刊允许申请延期。作者侧的实际投入：**社科 / 计算方向的小修**通常 3–7 个工作日；**大修**若不需补数据通常 2–4 周，需要补数据或补实验则由实验本身的周期决定，**生医方向补一组实验以月计并不罕见**。从修回到最终决定的时长同样由各刊自报口径决定，不可跨刊套用。
- **中国侧差异**:
  - 英语表达带来的额外损耗真实存在：相当一部分「表达不清」类意见其实是语言问题。语言润色可以用（很多出版商自己提供），但**内容不能代写**，且回复信必须由作者自己组织论证 `evidence: [T03-S021]`。
  - 国内考核的时间压力常导致「不敢大修、直接转投」，但转投等于放弃已经拿到的免费意见。务实做法是：即使决定转投，也先按意见改一遍。
  - 中文期刊的审稿文化与国际刊不同（意见更简短、更偏格式与规范、有时不给逐条理由），不要用应对国际刊的模板原样应对中文刊，反之亦然。
  - 「找关系打招呼」在国内的传说很多，但它落在期刊政策与国内规则的禁区里，且现代投稿系统的利益冲突申报会放大风险——这只作为要识别与避开的对象呈现 `evidence: [T03-S021, T03-S013]`。
- **近期变化**: `last_updated: 2026-09`。三条：透明同行评审（公开评审意见与作者回复）在主要出版商的部分刊已成默认，回复信要按「将来可能被公开」来写 `evidence: [T03-S084]`；生成式模型进入评审两端，出版商相继明确——把未发表稿件上传到外部模型服务违反保密义务，审稿意见由模型代写也需披露或被禁止 `evidence: [T03-S039, T03-S063]`；论文工厂与批量造假的压力使编辑部增加了投稿前筛查（图像、引用、身份），作者侧的表现是：投稿后可能收到关于原始数据与身份核验的额外问询，这是常规流程而不是被怀疑 `evidence: [T03-S041, T03-S037]`。
- evidence: [T03-S038, T03-S014, T03-S013, T03-S063, T03-S084, T03-S021, T03-S039]

### 11. 基金申请 (Decay risk: high)

- **触发场景**: 年度申报季（国内以国家自然科学基金的集中接收期为最强节点）；博后或新 PI 起步要拿第一笔；项目结题要接续；落选后决定再战。
- **入门 SOP（最少步骤）**:
  1. **先读规则再想内容**。交付物：目标资助机构当年度的申请须知 / 项目指南 / 政策总纲的关键条款摘录——申请人资格、限项要求、经费科目、提交截止时间、依托单位的内部截止时间。做完的标准：你知道自己**有没有资格**申请，以及本单位比机构截止日提前多久 `evidence: [T03-S064, T03-S024, T03-S068, T03-S069]`。
  2. **把科学问题写成一句话**。交付物：一句话——本项目要回答什么、为什么现在、为什么是你。做完的标准：非本方向的同行听完能复述。
  3. **写立项依据**。交付物：国内外研究现状 → 关键科学问题 → 本项目的切入点。做完的标准：现状综述的落点就是你的问题，中间没有跳跃。
  4. **写研究方案**。交付物：研究内容、研究目标、拟解决的关键科学问题、研究方法与技术路线、可行性分析、创新点。做完的标准：每一条研究内容都对应一个可验证的产出。
  5. **写工作基础与研究条件**。交付物：前期结果（预实验数据最有说服力）、团队、平台、已有合作。做完的标准：能回答「凭什么是你能做成」。
  6. **做预算**。交付物：按当年度经费科目与比例限制编制的预算表 + 依据说明。做完的标准：每一笔都能说出算法，且符合当年度的科目口径（口径会变，必须按当年文件）。
  7. **形式审查自查**。交付物：一张自查表——签字盖章、附件齐全、限项、格式、字数、匿名要求（部分类型要求正文中不出现申请人信息）。做完的标准：把本单位科研处的退回原因清单逐条对完 `evidence: [T03-S024]`。
  8. **找人评一遍**。交付物：至少两位读者的意见——一位本方向、一位跨方向。做完的标准：跨方向的读者能说出你的创新点。
- **资深路径**: **跳过**从零写（有前一版本子的先做差异化改写，把落选意见逐条对应到修改点）；**跳过**追热点（资深者按自己的长期主线布局，热点只作为切入角度而不是主体）。**优化**第 3 步——立项依据按「评审人视角」倒着写：评审人在有限时间里要判断的是问题重不重要、方案可不可行、你能不能做成，把这三个判断的证据放在最显眼处；**优化**时间分配——把最多时间给摘要、立项依据的第一段、研究目标这三处，因为它们决定评审人的第一印象。**额外**做的：提前一年布局，把关键的前期结果做出来并发表（工作基础比任何文字都有说服力）；额外提前联系合作单位拿承诺函与共享条件说明（这类文件常在最后一周卡住流程）；额外准备一份「同行评议模拟」——请两三位同事按真实评审表打分并写意见。
- **硬约束**:
  - **形式审查是硬门槛**：不符合项目指南与管理办法要求的申请**不予受理**；在通告发布前或接收截止时间之后提交的申请不予受理；依托单位须对申请材料的真实性、完整性、合法性进行审核。这些是资格性判定，不进入学术评审 `evidence: [T03-S024, T03-S023]`。
  - 基金申请中的抄袭、编造、篡改、重复申报、伪造评审意见等，按资助机构自己的调查处理办法处理，并有具名通报的处理决定公开可查——这既是红线也是可查证的判例来源 `evidence: [T03-S066, T03-S067, T03-S021]`。
  - 与美国资助机构相关的项目：数据管理与共享计划是拨款条件（2023 年起），政策总纲逐年更新，须按申请当年的版本 `evidence: [T03-S025, T03-S026, T03-S068, T03-S069]`。
  - 负责任研究行为的国家层面口径（中国）在《负责任研究行为规范指引（2023）》里有系统表述，各单位的科研诚信管理制度有示范文本可参照 `evidence: [T03-S070, T03-S071]`；欧洲侧的对应文本是 2023 修订版的欧洲科研诚信行为准则 `evidence: [T03-S072]`。
- **常见失败模式**:
  1. **症状**：材料在形式审查阶段被退，连评审都没进 → **根因**：把申请须知当参考而不是判据（限项、资格、格式、截止时间任一不符即出局） → **补救**：写内容之前先做一遍形式审查自查表；本单位的内部截止日比机构截止日早，按前者排期 `evidence: [T03-S024]`。
  2. **症状**：评审意见说「科学问题不清楚」 → **根因**：立项依据写成了文献综述，没有落到一个具体问题 → **补救**：把「关键科学问题」提到显眼位置并用一句话陈述；综述只保留支撑这个问题的部分。
  3. **症状**：评审意见说「工作基础薄弱」 → **根因**：没有前期结果，或有但没写进去 → **补救**：这是需要提前一年布局的事，当年补不了；退而求其次是补充预实验数据与团队既有产出。
  4. **症状**：研究内容写了五条，看起来很饱满，评审说「过于宽泛、不聚焦」 → **根因**：把「多」当成「强」 → **补救**：砍到二到三条，每条配清晰的验证方式。
  5. **症状**：落选后原样再投，第二年又落选 → **根因**：没有把评审意见转成修改清单 → **补救**：逐条对应，改不了的（如工作基础）就用一年时间补，而不是重写措辞。
- **时间尺度**: 口径为**中国国家自然科学基金面上 / 青年类项目的常见节奏**：集中接收期在每年上半年（**具体日期每年由当年通告规定，必须查当年文件，不能按往年推**）；从动笔到定稿，**首次申请者常见为 2–3 个月的断续投入**，有前一版本子的重写通常 3–6 周；依托单位的内部审核与提交需在机构截止日前预留时间（各单位不同，常见为提前一到两周）。评审与公布结果的周期由当年通告规定。**美国 NIH 类项目**的周期结构完全不同（有固定的多个接收轮次与再申请机制），不可用上面的数字类比。**社科类基金**的节点与理工类不同，同样按当年通告为准 `evidence: [T03-S024, T03-S064, T03-S068]`。
- **中国侧差异**:
  - 本子的文体是中国侧独有的：立项依据、研究内容、研究目标、拟解决的关键科学问题、技术路线、可行性分析、特色与创新、年度计划与预期成果——这是一套固定结构，与英文 proposal 的写法差异很大，照搬英文攻略会写出不符合评审预期的本子 `evidence: [T03-S064]`。
  - **限项与资格规则**（一个人同时能申请与在研几项、哪些身份能申请）是国内特有的强约束，且逐年调整，必须查当年度通告 `evidence: [T03-S024, T03-S065]`。
  - 依托单位这一层是英文攻略里没有的：单位科研处的内部审核、盖章、系统提交都是关键路径，个人无法绕过。
  - 评审导向在跟着评价改革走：破除「唯论文」的 2020 年文件把代表作评价写进政策，资助机构近年也在公布年度改革举措，写本子时对「成果」的呈现方式应按当年度的口径而不是往年经验 `evidence: [T03-S065, T03-S022]`。
- **近期变化**: `last_updated: 2026-09`。三条：资助机构逐年发布改革举措，申请与评审的规则处在持续调整中，**往年经验的失效速度是本文件里最快的之一**——这也是本条工作流被标为高失效风险的原因 `evidence: [T03-S065]`；具名案件通报持续发布，构成可查证的红线判例 `evidence: [T03-S067]`；国际侧的数据共享与政策总纲同样逐年更新（2026 年有新版政策总纲与更新版数据管理计划要素），跨国合作项目要按申请当年的版本准备 `evidence: [T03-S069, T03-S026]`。
- evidence: [T03-S024, T03-S023, T03-S064, T03-S065, T03-S066, T03-S067, T03-S068, T03-S069, T03-S070, T03-S072]

### 12. 实验室协作与署名协商 (Decay risk: medium)

- **触发场景**: 新项目启动、有人中途加入或离开、多组合作、学生毕业要带走数据、师兄师姐留下半成品、跨单位或跨国合作、合作关系出现分歧。
- **入门 SOP（最少步骤）**:
  1. **开工前谈署名**。交付物：一份书面记录（邮件即可）——预期的作者名单与顺序、通讯作者是谁、依据是什么、什么情况下会调整。做完的标准：每个人都回复确认过 `evidence: [T03-S011]`。
  2. **同时定贡献口径**。交付物：用贡献者角色分类法把 14 类角色分配到人（谁负责构思、方法、软件、验证、数据管理、写作原稿、写作审阅与编辑等）。做完的标准：这份表将来可以直接变成论文的贡献声明 `evidence: [T03-S012]`。
  3. **定数据与代码的归属与交接规则**。交付物：一段说明——数据存在哪、谁能访问、离组时怎么交接、发表后归档在哪。做完的标准：任何人明天离开，工作都能继续。
  4. **定沟通节奏**。交付物：组会频率与形式、进度记录在哪、决定写在哪。做完的标准：三个月后能查到「当时为什么这么定」。
  5. **跨单位合作先签好条件**。交付物：合作协议或至少一份书面备忘——各方投入、成果归属、署名、数据共享与出境的限制。做完的标准：涉及人类遗传资源或个人信息的部分已按法规走完审批或备案路径 `evidence: [T03-S018, T03-S019]`。
  6. **定期复核**。交付物：项目中期把第 1 步的记录拿出来对一次，按实际贡献调整并重新确认。做完的标准：调整有记录、有各方确认，不是口头默认。
  7. **通讯作者明确责任**。交付物：一句话——通讯作者对全文的完整性与准确性负责、负责与期刊沟通、负责保存原始数据、负责回应发表后的问询。做完的标准：担任这个角色的人知道这不是荣誉而是责任 `evidence: [T03-S011, T03-S009]`。
- **资深路径**: **跳过**「等有结果了再谈署名」（这是最贵的拖延，成本在几年后一次性爆发）；**跳过**口头约定（口头约定在争议发生时等于不存在）。**优化**第 1 步——把署名规则写进课题组的书面手册而不是每次单独谈，新人入组时一并交付，这样每次谈的只是这个项目的差异；**优化**第 3 步——用统一的仓库与命名规范（见工作流 5）让交接变成默认状态而不是离职时的专项任务。**额外**做的：给每个项目指定一位「数据负责人」，与第一作者分开；额外为学生明确「哪些工作能带走、哪些不能」，写进入组时的约定；额外为跨国合作预留合规时间并把它列入关键路径（人类遗传资源的审批或备案、数据出境、伦理的多中心审查关系）`evidence: [T03-S018]`；额外读一遍面向新 PI 的实验室管理手册与科研行为规范教材，把招人、带团队、处理冲突当成可学的技能而不是天赋 `evidence: [T03-S073, T03-S074]`。
- **硬约束**:
  - **署名四条标准必须同时满足**：对构思或数据有实质性贡献、起草或批判性修改、批准最终版本、同意对全部工作负责。不满足四条的列致谢，**不得以资历、职务、提供经费或提供样本为由赠予署名**；反过来，也不得把符合标准的人排除在外 `evidence: [T03-S011]`。
  - **贡献者角色分类法只描述做了什么，不决定谁能当作者**——两者是不同层次的工具，混用是常见的说法错误 `evidence: [T03-S012, T03-S011]`。
  - **期刊与出版商不裁定署名争议**，只会把争议退回作者所在机构调查，期间可能暂停处理或发关注声明 `evidence: [T03-S014, T03-S013]`。
  - 中国侧：违规署名（含代写代投、买卖署名、无实质贡献而署名）在《发表学术论文「五不准」》与《科研失信行为调查处理规则》里是明文列举的失信行为，高校侧另有教育部令第40号规定内部处理程序 `evidence: [T03-S021, T03-S022]`。
  - 涉及人类遗传资源的国际合作须审批或备案，对外提供信息须事先报告并提交备份——这是合作协议里必须写进去的条款而不是事务性细节 `evidence: [T03-S018]`。
- **常见失败模式**:
  1. **症状**：投稿前一周为作者顺序吵起来，项目停摆 → **根因**：署名在最后谈 → **补救**：本次只能按实际贡献逐条对照四条标准协商，并请一位双方都认可的第三方（如系主任或学术委员会）居中；下次开工前谈。
  2. **症状**：学生毕业带走了唯一一份数据与代码 → **根因**：没有统一仓库与交接规则 → **补救**：交接清单固定化（仓库 + README + 数据字典 + 凭据移交），并在毕业流程里设为必经环节。
  3. **症状**：某位「挂名」的合作者在论文出问题时说自己不了解内容 → **根因**：赠予署名 → **补救**：这是四条标准第四条（对全部工作负责）要防的正是这种情况；不了解内容的人本来就不应该是作者 `evidence: [T03-S011]`。
  4. **症状**：合作方要求把数据传到境外服务器，事后发现违规 → **根因**：把数据出境当技术问题而不是合规问题 → **补救**：合作意向阶段就把合规路径写进协议并启动审批 `evidence: [T03-S018]`。
  5. **症状**：合作破裂，一方单独投稿 → **根因**：没有书面约定成果归属 → **补救**：期刊不裁定，最终由机构处理；能做的是保留全部书面记录（邮件、会议纪要、仓库提交历史），这些是机构调查时唯一有用的东西。
- **时间尺度**: 口径为**协商与制度动作本身，不是研究周期**：开工前的署名与贡献协商一次会议 + 一封确认邮件，通常 1–2 小时；课题组书面手册首次撰写 1–2 天，之后每年更新一次；跨单位合作协议从起草到签署，在国内高校常见为**数周**（需过科研处与法务）；**涉及人类遗传资源的国际合作审批或备案要按数月预留**，这是最容易被低估的一项 `evidence: [T03-S018]`。争议一旦进入机构调查程序，时间尺度完全由程序决定，个人无法压缩。
- **中国侧差异**:
  - 师门结构与英文攻略假设的 PI-postdoc-student 关系不同：导师在署名、课题分配、毕业时间上的实际权重更大，学生的议价空间更小。这不改变规则（四条标准是一样的），但改变可行策略——**书面记录的价值在国内更高**，因为它是争议发生时唯一可核查的东西。
  - 「导师挂通讯作者、学生一作」是国内的常见默认，但它不能替代逐条核对四条标准；同样，把不参与工作的人加进作者名单在国内被明确列为失信行为，不存在「行业惯例」的豁免 `evidence: [T03-S021]`。
  - 高校处理学术不端与署名争议有专门的部门规章（教育部令第40号，2016 年施行且现行有效），程序上由学校学术委员会负责，与科技伦理委员会是两套体系 `evidence: [T03-S022]`。
  - 学位论文另有独立的作假处理办法与抽检制度，学生的学位论文与期刊论文的责任边界与英文语境不同 `evidence: [T03-S081, T03-S082]`。
- **近期变化**: `last_updated: 2026-09`。三条：AI 使用的责任归属成为新的协商项——中国科学院科研道德委员会发布过规范使用人工智能技术的诚信提醒，主要出版商也统一规定 AI 不能作为作者，课题组需要在开工时就约定谁负责披露、披露到什么粒度 `evidence: [T03-S079, T03-S039, T03-S010]`；教育部在 2024 年发文加强高校科研诚信建设与学术不端治理，各高校近两年在陆续落成本单位实施细则，本单位规则的更新频率高于国家文件 `evidence: [T03-S080]`；科技部有科研单位科研诚信管理制度的示范文本可参照，课题组手册可以直接对齐 `evidence: [T03-S071]`。
- evidence: [T03-S011, T03-S012, T03-S014, T03-S021, T03-S022, T03-S018, T03-S073, T03-S079, T03-S080]

### 13. 出错之后：更正、关注声明、撤稿与举报 (Decay risk: medium)

> 本条只呈现**公开规范与官方口径**下的处理流程与红线，不提供任何规避性做法。

- **触发场景**: 自己发现已发表论文有错；有人在发表后评议平台或邮件里提出质疑；期刊来信问询；合作者被指控；你发现别人的论文有问题在犹豫要不要报告；单位启动调查。
- **入门 SOP（最少步骤）**:
  1. **先判断错误的性质与影响**。交付物：一段书面判断——错在哪一步（数据、分析、报告、图）、影响哪些结论、如果读者当初就知道，结论会不会实质改变。做完的标准：能回答「结论还成立吗」这一个问题 `evidence: [T03-S015]`。
  2. **保全证据**。交付物：原始数据、分析脚本、通信记录的完整副本与时间戳，任何人不得修改。做完的标准：这份材料能交给第三方复核。
  3. **告知共同作者与所在单位**。交付物：书面告知与各方确认。做完的标准：没有人是在期刊发通知时才知道。
  4. **主动联系期刊编辑**。交付物：一封说明信——发现了什么、怎么发现的、影响范围、你建议的处理方式（更正 / 撤稿）与理由 + 支持材料。做完的标准：由你而不是由举报者把事实摆到编辑桌上。
  5. **配合编辑的处理路径**。交付物：按编辑要求提供的原始数据与说明。做完的标准：理解三条路径的分界——结论不受实质影响的走**更正**；事实尚待查清、需要时间的走**关注声明**；结论已不可靠的走**撤稿** `evidence: [T03-S015, T03-S014]`。
  6. **接受结果并把它写进自己的记录**。交付物：更正或撤稿通知的链接；在个人主页与简历里如实标注。做完的标准：不隐瞒——主动更正的记录在同行眼里是加分不是减分。
  7. **如果是要报告别人的问题**：先分清是学术分歧还是可能的失信行为；前者走公开学术讨论（评论、回应、发表后评议），后者按被指对象所在单位与期刊的正式渠道提交，写清具体证据与出处，不做超出证据的断言。做完的标准：你的材料能被第三方独立核验 `evidence: [T03-S021, T03-S077, T03-S078]`。
- **资深路径**: **跳过**在公开平台上先发难（资深者知道正式渠道更有效，也更能保护自己）；**跳过**与指控者的公开对线（对线不解决事实问题，只会让编辑更难处理）。**优化**第 1 步——先请一位不相关的同行独立复核，确认错误确实存在再启动流程，避免因为误判而发起不必要的更正；**优化**第 4 步——说明信写得像一份微型调查报告（发现过程、范围界定、已排除的可能性），编辑处理起来更快。**额外**做的：同时检查这篇论文用同一套数据或代码派生出的其他论文（错误往往不止一处）；额外把纠错的经过写成方法学说明或预印本，让引用过你这篇的人能看到；额外为课题组建立一条内部纠错通道（发现问题先内部说，不必担心被追责），因为最怕的不是出错而是没人敢说。
- **硬约束**:
  - **更正 / 关注声明 / 撤稿的分界**（出版伦理机构撤稿指南）：判断依据是「读者若知晓现在已知的一切，是否会得出实质不同的结论」——否 → 更正；尚未查清且需要时间（例如数月）或质疑可信且严重但信息不足 → 关注声明；结论明确不可靠 → 撤稿。撤稿通知应在编辑确信论文严重有缺陷或有误导性后尽快发布 `evidence: [T03-S015]`。该指南 2019 年为第 2 版，**2025 年由修订版接替，新增针对论文工厂与第三方的内容** `evidence: [T03-S037]`。
  - **撤稿不等于认定作者有过错**：撤稿也可能因诚实错误发生；反过来，撤稿数据库里「没有记录」也不等于论文可信 `evidence: [T03-S076, T03-S075]`。
  - **中国的调查处理程序**：《科研失信行为调查处理规则》（2022，国科发监〔2022〕221号）是现行的全国性程序规则，明确了失信行为的种类、调查主体、程序与处理措施，其中买卖、代写、代投论文与违规署名属于明文列举并从重处理的情形 `evidence: [T03-S021]`；高校内部按教育部令第40号（2016 年施行、现行有效）处理 `evidence: [T03-S022]`；期刊学术不端行为的界定另有新闻出版行业标准 CY/T 174—2019 `evidence: [T03-S087]`。
  - **资助机构侧**另有独立的调查处理办法与具名通报制度，处理结果公开可查 `evidence: [T03-S066, T03-S067]`。
  - **发表后评议平台上的质疑是线索不是裁定**：平台自述无裁定权，图像类指控质量通常较高，方法与解释类容易变成立场之争；被评者不回应会形成单方记录 `evidence: [T03-S077, T03-S078]`。
  - **红线（只作为识别信号呈现）**：编造、篡改、剽窃；买卖、代写、代投论文；伪造同行评审人；违规署名；一稿多投与重复发表；引用操纵；把一份工作拆成多篇最小可发表单元。这些都有明文规定与处理措施，不存在「行业惯例」或「情节轻微」的自我豁免空间 `evidence: [T03-S021, T03-S013, T03-S087]`。
- **常见失败模式**:
  1. **症状**：发现错误后拖着不处理，指望没人注意 → **根因**：把纠错当成认错、担心影响评价 → **补救**：主动纠错与被举报后被动处理，在规范与同行评价里是两件性质完全不同的事；越早越好。
  2. **症状**：在公开平台与质疑者互相指责，事情越闹越大 → **根因**：把学术质疑当成人身攻击 → **补救**：把事实性回应写成一份材料交给编辑，公开场合只说「已提交编辑处理」。
  3. **症状**：只更正了被指出的那一处，其他同源论文没查 → **根因**：把问题当成孤立事件 → **补救**：凡涉及共用数据或共用流程的，全部自查一遍。
  4. **症状**：举报了但材料被认为「无法核实」 → **根因**：只有结论没有可复核的证据、或超出证据做断言 → **补救**：按「哪一篇、哪张图、哪个数字、与什么比对、来源链接」的粒度组织材料，不评价动机。
  5. **症状**：合作者单方面与期刊沟通，其他作者被蒙在鼓里 → **根因**：跳过第 3 步 → **补救**：所有与编辑的往来抄送全体作者；这既是规范也是自保。
- **时间尺度**: 口径为**编辑部与机构的程序时长，由程序决定而非作者**：出版伦理机构的指南本身指出，当调查或解决一项可信质疑需要相当时间（例如数月）时应先发关注声明——这句话本身说明这类流程的量级是**月到年**。机构调查的时长按各国各单位的程序规定，中国侧按《科研失信行为调查处理规则》的程序办理。作者侧能控制的只有前四步：从发现问题到把说明信发给编辑，**应当以天到周计而不是以月计** `evidence: [T03-S015, T03-S021]`。
- **中国侧差异**:
  - 有**成体系的国家级程序规则**（2022 年的调查处理规则）与高校部门规章（教育部令第40号），以及资助机构的独立处理办法与具名通报——这套制度密度高于多数英文攻略描述的情形 `evidence: [T03-S021, T03-S022, T03-S066, T03-S067]`。
  - 「五不准」（不准由第三方代写、不准由第三方代投、不准由第三方对论文内容进行修改、不准提供虚假同行评审人信息、不准违反论文署名规范）是国内研究者需要能背下来的五条硬红线 `evidence: [T03-S021]`。
  - 学位论文另有作假行为处理办法（教育部令第34号）与抽检制度，责任链条与期刊论文不同 `evidence: [T03-S082, T03-S081]`。
  - 举报渠道在国内是本单位科研诚信责任主体 + 上级主管部门 + 资助机构三条线，与英美的机构办公室加联邦监管机构的结构不同；材料的可核验性要求是一样的。
- **近期变化**: `last_updated: 2026-09`。三条：出版伦理机构在 2025 年发布修订版撤稿指南，新增了针对论文工厂与第三方的处理内容，这是近 24 个月最直接影响流程的一次改版 `evidence: [T03-S037, T03-S015]`；撤稿与更正数据已进入公开的元数据接口并每工作日更新，任何人都能按 DOI 查一篇论文是否被撤稿或更正——引用前查一遍已经成为可执行的常规动作 `evidence: [T03-S075, T03-S086, T03-S076]`；中国侧近两年持续在把国家规则落成单位实施细则并建立年度报告制度，本单位规则的变化比国家文件快 `evidence: [T03-S080, T03-S071]`。
- evidence: [T03-S015, T03-S037, T03-S021, T03-S022, T03-S066, T03-S067, T03-S075, T03-S076, T03-S077, T03-S087]

### 14. 发表之后：归档、传播与被质疑的应对 (Decay risk: medium)

- **触发场景**: 论文接受或上线；资助机构要求公共获取；有人写信要数据或代码；论文被媒体报道；有人在发表后评议平台提出质疑；有人做了复制研究但没复制出来；准备做年度总结或申请材料。
- **入门 SOP（最少步骤）**:
  1. **归档数据、代码与材料**。交付物：存入有持久标识符的仓储，拿到 DOI，写清元数据与使用许可；论文里的数据可用性声明指向这个 DOI。做完的标准：别人不联系你就能拿到并知道能怎么用 `evidence: [T03-S045, T03-S044, T03-S048, T03-S034]`。
  2. **满足公共获取要求**。交付物：按资助机构与所在单位的政策把论文存入指定仓储或本单位知识库。做完的标准：合规状态可查（资助机构侧的公共获取要求近年在收紧，须按当年版本）`evidence: [T03-S060]`。
  3. **让人找得到**。交付物：研究者唯一标识符与论文关联、机构主页更新、预印本版本与正式版本互相指向。做完的标准：搜你的名字能找到这篇，且各版本关系清楚 `evidence: [T03-S085]`。
  4. **写一段面向非专业读者的说明**。交付物：三到五句话——发现了什么、有多确定、不能推出什么。做完的标准：这段话可以直接给记者或做成社交媒体贴文，且不夸大。
  5. **准备好回答问询**。交付物：一份常见问题与答案（数据怎么拿、代码怎么跑、某个参数为什么这么选）。做完的标准：收到邮件当天能回。
  6. **监控被引与被质疑**。交付物：一个定期检查的动作——这篇被谁引了、引的时候是支持还是反驳；有没有出现在发表后评议平台上。做完的标准：不是靠别人转告才知道有人质疑 `evidence: [T03-S077, T03-S078]`。
  7. **被质疑时按事实回应**。交付物：一份可核验的回应（补充分析、原始数据、澄清说明），必要时联系编辑。做完的标准：区分「学术分歧」（公开讨论即可）与「可能的错误」（走工作流 13）。
- **资深路径**: **跳过**逐条回应所有网络评论（资深者只回应可核验的具体质疑，对无法核验的断言不做逐条辩驳）；**跳过**为传播而夸大（一次夸大的通稿的长期成本远高于短期关注）。**优化**第 1 步——归档在投稿时就做好而不是发表后补，把仓储 DOI 直接写进稿件；**优化**第 4 步——写通俗说明时同时写出「这项工作**不能**说明什么」，这一句能挡掉大部分误读式报道。**额外**做的：主动做一次自我复制或让组内另一人独立重跑，把结果作为附录或后续说明；额外维护一个「本文发表后的更新」页面（新证据、勘误、他人复制结果），把论文当成活文档；额外把数据与代码整理成别人真的能用的形式（一条命令跑通 + 示例数据），这比论文本身带来的长期影响常常更大。
- **硬约束**:
  - **FAIR ≠ Open**：受控访问、需申请审批的数据完全可以是 FAIR 的；涉及个人信息与人类遗传资源的数据不能因为「开放科学」就直接公开 `evidence: [T03-S034, T03-S018, T03-S019]`。
  - **中国侧**：人类遗传资源信息的对外提供或开放使用须事先报告并提交信息备份——这一条直接约束「把数据挂到国际仓储」这个默认动作 `evidence: [T03-S018]`。
  - 资助机构的公共获取要求是拨款条件的一部分，须按申请与获奖当年的版本执行 `evidence: [T03-S060, T03-S068]`。
  - 期刊的透明度与数据可用性要求按各刊政策与分级框架执行；「合理要求下可向作者索取」这种表述正在被更强的要求取代 `evidence: [T03-S028, T03-S039]`。
  - 评价侧：不得用期刊指标替代单篇质量与人事决定（研究评价宣言与十条原则的核心主张）；中国官方版对应文件是 2020 年破除「唯论文」的两份文件 `evidence: [T03-S058, T03-S022]`。
- **常见失败模式**:
  1. **症状**：有人索要数据，翻不出来或跑不通 → **根因**：归档在发表后才做，且没有做过新人测试 → **补救**：把归档提前到投稿阶段，并让组内另一人按 README 跑一遍。
  2. **症状**：媒体报道把相关说成因果 → **根因**：通稿或摘要里用了暗示因果的动词 → **补救**：主动提供「不能说明什么」那一句；发现误读后要求更正，并在自己的渠道澄清。
  3. **症状**：有人复制不出来，作者第一反应是质疑对方能力 → **根因**：把复制失败当成攻击 → **补救**：先自查（版本、参数、数据），把两边的差异当成信息；复制失败本身是科学的正常产出，不是判决。
  4. **症状**：论文引用了一篇已被撤稿的文献，被审稿人或读者指出 → **根因**：引用时没查撤稿状态 → **补救**：撤稿与更正数据已可按 DOI 公开查询，把「引用前查撤稿状态」纳入定稿清单 `evidence: [T03-S075, T03-S086]`。
  5. **症状**：几年后被问到某个细节完全答不上来 → **根因**：留痕止于论文，分析日志没归档 → **补救**：把决策日志与分析脚本一并归档（见工作流 5、6）。
- **时间尺度**: 口径为**作者侧的投入，不含期刊排版与见刊周期**：归档整理（数据 + 代码 + README + 元数据）在流程规范的项目里 **2–5 天**，在没有提前规划的项目里可能要 **2–4 周**（这就是提前做的价值）；通俗说明 1–2 小时；被引与质疑的监控是每季度 30 分钟量级的常规动作。**从接受到正式见刊**的时长由各刊自报口径决定，差异极大，不可跨刊套用。
- **中国侧差异**:
  - **数据出境是硬约束**：国际通用仓储不是默认可选项，涉及人类遗传资源信息的须先走事先报告与信息备份 `evidence: [T03-S018]`。务实做法是分层归档——可公开的挂国际仓储，受限的放境内受控访问，两层都在数据可用性声明里写清。
  - 机构知识库在国内普及度不均，很多单位没有长期可维护的存储；把归档位置写成个人网盘是常见但不可持续的做法。
  - **期刊分级的国内口径正在变**：中科院文献情报中心已停止更新与发布分区表（2026-03-27 声明），过渡期内各单位口径不一，做年度总结与申请材料时必须写清用的是哪一套、哪一年，不能只写「几区」`evidence: [T03-S056, T03-S057]`。
  - 传播侧：国内的科研传播渠道与英文攻略假设的不同，但纪律是一样的——不夸大、不把相关说成因果、不用单篇论文的结论去支持超出其范围的主张。
- **近期变化**: `last_updated: 2026-09`。三条：撤稿与更正数据进入公开元数据接口并每工作日更新，「引用前查撤稿」从愿望变成可执行动作 `evidence: [T03-S075, T03-S086]`；公共获取政策在收紧（资助机构侧取消延迟期一类的变化），发表后的合规动作变多 `evidence: [T03-S060]`；国内期刊分级口径因分区表停更进入过渡期，个人成果呈现方式需要相应调整 `evidence: [T03-S056]`。
- evidence: [T03-S045, T03-S034, T03-S018, T03-S060, T03-S075, T03-S086, T03-S056, T03-S077, T03-S028]

## 跨工作流的通用纪律

1. **任何决定都要留下可追溯的记录。** 检索式与执行日期、纳入排除的理由、分析设定的变更、署名的约定、与编辑的往来——争议发生时，能被第三方核验的书面记录是唯一有用的东西，口头约定与记忆都不算。`evidence: [T03-S002, T03-S021, T03-S014]`
2. **分析计划写在看结果之前。** 这是区分「假设检验」与「假设生成」的唯一机制；两类分析都正当，但不能互换叙述，也不能事后互换标签。偏离不是污点，隐瞒偏离才是。`evidence: [T03-S027, T03-S029]`
3. **作者顺序在开工前谈，用书面记录，中期复核一次。** 署名按四条标准逐条核对（四条必须同时满足），贡献用角色分类法描述；期刊与出版商**不裁定**署名争议，只会退回你所在机构。`evidence: [T03-S011, T03-S012, T03-S014]`
4. **每写一份东西，先去规范总登记处确认现行版本号。** 报告规范在换版（CONSORT 2025、SPIRIT 2025 取代了 2010 / 2013 版），法规在换版，期刊政策在换版；引旧版是最省力的外行识别器。`evidence: [T03-S001, T03-S003, T03-S004]`
5. **合规不是一条线而是几条并行的线。** 伦理审查、个人信息保护、人类遗传资源、动物福利、资助机构要求、期刊政策——过了一条不代表过了其他条，尤其「有伦理批件」不等于「个人信息处理合法」。`evidence: [T03-S016, T03-S017, T03-S018, T03-S019]`
6. **数字必须带口径。** 周期、接受率、通过率、费用，说的时候必须同时说清是谁在什么年份对哪个学科用什么定义统计的；某一本刊自报的中位审稿天数不能说成「这个学科的平均审稿周期」，某一年某一套分区不能说成「几区」。`evidence: [T03-S057, T03-S056]`
7. **合规与诚信的边界处不存在灰色地带。** 代写、代投、买卖署名、伪造评审人、编造与篡改数据、拆分发表、引用操纵——这些在中国有明文列举的规则与从重处理的规定，在国际侧有出版伦理机构与科研诚信准则的对应条款。识别它们、拒绝它们，不要试图区分「严重的」和「轻微的」。`evidence: [T03-S021, T03-S013, T03-S087, T03-S072, T03-S088]`
8. **每个交付物都要通过「新人测试」。** 数据仓库、分析脚本、方法学章节、交接文档——让一个没参与的人只拿着它走一遍，走不通的地方就是留痕不足的地方。这一条同时覆盖可重复性、可交接性与方法学的可重做性。`evidence: [T03-S034, T03-S044]`

## Phase 2 提炼提示

### (a) 反复出现的同一条判断（候选心智模型与候选 playbook 规则）

写成「如果 X，则 Y」的形式，供 Phase 2 提炼为心智模型或规则：

1. **如果一个选择是在看到数据之后做出的，则它属于探索性，必须如此标注，不能写成检验结果。** —— 贯穿工作流 3、6、8。这是本行业最核心的一条纪律，也是复制危机的主线。`evidence: [T03-S027, T03-S050]`
2. **如果一件事将来可能产生争议，则现在就把它写下来并让相关方确认。** —— 贯穿工作流 5、10、12、13。署名、数据归属、分析设定、与编辑的往来，同一条判断的四个应用。`evidence: [T03-S011, T03-S014]`
3. **如果某个数字没有口径（谁、哪年、哪个学科、什么定义），则它不能被使用。** —— 贯穿工作流 9、11、14。分区、影响因子、审稿周期、接受率都是同一个陷阱。`evidence: [T03-S057, T03-S056]`
4. **如果一个步骤需要外部机构批准，则它在关键路径上，必须最先启动。** —— 贯穿工作流 1、4、11、12。伦理审查、人类遗传资源审批、依托单位审核、合作协议签署。这是时间表崩溃的最常见单一原因。`evidence: [T03-S016, T03-S018, T03-S024]`
5. **如果你要引用或采用一份规范 / 法规 / 期刊政策，则先确认现行版本号与生效日期。** —— 贯穿工作流 2、3、4、8、9、11。`evidence: [T03-S001, T03-S010]`
6. **如果结果异常漂亮，则先找错误再找解释。** —— 工作流 6、7。低功效加发表门槛会系统性放大效应量；漂亮结果的第一反应应该是查数据。`evidence: [T03-S050]`
7. **如果你发现自己论文有错，则由你主动把事实交给编辑，而不是等别人发现。** —— 工作流 13。主动纠错与被动处理在规范与同行评价里是两件不同性质的事。`evidence: [T03-S015]`
8. **如果一本刊在投稿前不明示费用、评审流程或编委会信息，则不投。** —— 工作流 9。正向核查清单优于任何黑名单。`evidence: [T03-S053, T03-S055]`
9. **如果一份工作可以被完整报告，则不拆成多篇。** —— 工作流 1、8。`evidence: [T03-S013]`
10. **如果一个数据集涉及个人信息或人类遗传资源，则「开放」不是默认选项，分层归档才是。** —— 工作流 5、14。FAIR ≠ Open。`evidence: [T03-S034, T03-S018]`

### (b) 入门与资深的真实差距在哪几步

不是「资深的人做得更快」，而是**在这几步上做的事根本不同**：

1. **选题的来源不同**（工作流 1）。入门者从兴趣发散再收敛；资深者的题目来自上一篇的局限、审稿意见里反复出现的质疑、或指南空白——本质是从「找一个能做的题」变成「维护一条能长期长下去的线」。
2. **文献的读法不同**（工作流 2）。入门者按关键词穷举；资深者用引文网络反向追并区分「引用是支持还是反驳」，把近三年的高质量综述当骨架。
3. **写作的顺序不同**（工作流 8）。入门者从引言写起并边写边查；资深者先定图、先写方法、最后写标题与摘要，且改稿顺序是结构 → 句子 → 词。
4. **对「补实验」要求的处理不同**（工作流 10）。入门者自动买单；资深者先判断这个实验是否真的改变结论，不改变的用敏感性分析或文献替代并说明理由。
5. **关键路径的识别不同**（工作流 4、11、12）。资深者把伦理审批、人类遗传资源备案、依托单位内部截止日、合作协议签署这些外部依赖排在最前面并与其他工作并行；入门者串行推进，然后在最后一周被卡住。
6. **稳健性的做法不同**（工作流 6）。入门者补几个模型应付审稿人；资深者系统化地把所有合理设定跑一遍，先自己知道结论有多脆弱。
7. **纠错的时机不同**（工作流 13）。入门者拖延观望；资深者在天到周的量级内主动把事实交给编辑。

### (c) 理工与社科在流程上的关键差异

| 环节 | 理工 / 生医侧 | 社科侧 |
|------|---------------|--------|
| 可行性瓶颈 | 设备、试剂、动物、算力、伦理批件周期 | 数据可得性、被访者招募、量表授权、二次数据的使用条款 |
| 设计与预注册 | 随机对照与动物实验有成熟的报告规范（CONSORT 2025、ARRIVE 2.0），方案规范与结果规范配套 | 预注册文化更强（源自复制危机），但定性研究的规范（COREQ / SRQR）本身存在方法学争议 |
| 主要偏倚来源 | 材料与试剂（细胞系、抗体）、低功效、随机化与盲法缺失 | 研究者自由度、测量效度、分叉路径、发表偏倚 |
| 稳健性做法 | 正对照 / 负对照、独立重复实验、盲态分析 | 多重宇宙 / 规格曲线、多种模型设定、跨样本验证 |
| 图表 | 图版（显微、电泳、影像）受图像完整性政策强约束，被常规抽查 | 以统计图为主，主要风险是不确定性未呈现与轴的误导 |
| 写作 | 方法学细节的可重做性是审稿焦点 | 理论框架与操作化的对应关系是审稿焦点 |
| 综述 | 系统综述与元分析在健康领域是独立研究体裁 | 叙述性综述与理论综述占比更高，系统综述的规范落地较晚 |
| 时间结构 | 受实验周期与设备排期支配，补实验以月计 | 受数据收集与伦理周期支配，分析与写作占比更高 |
| 中国侧特有约束 | 人类遗传资源、实验动物许可证、临床试验注册 | 个人信息保护法的单独同意、AI 与算法纳入伦理审查、涉密与敏感议题的额外审核 |

### (d) 信号薄弱维度（Phase 2 需要补研究或明确标注不确定的地方）

1. **一切周期类数字。** 审稿周期、伦理审查时长、基金评审时长——公开可查的只有各期刊各机构的**自报口径**，且不同刊不同学科相差数倍。本文件一律写成区间并注明口径，Phase 2 不应把它们压成点估计，也不应跨学科套用。
2. **接受率与通过率。** 多数期刊不公布，公布的也口径不一（是否含桌拒、是否按投稿数还是按送审数）。本文件因此没有给出任何具体数字。
3. **中国各单位的内部流程。** 伦理委员会开会频率、科研处内部截止日、本单位的学位与考核细则——这些变化频率高于国家文件，且单位间差异极大，只能写成「必须去查本单位现行版本」这样的行为指令，不能写成事实。
4. **期刊分级的国内口径。** 中科院文献情报中心停止更新与发布分区表之后，各单位改用什么判据尚在过渡期，Phase 2 若涉及此处需按最新情况重查。`evidence: [T03-S056]`
5. **定性研究与人文学科的流程。** 本文件的定性侧主要依托 COREQ 与 SRQR 两套规范，但这两套本身受到「把量化清单思维套到定性研究上」的方法学批评；纯人文学科（史学、文学、哲学）的工作流与本文件的假设差异很大，本文件不覆盖。`evidence: [T03-S007, T03-S008]`
6. **AI 相关规则的稳定性。** 近 24 个月是这条线变化最快的时期（医学期刊编辑规范 2026 年 1 月版把 AI 独立成节、各出版商政策陆续更新、中国科学院发布诚信提醒），任何具体条款都应假定在 6–12 个月内可能再变。`evidence: [T03-S010, T03-S062, T03-S079]`
7. **基金申请的当年度规则。** 限项、资格、经费科目、时间节点逐年调整，本文件只写结构性事实与「查当年通告」的指令，不写任何具体日期与限额。`evidence: [T03-S024, T03-S065]`
